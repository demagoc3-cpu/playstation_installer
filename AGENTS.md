# PackageFlow: сохраняемые сценарии установки

## Постоянное требование: сохранять прежние функции

При любом изменении кода все ранее работающие функции должны продолжать
работать. Перед правкой определить затронутые сценарии и сохранить их
поведение, API, настройки и пользовательские данные. Исправлять согласованную
задачу; не включать попутно редизайн, замену протокола или маршрута установки.
Проверять затронутые сценарии подходящими существующими регрессионными тестами,
а изменения UI — также в браузере. При восстановлении логики установки и сети
сохранять согласованный дизайн библиотеки, «Заданий» и стабильную геометрию
карточки передачи. Не выдавать host-тесты за аппаратную проверку;
непроверенные сценарии явно указывать в отчёте. Реальную переустановку PS4
не повторять без нового задания пользователя.

Dev-сервер и production/Windows-сборка Nuxt не должны работать в одном каталоге
одновременно: они используют общую .nuxt. Сборку готовить в отдельной копии
или в согласованное окно. Не заменять node_modules у работающего dev-сервера.

Перед изменением выбора устройств, очередей, готовности или интерфейса заданий
  прочитайте это правило и запускайте соответствующие регрессионные тесты в
  пределах текущего задания; явные ограничения пользователя имеют приоритет.

- PS5 поддерживает PS4/PS5 PKG, Folder, UFS2, exFAT, PFS и FFPFSC.
  PKG использует наш отдельный PackageFlowInstaller-PS5; Folder и образы
  используют собственные маршруты. Недоступность одного маршрута не выключает
  остальные. Не подменять причину отказа PKG сообщением о готовом ShadowMount.
- Проверять как новую установку, так и повторную установку уже имеющегося PKG.
  Явное подтверждение переустановки должно доходить до очереди; наличие игры
  само по себе не запрещает выбор устройства.
- Готовность временно остановленного проверенного PKG-компонента PS5 не
  блокирует выбор приставки. Допуск задания и готовность передачи разделены:
  исходный worker сам ждёт готовности перед чтением/отправкой, без обхода его
  проверок. Исправление галочки не требует замены ELF или протокола установки.
- Сохранять переустановку PS4 через PackageFlowService: таблица подтверждения
  базы, патчей и DLC, проверка затронутых компонентов и переход к следующему
  заданию после успеха или ошибки. Не переносить ограничения PS5 на PS4.
- PyLoader работает без сопряжённой службы, её каталога и проверки места.
  Неизвестное или устаревшее freeBytes не блокирует этот способ установки.
- PS4 не устанавливает содержимое PS5. Не фильтровать смешанный набор молча.
- Скорость и оставшееся время берутся из живой телеметрии публичной очереди.
  Повторный опрос без нового подтверждённого блока не означает разрыв передачи.
  Не менять протокол передачи ради правки отображения.
- Выбор библиотеки сохраняется между поиском, страницами и фильтрами.
  Одиночная установка не очищает остальные выбранные игры.
- Не отправлять реальную установку и не перезапускать службу ради проверки UI,
  пока на приставке идёт задание. Host-тесты отделять от аппаратных результатов.

Основные проверки: `server/tests/device-installation.test.mjs`,
`device-install-modal.test.mjs`, `device-installed-review.test.mjs`,
`ps5-install-readiness.test.mjs`, `ps5-folder-production.test.mjs`,
`ps5-image.test.mjs`, `transfer-speed.test.mjs`, `library-selection.test.mjs`.

## Проверка веб-фиксов на Windows

Порядок пользователя: для итераций WEB-фиксов сначала собрать production WEB
в отдельной копии проекта и передать совместимый веб-патч для установленного
PackageFlow. Проверить исправления на Windows, затем после успешных тестов
собрать полный установщик EXE. Не выполнять полную Windows-сборку на каждой
итерации правок только в WEB.

Патч сохраняет данные, настройки, библиотеку, ключи и очереди. Зафиксировать
исходную версию и хеши; сохранить заменяемый веб для отката. Изменения launcher,
Node runtime или состава поставки требуют отдельной оценки совместимости и
нужной сборки. Прямой запрос пользователя на полный установщик имеет приоритет.

## Рабочие чаты и границы ответственности

Пользователь заменил исторические рабочие чаты новыми. Для новых заданий
использовать только это распределение:

- Оркестратор / WEB / общие API: `01a13f28-856b-71d2-8f49-157b8cef0959`.
- Windows / установщик: `01a13f51-d1f0-7670-9e33-ac86845ace81`.
- Нативное приложение PS5: `01a13f52-2bcd-7b21-bddb-8abec2bfa697`.
- Самостоятельная ELF-служба PS5: `01a13f4d-78b7-7941-9fdd-26c5f6c17ac0`.

Windows ведёт apps/windows-launcher, packaging/windows, scripts/package-windows*
и Windows CI. app/, server/, shared/ и nuxt.config.ts ведёт WEB. Общие изменения
API и состава комплекта согласовывать с оркестратором до редактирования.
