# Файлы — PackageFlowService 1.55

## Удаление

- Отметьте файлы или папки и нажмите «Удалить». «В корзину» по-прежнему позволяет сохранить их для возврата.
- В корзине можно удалить отдельную копию либо нажать «Очистить корзину». WEB показывает точный список выбранных копий перед подтверждением; новые копии не включаются в уже начатое задание.
- Окончательное удаление необратимо. Подтверждение показывает консоль, пути и количество элементов.
- Перед удалением папки WEB собирает проверенный список содержимого. Сервис удаляет только проверенные файлы и пустые папки, сверяя ревизию и идентификатор объекта. Новые файлы, появившиеся после проверки, не удаляются автоматически.
- Служебные файлы, системные области, ссылки, файлы с несколькими жёсткими ссылками, незавершённые передачи и источник активной установки защищены.
- Прерванное задание доступно в «Истории операций». Продолжение использует прежний список и записанные результаты. Частично удалённая копия из корзины не предлагается к восстановлению.

Для новых действий нужна запущенная служба 1.55. На предыдущих версиях новые кнопки отключены.

## Скорость загрузки

Раньше браузер передавал фрагменты по 256 КиБ; каждый фрагмент проходил через WEB отдельным запросом и завершался `fsync` на PS4. В 1.55 размер фрагмента согласуется при начале передачи и может достигать 4 МиБ. Сервис читает сетевые данные несколькими ограниченными порциями за проход, не выделяя память под весь фрагмент. Проверка позиции и принудительная запись перед подтверждением сохранены; старые службы продолжают получать по 256 КиБ. Пауза/докачка поддерживаются и при разрыве внутри большого фрагмента.
