# Установленное на PS4 — PackegeFlowService 1.19

В боковом меню **«На консоли»** показываются игры, установленные именно на выбранной PS4. Локальная библиотека PKG на компьютере — отдельный источник.

Названия, обложки, запуск/остановка, переустановка и обновление сервиса добавлены в 1.19. [Порядок проверки новой версии](console-management-1.19.md). Пользователь подтвердил работу раздела 1.18; подробные сценарии удаления ниже остаются отдельными проверками.

## Проверка удаления

1. Дождаться завершения установки/удаления на PS4. Установить PKG 1.19 поверх 1.18 и открыть запускатель: он остановит предыдущий собственный демон и запустит новый. В «О системе» должна быть версия сервиса 0.6.0 / PKG 1.19.
2. Обновить и перезапустить WEB. Открыть «На консоли»; прежнее сопряжение используется автоматически. Если подключение ещё не сохранено, ввести код ABC-DEF с экрана запускателя один раз.
3. Открыть игру и проверить базовую игру, установленный патч / бэкпорт и DLC, версии и размеры PKG, внутренний или внешний диск.
4. Для первого испытания выбрать ненужный отдельный DLC или патч. В окне удаления проверить список и ввести TITLE_ID игры. Дождаться «Удаление подтверждено PS4», проверить состав на самой консоли и запуск игры.
5. После этого испытать удаление всей отдельной тестовой игры. Сохранения не включаются в команды удаления.

Бэкпорт не имеет самостоятельного надёжного признака в установленном содержимом PS4. Он показывается в составе патча. После удаления патча игра возвращается к базовой версии; совместимость конкретной игры с текущей прошивкой и сохранениями нужно проверить на PS4.

## Как подтверждается удаление

- Игра: `sceAppInstUtilAppUnInstall(TITLE_ID)`; патч: `sceAppInstUtilAppUnInstallPat(TITLE_ID)`; DLC: `sceAppInstUtilAppUnInstallAddcont(TITLE_ID, label16)`.
- Полное удаление выполняет команды для обнаруженных DLC, патча, затем базовой игры. Системные приложения и сам сервис доступны только для просмотра. Файлы игры напрямую не удаляются, базы приложений не редактируются, команды удаления пользовательских сохранений не вызываются.
- Состав читается из `/user/app`, `patch`, `patch0`, `addcont`, `appmeta` и доступных `/mnt/ext0/user`, `/mnt/ext1/user`. Название/версия читаются из SFO. Системный `AppExists` подтверждает наличие игры: оставшийся appmeta не выдаётся за установку.
- Перед удалением повторно читается состав и проверяется его идентификатор версии. Установка/обновление и неполный состав блокируют команду. Отключённый внешний диск необходимо подключить.
- Команда выполняется отдельным потоком. Счётчик показывает выполненные системные команды, затем три проверки отсутствия выбранных компонентов. Исходные файловые системы должны оставаться доступны. Код 0 от удаления сам по себе ещё не даёт успешный итог.
- PS4 сохраняет журнал до каждого системного вызова; WEB сохраняет идентификатор до единственного POST. После перезапуска или разрыва связи используются GET прежнего задания. Повторной команды, переключения на payload и удаления других компонентов по догадке нет.
- Частичный сбой — отдельное состояние: уже удалённое не восстанавливается автоматически. Обновить список для проверки фактического состава. Неизвестное состояние сверяется чтением, без новых удаляющих вызовов.
- После подтверждённого удаления WEB снимает соответствующие отметки установки и старые записи очереди в своей библиотеке. Исходные PKG на компьютере остаются.

## API

Все методы демона ниже требуют существующий Bearer ключ сопряжения. Его хранит сервер WEB; браузер ключ не получает.

| Демон, порт 12801 | Назначение |
| --- | --- |
| `GET /apps/list?offset=0` | Страница списка; 8 приложений. Следующая страница передаёт `offset` и `revision` из ответа |
| `GET /apps/title/CUSA00001?offset=0` | Страница компонентов; 8 компонентов; последующие страницы с тем же `revision` |
| `POST /apps/remove` | Команда удаления с UUID, выбранной игрой/компонентом и подтверждением |
| `GET /apps/operations/{requestId}` | Прежнее задание и проверка его результата |

Пример тела команды (передаётся только после подтверждения выбранного компонента):

```json
{"requestId":"11111111-1111-1111-1111-111111111111","titleId":"CUSA00001","kind":"dlc","componentId":"ABCDEFGHIJKLMNOP","revision":"0123456789abcdef","confirmTitleId":"CUSA00001"}
```

`kind`: `game` / `patch` / `dlc` / `dlcs`. `componentId`: `all` для игры и всех DLC, `patch` для патча, 16 символов label для отдельного DLC. `revision` берётся из свежего ответа состава. Состояния: `queued`, `running`, `verifying`, `removed`, `failed`, `partial`, `uncertain`; ответ содержит выполненное/общее число команд, native код ошибки и код проверки.

WEB: `GET /api/ps4/apps?ip=…`, `GET /api/ps4/apps/details?ip=…&titleId=…`, `POST /api/ps4/apps/remove`, `GET /api/ps4/apps/operation?ip=…`. Изменяющий маршрут проверяет JSON и Origin; используется тот же сохранённый ключ, что и для установки.

Журналы: `.data/ps4-remove-operations.json` на компьютере, `/data/PackegeFlowService/remove-jobs-v1.bin` на PS4. Первая версия ограничена 512 приложениями, 130 компонентами игры, 32 записями удалений PS4 и 256 записями WEB. Переполнение блокирует новую команду; неполный список помечается явно.

PyLoader остаётся способом установки по умолчанию, в том числе для торрентов, патчей и DLC. Установка новой базовой игры через сервис 1.17 подтверждена пользователем. Работа раздела 1.18 подтверждена пользователем. Локальные проверки покрывают отдельные сценарии удаления с имитацией системных вызовов; это не подтверждает испытание каждого такого сценария на прошивке 12.50.

## Проверки и первичные источники

Native проверки: `make -C PackegeFlowService test-apps test-ps4-install`; production тесты WEB: `node --experimental-strip-types --test server/tests/*.test.ts` на Node 24. Проверяются настоящие модули проекта с временными файлами и имитацией внешних PS4 вызовов: DLC label, patch0, 64-битные размеры, AppExists, повторы/перезапуск, изменившийся состав, частичный сбой, отключённый диск, пустые каталоги и сохранения. Сборка проверяет SFO/SELF/imports/GP4. Это не заменяет реальное испытание удаления на PS4.

Методы AppInstUtil сверены с [PS4 Remote PKG Installer](https://github.com/flatz/ps4_remote_pkg_installer/blob/master/installer.c); расположение дополнений — с [Itemzflow](https://github.com/LightningMods/Itemzflow/blob/main/itemzflow/source/sql.cpp). Дополнительный референс: [STORM PS4 PKG INSTALLER](https://github.com/ReiKatari/STORM_PS4_PKG_INSTALLER).
