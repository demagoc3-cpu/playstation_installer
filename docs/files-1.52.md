# Файлы: PackageFlowService 1.52

## Использование

1. После завершения текущей очереди выберите `PackageFlowService-1.52.pkg` в «О системе» и установите обновление.
2. Запустите PackageFlowService на PS4 вручную; WEB должен увидеть PKG 1.52. На странице «Файлы» можно нажать «Проверить версию».
3. Для изменений откройте `/data` или USB. Отметьте элементы и выберите действие.
4. Для копирования/перемещения откройте папку назначения и нажмите «Вставить сюда». Прогресс показан отдельной карточкой; копирование можно приостановить и продолжить.
5. «В корзину» сохраняет выбранное на том же диске. В «Корзине и предыдущих версиях» кнопка «Вернуть» возвращает элемент, если исходное имя свободно.
6. Для редактирования TXT/JSON/конфигурации нажмите «Открыть». Сохранение проверяет исходник и оставляет предыдущую версию.
7. При загрузке файла с занятым именем подтвердите замену. Ранее существовавший файл сохраняется.

Результат операции появляется временно в углу: успех — на 5 секунд, ошибка или пауза — на 10 секунд. Уведомление можно закрыть сразу. Текущая операция показывает прогресс, завершённые доступны по кнопке «История операций»; там же можно продолжить прерванную операцию. Старые результаты при открытии страницы повторно не всплывают.

## Где хранятся данные

PKG не копируются в WEB целиком при операциях проводника: передача идёт частями по 256 КиБ. Фоновая задача требует работающий WEB. После его перезапуска нажмите «Продолжить проверку» в прежней задаче; записанные результаты сверяются перед продолжением.

Корзина и предыдущие версии находятся на PS4 и занимают место. Их каталог хранится в `.data/console-files` на компьютере с WEB; при Docker это часть постоянного volume. Список корзины зависит от сохранности этих данных. Символические ссылки и служебные пути не изменяются. Сохранения игры восстанавливаются через «Сохранения», игры удаляются через «На консоли».

## Проверка

Локально проверены реальные C-операции и серверный исполнитель: папки, переименование, перемещение, копирование большого файла с продолжением после обрыва, копирование пустых папок, конфликты имён, потеря ответа после перемещения, корзина и возврат папки, редактор UTF-8, резервная версия и отклонение устаревшей записи. Отдельно проверяется совместимость прежних служебных загрузок обложек. Собираются WEB и PKG, проверяются SFO/SELF/импорты.

На реальной PS4 в 1.50 обнаружен отказ OpenOrbis libc `lstat`: она вызывает неподдерживаемую `fstatat`. В 1.52 проверка без перехода по символическим ссылкам использует системный вызов PS4 и явно декодирует структуру свойств: у SDK также неверна ширина mode_t, смещающая число ссылок, размер и даты. Эта ветка также проверяется локальными тестами. Проверка операций на приставке завершена: PackageFlowService 1.52, PS4 Pro, прошивка 12.50, 02.10.2026. В отдельной папке /data проверены создание папок, переименование, копирование папки и файла 640 000 байт с побайтовой сверкой, перемещение, загрузка с продолжением от 262 144 байт, редактирование UTF-8/CRLF, отказ устаревшему исходнику, восстановление предыдущей версии, замена при загрузке, корзина и возврат папок. Данные успешной проверки и отдельной проверки интерфейса убраны в обратимую корзину. От диагностики 1.51 осталась папка `/data/PackageFlowFilesTest-20261002-fef542` с незавершённой пустой частью передачи; она не содержит пользовательских данных. Очистка забытых частей передачи после перезапуска остаётся отдельной доработкой. USB и перемещение между дисками проверены только локально, реальный USB не испытывался.

Схема свойств PS4 сверена с [определением OrbisKernelStat в shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/kernel/file_system.h); на неё добавлены проверки размера и смещений полей при сборке.
