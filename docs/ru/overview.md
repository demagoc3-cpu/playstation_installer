# Обзор и схема работы

[← Содержание](index.md) · [English](../en/overview.md)

## Возможности

**Библиотека пакетов**
- Рекурсивное сканирование папки с `.pkg` / `.fpkg` (до 500 пакетов за проход); системный диалог выбора папки на Windows, macOS и Linux.
- Метаданные прямо из PKG: таблица файлов и заголовок (тип тома приложения, патча или DLC), `PARAM.SFO` (название, `TITLE_ID`, `CONTENT_ID`, `APP_VER`, исходная версия) и обложка `icon0.png`. Одинаковый `CONTENT_ID` у игры и патча не считается признаком одинакового пакета.
- Автоматическое определение типа: **Игра**, **Патч**, **Бэкпорт** (по слову `backport` в имени), **DLC**; группировка по `CUSA`.
- Кэш сканирования и сохранение библиотеки между запусками. Файлы **никогда не копируются** — только читаются и раздаются по HTTP.

**Установка на PS4**
- Один пакет, выбранные, все DLC или вся библиотека; порядок очереди **игра → патчи / бэкпорты → DLC**.
- Два способа установки:
  - **PackageFlowService** (по умолчанию) — фоновый сервис на PS4: сообщает этап установки, ошибки и подтверждение завершения, умеет ставить игры, патчи и DLC;
  - **PyLoader** — через загрузчик payload на порту `9090`, ничего ставить на приставку не нужно.
- Прогресс передачи в реальном времени, отмена установки, сброс статуса для повторной установки.
- Очередь сохраняется на диск и продолжает работу после перезагрузки страницы или сервера.

**На консоли** *(через PackageFlowService)*
- Список установленных игр с обложками и составом: базовая игра, патч / бэкпорт, отдельные DLC, версии, размеры, внутренний или внешний диск.
- Удаление патча, отдельного DLC, всех DLC или игры целиком — с подтверждением. Сохранения не удаляются.
- Запуск и остановка игры.
- Переустановка игры из библиотеки: удаление прежней версии с патчами и DLC и установка выбранного PKG.

**О системе и обслуживание сервиса**
- Прошивка, модель (PS4 / Pro), версия GoldHEN, место на дисках, версия и время работы сервиса.
- Обновление PackageFlowService прямо из веба: из релиза на GitHub или из локального PKG; перезапуск сервиса.

**Файлы консоли** *(через PackageFlowService)*
- Проводник по каталогам PS4, скачивание файлов на ПК (с докачкой).
- Загрузка файлов в `/data` и на USB‑накопители с паузой и продолжением после обрыва связи.

**Торренты**
- qBittorrent на этом ПК, на NAS, в Docker или на другом компьютере в сети.
- magnet‑ и `.torrent`‑ссылки, выбор файлов, пауза / продолжение.
- **Автоустановка**: после загрузки сервер сам добавляет пакеты в библиотеку и отправляет их на PS4 — страница может быть закрыта.
- Поиск через Torznab (Jackett, Prowlarr).

**Интерфейс**
- Боковое меню: Библиотека, На консоли, Загрузки, Поиск, Журнал, Файлы, О системе.
- **Журнал** событий сервера: запросы PS4, передача пакетов, ошибки qBittorrent и API — прямо на странице.
- IP приставки и настройки запоминаются; открытый раздел сохраняется в адресе (`/#console`, `/#log` …).

## Как это работает

PS4 всегда скачивает PKG **с сервера PackageFlow** по HTTP (сервис загрузок BGFT). Способ установки определяет только то, **кто даёт приставке команду** и как PackageFlow узнаёт результат.

```
┌──────────────────────── ПК ─────────────────────────┐              ┌──────────── PS4 ────────────┐
│                                                     │              │                             │
│  Браузер ──► PackageFlow (Nuxt / Nitro, порт 3000)  │              │  GoldHEN                    │
│                 │                                   │              │                             │
│                 │  PackageFlowService (по умолч.)   │              │                             │
│                 ├── HTTP API :12801 + ключ ─────────┼─────────────►│  PackageFlowService         │
│                 │   установка, статус, консоль      │◄─────────────┼─ этап, ошибки, результат    │
│                 │                                   │              │                             │
│                 │  PyLoader                         │              │                             │
│                 ├── payload (.bin) на :9090 ────────┼─────────────►│  загрузчик payload          │
│                 │                                   │              │                             │
│   /json/<id>.json      (манифест)  ◄────────────────┼──────────────┤  BGFT скачивает PKG         │
│   /api/packages/<id>   (Range)     ◄────────────────┼──────────────┤  и устанавливает            │
│                                                     │              │                             │
│   qBittorrent Web UI (этот ПК или NAS) ◄── API      │              │                             │
└─────────────────────────────────────────────────────┘              └─────────────────────────────┘
```

**Через PackageFlowService.** PackageFlow передаёт сервису на приставке ссылку на манифест пакета (`http://<IP ПК>:3000/json/<id>.json`). Сервис ставит задачу в BGFT и сообщает этап установки, ошибки и подтверждение завершения. Для этого WEB и сервис один раз сопрягаются кодом с экрана PS4 — см. [раздел ниже](ps4-app.md).

**Через PyLoader.**
1. Проверяется загрузчик: `GET http://<PS4_IP>:9090/status` → `{"status":"ready"}`.
2. PackageFlow вшивает `IP:порт` компьютера в payload `public/ps4-pkg-installer.bin` и отправляет его на `PS4:9090`; payload подключается обратно к ПК.
3. Для каждого пакета передаётся команда с URL манифеста, консоль скачивает PKG, PackageFlow считает переданные байты и двигает очередь. Итог установки PyLoader не сообщает — его видно на экране PS4.

## Ограничения

- Поддерживается только **PS4** (`PS4GD`, `PS4GP`, `PS4AC` …). PS5 не поддерживается.
- Разделы «На консоли», «О системе» и «Файлы» работают только с запущенным и сопряжённым PackageFlowService.
- Одна активная очередь установки. Автоустановка торрентов использует сохранённый способ установки.
- В «Файлах» нет перезаписи, удаления и переименования; запись разрешена только в `/data` и на USB.
- Раздел «Удалённый доступ» пока в разработке.
- У самого WEB нет входа по паролю: **не открывайте порт `3000` в интернет**, используйте PackageFlow только в доверенной локальной сети.
- Пароль qBittorrent и API‑ключ Torznab хранятся в `.data/` в открытом виде.
