# Приложение PS4 и сопряжение

[← Содержание](index.md) · [English](../en/ps4-app.md)

## PackageFlowService и сопряжение с WEB

В приложении 1.72 при открытии проверяется, принимает ли служба ключ именно этого WEB. Пока проверка не завершена или сопряжения нет, доступны только **«Настройки»**, **«Подключения»** и **«Поддержать»**. Состояние видно в шапке: проверка, нет сопряжения, WEB недоступен или WEB сопряжён. Разделы автоматически открываются после успешного сопряжения; при разрыве связи приложение возвращается в «Подключения». Раздел [«Файлы»](files.md) использует общие с WEB операции.

**PackageFlowService** — фоновый сервис для PS4, с которым работает WEB. Через него идут установка с подтверждением результата, раздел «На консоли», «О системе» и «Файлы». Сервис распространяется **готовым PKG** в разделе [Releases](https://github.com/demagoc3-cpu/playstation_installer/releases) этого репозитория; его исходный код хранится в отдельном приватном проекте и не входит в исходники WEB. Сервис слушает HTTP API на порту `12801` и принимает команды только от сопряжённого WEB.

### Установка сервиса на PS4

1. Скачайте `PackageFlowService.pkg` из [Releases](https://github.com/demagoc3-cpu/playstation_installer/releases).
2. Установите его на PS4 удобным способом — например, из библиотеки PackageFlow способом **PyLoader** (добавьте папку с PKG, выберите «PyLoader», нажмите «Установить»).
3. Запустите **PackageFlowService** на приставке (в меню PS4 он называется *PackegeFlowService*). На экране появятся адрес сервиса и **код сопряжения**.

Дальнейшие обновления сервиса ставятся прямо из веба — раздел **«О системе» → «Обновление PackageFlowService»**: проверка релиза на GitHub или выбор локального PKG, затем установка и перезапуск сервиса. Приставка скачивает обновление с вашего ПК по локальной сети.

### Сопряжение

Сопряжение выполняется **один раз для каждого IP приставки**:

1. Подключите PS4 в PackageFlow: нажмите на IP в правом верхнем углу, введите адрес консоли → **Подключить**.
2. В разделе **«Библиотека»** в блоке **«Способ установки»** выберите **PackageFlowService**. Если сопряжения ещё нет, появится поле **«Код с экрана запускателя PS4»**.
3. Запустите PackageFlowService на PS4 и введите показанный код вида `F7Y-YUH`. Дефис и заглавные буквы подставляются автоматически. **Код действует 5 минут**; если он истёк, откройте запускатель на PS4 ещё раз.
4. Нажмите **«Подключить»**. PackageFlow проверит сервис и сохранит подключение — статус станет «Сервис готов к установке игр, патчей и DLC».

После этого сервис используется автоматически во всех разделах: повторно вводить код после перезапуска PS4 или PackageFlow не нужно.

- **«Проверить сервис»** — проверить, отвечает ли сервис и действительно ли сопряжение.
- **«Повторить сопряжение»** — ввести новый код, например после переустановки сервиса или если приставка «забыла» подключение.
- **Сменился IP приставки** (например, роутер выдал другой адрес) — выполните сопряжение для нового адреса. Лучше закрепить за PS4 постоянный IP в настройках роутера.

**Как хранится подключение.** При сопряжении сервис выдаёт WEB ключ доступа. Ключ хранится только на сервере PackageFlow — в файле `.data/ps4-service-keys.json` с правами доступа только для владельца — и никогда не передаётся в браузер. Чтобы «забыть» приставку, удалите её запись из этого файла (или весь файл) при остановленном PackageFlow.

## Язык интерфейса

Переключатель **RU / EN** находится справа в верхней панели. По умолчанию используется русский язык. Выбор сохраняется в браузере на год; переключение происходит сразу, без перезагрузки страницы и перезапуска очереди.

Переводятся разделы, кнопки, подсказки, диалоги и известные сообщения операций. Даты и числа отображаются в формате выбранного языка. Названия игр, имена файлов, пути и адреса кошельков сохраняются исходными. Язык WEB не меняет язык установленной игры или интерфейса PS4.

Для разработчиков: словарь английского перевода находится в `app/locales/en.json`, общее состояние языка — в `app/composables/useAppLocale.ts`. Добавляйте новые сообщения в словарь и выводите их через `t(...)`; переменные в шаблонах обозначаются `{0}`, `{1}` и т. д. Внутренние значения типов пакетов и сохранённые статусы API остаются прежними. Неизвестные диагностические сообщения показываются исходными.

## Меню PackageFlow на PS4

Один PKG содержит интерфейс и фоновую службу. После активации HEN запустите PackageFlow. Чтобы закрыть только интерфейс, выйдите из карточки кругом и выберите Options → крестик. Служба продолжит работу; после перезагрузки PS4 снова активируйте HEN и запустите приложение.

Интерфейс Full HD (1920×1080): каталог из пяти карточек в ряд и двух рядов, обложки приходят из WEB. ПК с WEB должен оставаться доступным по сети. Встроенного торрент-клиента и внешнего JSON-каталога пока нет.

| Раздел | Как пользоваться |
|---|---|
| Каталог | Стрелки / левый стик — выбор; крестик — открыть игру; квадрат — избранное |
| Поиск | Треугольник — поиск; на PS4 вызывается штатная клавиатура, при отказе — резервный ввод; поиск по названию или CUSA |
| Избранное | Отмеченные игры; сейчас выбор сохраняется только до закрытия приложения |
| Задания | Очередь установок, текущий пакет, отмена текущего пакета или всей очереди |
| Загрузки | Отдельные вкладки для qBittorrent WEB и будущего клиента PS4; локальная вкладка пока без загрузок |
| На консоли | Управление из самого приложения ещё не подключено; используйте WEB → На консоли |
| Настройки | Квадрат — RU/EN, язык сохраняется после перезапуска; крестик — обновить каталог |
| Подключения | Получить код и разорвать сопряжение с WEB |
| Поддержать | BTC и USDT (Tron / TRC20); QR скрыты, крестик показывает только выбранный код |

В шапке: IP PS4, прошивка, свободное место внутреннего диска и язык. Версия PKG находится возле логотипа.

### Карточка игры

Слева обложка, справа описание и пакеты. L1/R1 — страницы пакетов; треугольник — полное имя файла; крестик — выбор пакета / действие; Options — установить выбранное. Кнопки «Установить всё», «Выбранное», «Патчи», «DLC» запускают одну очередь WEB/PS4. «Переустановить всё» сначала показывает состав удаления; Options подтверждает, круг отменяет. Затем устанавливается комплект игра → патчи/бэкпорты → DLC.

В версии 1.68 добавлены прогресс и этап прямо в карточке, «Отменить пакет» и «Отменить игру». Отмена игры затрагивает только её незавершённые пакеты; очередь других игр сохраняется. Отмена текущего пакета доступна, когда именно эта игра устанавливается. Полная передача файла ещё не означает успешную установку: окончательный результат подтверждает PS4. При обрыве WEB показаны последние данные.

Статус в шапке карточки проверяет наличие базовой игры непосредственно на консоли. «Установлена» не означает, что уже установлены все патчи и DLC.

### Разрыв сопряжения

Подключения → вправо → «Разорвать сопряжение» → Options. Отзывается **общий ключ всех сопряжённых WEB**, а не одного устройства. Синхронизация прекращается; после перезапуска прежний ключ по-прежнему не действует. Для нового подключения получите код и в WEB нажмите «Повторить сопряжение»; будет выдан новый ключ.

Сначала завершите/отмените установки и удаления и завершите загрузки через «Файлы», в том числе поставленные на паузу. Во время незавершённых операций отключение отклоняется. Функция не отключает PS4 и не останавливает службу.

### Адрес WEB для каталога

Используется `/data/PackageFlowUI/server-url.txt`, если он существует, иначе адрес из PKG. Для собственной сети запишите полный адрес `http://<IP компьютера>:3000`, например `http://192.168.1.10:3000`, и перезапустите интерфейс. `127.0.0.1` на PS4 означает саму PS4. Настройка адреса пока не редактируется кнопками меню.

### Проверка новой сборки

На реальной PS4 подтверждены открытие штатной клавиатуры, отзыв сопряжения и повторное подключение в 1.67. В 1.68 исправлено назначение крестика в системной клавиатуре; оно требует проверки после установки. Прогресс и отмена в карточке проходят автоматические проверки; полный сценарий установки и отмены на PS4 ещё проверяется.
