# Дальнейший план

[← Содержание](index.md) · [English](../en/roadmap.md)

План не означает, что эти функции уже доступны.

1. Закончить проверку 1.68 на PS4: карточка/отмена, штатная клавиатура и отзыв сопряжения; исправить обнаруженные ошибки.
2. Подключить «На консоли» в приложении к уже существующему API установленных игр и управления.
3. Сохранять избранное и наборы игр. Пак — список ссылок на пакеты библиотеки, без копирования PKG; редактирование и установка набора по очереди.
4. Добавить внешний JSON-каталог через отдельный API: обложки, описания, версии, патчи, DLC и разрешённые magnet-ссылки. Внутренняя библиотека WEB и внешние источники отображаются раздельно.
5. Исследовать встроенный торрент-клиент PS4: докачка, ограничения диска и сети, последовательная установка через единую службу. Загрузки WEB и локальные PS4 остаются разными источниками.
6. Несколько PS4: отдельная страница консолей, выбор получателя перед установкой, независимая очередь на каждую PS4, установка одного пака на несколько приставок.

Работа над удалённым экраном и интернет-туннелем отложена. Раздел удалён из WEB. Автоматическая активация HEN самим неподписанным PKG не реализована.
