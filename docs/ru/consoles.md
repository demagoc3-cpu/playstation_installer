# Подключение PS4 и PS5

[← Содержание](index.md) · [README](../../README.md) · [English](../en/consoles.md)

Один WEB PackageFlow работает с несколькими PS4 и PS5. У каждой приставки собственные подключение, очередь и история; библиотека на компьютере или NAS общая. Файлы компонентов доступны в [Releases](https://github.com/demagoc3-cpu/playstation_installer/releases/latest).

## Перед подключением

- Запустите WEB на компьютере или NAS. Откройте `http://localhost:3000` на этом компьютере или `http://<IP компьютера>:3000` с другого устройства. Если порт изменён, используйте свой.
- Подключите приставку и компьютер к доступной друг другу локальной сети. Приставка должна обращаться к **LAN IP компьютера**, а не к `localhost`. Разрешите необходимые соединения в брандмауэре и оставляйте WEB включённым во время заданий.
- Подготовьте совместимую среду homebrew на приставке. Установка PackageFlow сама по себе не активирует GoldHEN, эксплойт или загрузчик ELF.
- По возможности закрепите IP приставки в DHCP роутера: адрес существующего профиля в WEB не редактируется.

## PS4

1. Активируйте **GoldHEN**. Установите PKG **PackageFlow для PS4** из релиза и запустите приложение на приставке: оно содержит интерфейс и фоновую службу **PackageFlowService**.
2. В WEB откройте **«Устройства» → «Добавить устройство»**. Укажите название, тип **PlayStation 4** и **«IP приставки»**. В поле **«Способ установки»** выберите **PackageFlowService**, нажмите **«Сохранить»**.
3. В строке PS4 выберите **«Сервис → Подключить»**. Актуальная служба подключается **без кода с экрана приставки**. WEB сохраняет ключ и передаёт службе адрес WEB; статус подключения становится **«Сопряжено»**.
4. Добавьте папку с играми в библиотеку и отправьте выбранные PKG на PS4. Перед запуском проверьте получателя и состав игры, патчей и DLC в окне установки.

Если WEB просит обновить службу для подключения без кода, установите актуальный PKG и запустите его. Для уже подключённой PS4 доступны **«Сервис → Проверить подключение»**, **«Обновить сервис»** и **«Переподключить»**.

**PyLoader — резервный способ для PS4**, в том числе для первой установки PKG службы. На приставке нужны активный GoldHEN и PyLoader на TCP `9090`; в профиле PS4 выбирается способ **PyLoader**. В Windows мастер также предлагает **«Установить сервис»** через PyLoader. Для этого пути сопряжённая служба не обязательна. Передача PKG и окончание системной установки — разные этапы: результат первой установки проверьте в **«Уведомления → Загрузки»** на PS4, затем запустите PackageFlow и подключите службу.

## PS5

У PS5 два отдельных компонента:

| Компонент                                                                                         | Назначение                                                                                                   |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **ELF-служба** (`PackageFlowPayload-PS5_….elf` в релизе; в PLDMGR — `PackageFlowService-PS5.elf`) | Фоновое API для передачи, установки и управления из WEB. Нужна для работы WEB с PS5.                         |
| **Нативное приложение** (`PackageFlow-PS5_….ffpkg`)                                               | Необязательный интерфейс библиотеки и заданий на самой PS5, с управлением геймпадом. Не заменяет ELF-службу. |

1. Подготовьте совместимую среду homebrew с запуском ELF. Для управления службой из WEB нужен доступный **PLDMGR** на PS5 (HTTP `8084`). Для **Folder и образов** также нужен установленный и работающий **ShadowMount**, API которого поддерживает служба.
2. В WEB откройте **«Устройства → Добавить устройство»**, выберите **PlayStation 5**, укажите имя и IP, нажмите **«Сохранить»**.
3. Подготовьте ELF-службу из того же выпуска PackageFlow. Если WEB содержит комплект для приставок, используйте **«Сервис → Установить из комплекта WEB»** и подтвердите действие. Если ELF уже сохранён в PLDMGR, выберите **«Сервис → Запустить»**. При ручной подготовке используйте ELF из Releases и совместимый загрузчик вашей среды.
4. Выберите **«Сервис → Проверить службу»**, затем **«Сервис → Подключить»**. Подключение актуальной службы выполняется **без кода**; API службы работает на TCP `8095`.
5. Добавьте источники в библиотеку. В окне установки WEB отдельно проверит доступность **PKG**, **Folder** и образов **UFS2, exFAT, PFS, FFPFSC** для этой PS5.

Для сохранённой в PLDMGR службы доступны **«Добавить в автозапуск»**, **«Проверить обновления»**, запуск и остановка. Кнопка **«Открыть»** в строке PS5 открывает её PLDMGR. Проверка состояния сама по себе не устанавливает и не запускает ELF.

Для работы только из браузера нативное приложение PS5 устанавливать не требуется. Если нужен интерфейс на приставке, используйте FFPKG из Releases и совместимый способ установки в своей среде. Приложение должно обращаться к LAN адресу запущенного WEB; подключение приложения к каталогу и подключение фоновой службы — отдельные настройки.

## Что определяет доступность установки

WEB учитывает возможности **запущенной службы**, её готовность, прошивку и метаданные выбранного содержимого. Успешное подключение не означает готовность каждого способа установки. Недоступность ShadowMount относится к Folder/образам и сама по себе не отключает PKG; для PKG показывается собственная причина отказа.

PS5 может принимать PKG PS4 и PS5, а также поддерживаемые Folder и образы, когда соответствующий маршрут подтверждён службой. **PS4 не устанавливает содержимое PS5.** Поддержка формата не гарантирует совместимость любой прошивки или запуск конкретной игры. Перед установкой весь выбранный набор проверяется для каждого получателя.

После потери ответа проверьте прежнее задание в **«Заданиях»** или результат операции, прежде чем отправлять команду снова. Обновляйте и перезапускайте компоненты после завершения активных передач и установок.
