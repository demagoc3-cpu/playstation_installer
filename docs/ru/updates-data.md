# Обновления, данные и настройки

[← Содержание](index.md) · [English](../en/updates-data.md)

## Где хранятся данные

Всё состояние — обычные JSON‑файлы в папке `.data/` (она в `.gitignore`), база данных не нужна.

| Путь | Содержимое |
|---|---|
| `.data/package-library.json` | Библиотека пакетов и статистика передачи |
| `.data/installation-queue.json` | Очередь установки |
| `.data/ps4.json` | Последний IP приставки |
| `.data/ps4-service-keys.json` | Ключи сопряжения с PackageFlowService (по IP) |
| `.data/ps4-remove-operations.json`, `.data/console-*.json` | Задания удаления и управления приложениями на консоли |
| `.data/service-updates/` | Проверенные PKG обновлений сервиса |
| `.data/qbittorrent.json` | Настройки qBittorrent (**пароль хранится открытым текстом**) |
| `.data/search-providers.json` | Настройки Torznab (включая API‑ключ) |
| `.data/torrent-library.json` | Импортированные и автоустановленные торренты |
| `.data/package-cache/` | Кэш сканирования и извлечённые обложки; запись в исходную папку с PKG не требуется |

Чтобы полностью сбросить состояние, остановите сервер и удалите `.data/`. Сопряжение с PS4 после этого нужно будет выполнить заново.

## Обновить WEB

Сохраните `.data/` и исходные PKG. Остановите сервер, получите нужный релиз, установите зависимости и пересоберите `pnpm install && pnpm build`, затем запустите из корня проекта. Для Docker используйте [отдельную инструкцию](docker.md#обновление); сохраняйте том данных.

## Обновить приложение PS4

### На самой PS4 (с версии 1.82)

1. Откройте **«Настройки» → «Обновить»**, нажмите крестик. Служба проверит последний опубликованный стабильный релиз GitHub.
2. Если новая версия доступна, нажмите крестик ещё раз и подтвердите установку кнопкой **Options**. Круг отменяет подтверждение.
3. PS4 сама скачает PKG; в настройках отображается прогресс загрузки. После проверки пакет устанавливается фоновой службой: интерфейс автоматически закроется, затем новая версия запустится сама.

Для этого нужен интернет на PS4; WEB и сопряжение не требуются. Завершите установки и передачи файлов, оставьте PS4 включённой. Версия сравнивается по PKG службы, а не по тегу WEB. Старые и одинаковые версии не устанавливаются.

Обновлятор принимает `PackageFlowService-<версия>.pkg` из релизов `demagoc3-cpu/playstation_installer`, до 25 МиБ, с SHA-256 в метаданных GitHub. Проверяются HTTPS, размер, контрольная сумма, идентификаторы приложения и версия внутри PKG. При обрыве загрузки проверьте обновления повторно. Не отправляйте повторную установку при неопределённом результате; проверьте её через WEB.

### Через WEB

В **«О системе» → «Обновление PackageFlowService»** остаются проверка GitHub, загрузка локального PKG, установка и перезапуск. Перед заменой PKG закройте интерфейс PS4. Сопряжённый сервис используется для штатного обновления; **WEB → PyLoader** — резервный способ, когда служба недоступна. После установки запустите приложение и проверьте версию.

Чтобы впервые получить самостоятельный обновлятор, установите PKG **1.82** через WEB или вручную. Установка PKG не активирует HEN.

## Публичные кошельки

`NUXT_PUBLIC_DONATION_BTC` и `NUXT_PUBLIC_DONATION_USDT_TRC20` задают адреса пожертвований. Пустой адрес скрывает карточку. WEB передаёт адреса и QR приложению PS4; содержимое PKG не нужно менять.
