# Обновления, данные и настройки

[← Содержание](index.md) · [English](../en/updates-data.md)

## Где хранятся данные

Всё состояние — обычные JSON‑файлы в папке `.data/` (она в `.gitignore`), база данных не нужна.

| Путь | Содержимое |
|---|---|
| `.data/package-library.json` | Библиотека пакетов и статистика передачи |
| `.data/installation-queue.json` | Очередь установки |
| `.data/ps4.json` | Последний IP приставки |
| `.data/ps4-service-keys.json` | Ключи сопряжения с PackageFlowService (по IP) |
| `.data/ps4-remove-operations.json`, `.data/console-*.json` | Задания удаления и управления приложениями на консоли |
| `.data/service-updates/` | Проверенные PKG обновлений сервиса |
| `.data/qbittorrent.json` | Настройки qBittorrent (**пароль хранится открытым текстом**) |
| `.data/search-providers.json` | Настройки Torznab (включая API‑ключ) |
| `.data/torrent-library.json` | Импортированные и автоустановленные торренты |
| `.data/package-cache/` | Кэш сканирования и извлечённые обложки; запись в исходную папку с PKG не требуется |

Чтобы полностью сбросить состояние, остановите сервер и удалите `.data/`. Сопряжение с PS4 после этого нужно будет выполнить заново.

## Обновить WEB

Сохраните `.data/` и исходные PKG. Остановите сервер, получите нужный релиз, установите зависимости и пересоберите `pnpm install && pnpm build`, затем запустите из корня проекта. Для Docker используйте [отдельную инструкцию](docker.md#обновление); сохраняйте том данных.

## Обновить приложение PS4

В WEB → «О системе» доступны проверка и установка обновления службы. Закройте интерфейс PS4 перед заменой PKG. Сопряжённый сервис используется для штатного обновления; PyLoader остаётся резервным способом через WEB, когда сервис недоступен. После установки запустите приложение PS4 и проверьте версию службы. Следуйте состоянию задания, не отправляйте повторную установку при потерянном ответе.

Новая WEB логика отмены игры нужна для соответствующей кнопки в приложении 1.68: обновите обе части. Обновление PKG не активирует HEN автоматически.

## Публичные кошельки

`NUXT_PUBLIC_DONATION_BTC` и `NUXT_PUBLIC_DONATION_USDT_TRC20` задают адреса пожертвований. Пустой адрес скрывает карточку. WEB передаёт адреса и QR приложению PS4; содержимое PKG не нужно менять.
