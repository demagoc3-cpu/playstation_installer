# Один WEB для PS4 и PS5

## Что уже реализовано

В разделе **Устройства** можно добавить, назвать и сопрячь любое количество PS4 и PS5. Модель (Fat / Slim / Pro) задаётся при добавлении. Для каждого устройства отдельно сохраняется способ установки. Есть поиск, фильтры **Все / PS4 / PS5 / В сети**, статус соединения и свободное место, если сервис его прочитал.
Для PS5 проверяется собственный PackageFlow API на порту **8095**; код сопряжения
содержит шесть цифр. Сохранённый токен остаётся на сервере WEB и не возвращается
в браузер или каталог.

Библиотека общая. Исходные файлы остаются в своих папках. Фильтры **Все / PS4 / PS5**
применяются на сервере перед пагинацией. Поиск работает по всей выбранной части
библиотеки и возвращает комплект игры, даже если совпал только патч или DLC.

| Выбранная приставка | «Все» в библиотеке | Установка в текущей реализации |
| --- | --- | --- |
| PS4 | Общая библиотека PS4 и PS5 | Существующий PackageFlowService или PyLoader |
| PS5 | Общая библиотека PS4 и PS5 | PKG через собственный ELF при подтверждённой готовности маршрута |

Явный фильтр позволяет просмотреть другую платформу. Он не разрешает установку
PS5-контента на PS4. Возможность установки определяется отдельно от возможности
показать файл: учитываются сервис, сопряжение и поддерживаемый формат. Совместимость
конкретной игры и её запуск также требуют проверки на нужной прошивке.

## Распознавание содержимого

Платформа и формат читаются из заголовков и метаданных, а не из названия файла.
Для PS4 используются CNT/PARAM.SFO. Для PS5 — FIH/CNT и PARAM.JSON либо содержимое
образа. В интерфейсе рядом с названием показаны платформа и формат.

| Содержимое | Что читает сканер |
| --- | --- |
| PKG PS4 | Прежний разбор CNT/SFO |
| PKG / FPKG PS5 с открытыми метаданными | FIH и таблица CNT; признак debug/retail в заголовке |
| Folder PS5 | `eboot.bin`, `sce_sys/param.json`, размер файлов, обложка |
| UFS2, exFAT | Метаданные и обложка из образа |
| PFS, FFPFSC | Незашифрованный PFS и поддерживаемые сжатые PFSC-блоки |

Распознаются расширения `.pkg`, `.fpkg`, `.ffpkg`, `.ufs2`, `.exfat`, `.pfs`,
`.ffpfs`, `.ffpfsc`; итоговый формат определяется содержимым. Проверено чтение
всех перечисленных контейнеров на наших тестовых приложениях.

Ограничения: пока поддержана базовая категория PS5 `applicationCategoryType = 0`.
Неизвестные категории, закрытые метаданные и неподдерживаемые варианты шифрования
не превращаются автоматически в «игру». Метка FPKG описывает заголовок и не является
проверкой криптографической подписи или гарантией запуска. Образы не монтируются и
не распаковываются целиком при индексации.

На стенде PS5 Slim 13.60 проверено чтение реальных FFPFSC ANIMAL WELL
(`01.000.011`) и Hades II (`01.006.000`). Сканер поддерживает непрерывное
размещение с пустыми indirect-слотами `0` или `UINT32_MAX`, а также разбросанные
direct/indirect-блоки. Недопустимые указатели и выход за лимит чтения отклоняются.
Чтение метаданных не подтверждает целостность всего образа или его запуск.

## Состояние каждой приставки

- Очередь, история, отмена и отметки установки разделены по адресу профиля.
- Смена выбранной приставки не перенаправляет уже запущенный worker очереди.
- При переключении сбрасывается выбор пакетов в браузере; запоздавшие ответы
  предыдущей приставки не подменяют её состояние.
- Автоустановка торрента закрепляет адрес получателя при включении. Для PS5 она
  пока недоступна; обычное скачивание доступно.
- Старые глобальные отметки и очередь принадлежат прежней PS4. При миграции её
  адрес сохраняется в `legacy-console.json`; новым приставкам эти отметки не копируются.
- Для скачивания PS4 адрес получателя включён в путь манифеста и файла:
  `/ps4/manifest/<IP>/<id>.json` и `/ps4/package/<IP>/<id>.pkg`. Полный URL
  заканчивается расширением, без параметров после него: BGFT может отклонить
  адрес `.json?console=…` с CE-32942-0 / `0x80990033`. Старый `/json/<id>.json`
  остаётся доступен. HEAD возвращает размер без передачи файла; Range сохраняется.
- Пресеты остаются общими; их состав, количество файлов и размер при просмотре
  учитывают совместимость с выбранной приставкой. Экспорт сохраняет платформу и формат.

В текущей версии адрес и платформа существующего профиля неизменяемы. Для стенда
рекомендуется закрепить IP приставки в DHCP. Перенос профиля между адресами с
проверкой идентичности консоли предстоит реализовать отдельно.

## Контракт для приложения PS5

`GET /api/catalog/v2?consoleId=<id>&offset=0&limit=20&q=...`

Возвращает страницу каталога, `schemaVersion: 2`, получателя, платформу консоли,
платформу/формат/признак подписи каждого пакета и подтверждённые возможности сервиса.
Идентификатор ветки включает платформу. Каталог PS4 `/api/catalog/v1` сохранён;
в него не попадают PS5-файлы.

`GET /api/catalog/v2/status?consoleId=<id>` обновляет состояние приставки
даже без открытой вкладки WEB. Параллельные запросы используют общий кэш
проверки соединения на 15 секунд. На реальном стенде проверены online/paired,
каталог обеих игр, поиск, избранное, пресеты и загрузка обложек. Установка PS5
остаётся недоступной, пока собственный backend не подтверждён.

Профили: `GET/POST /api/consoles`, `POST /api/consoles/active`, `/probe`, `/pair`.
Установка для одного клиента/приложения: `POST /api/consoles/install`; сервер разрешает идентификаторы пакетов
и получателя самостоятельно. Для PS5 добавлена отдельная сохранённая очередь;
перед первой передачей проверяются сопряжение и подтверждённые возможности
сервиса для всего набора. Для PS5 готовность конкретного маршрута PKG читается
из авторизованного `/api/v1/install/readiness`. Недоступный установщик, неизвестная
версия или непроверенная прошивка дают отдельную причину отказа. Сопряжение и
показ каталога при этом сохраняются. Перед чтением и передачей большого файла
драйвер снова проверяет готовность. Установщик PS4 для PS5 не вызывается.

Задания: `GET /api/consoles/installation`, `GET /api/consoles/tasks` с consoleId;
`POST /api/consoles/tasks` с action `cancel`/`clear`. Отмена может содержать
packageIds или branches; без них убирается вся ожидающая очередь. Принятое
системное задание без подтверждённой операции отмены не останавливается.

Приложение PS5 использует `POST /api/catalog/v2/command`, получает результат
через GET того же маршрута по consoleId и id. RequestId сохраняется до выполнения:
повтор читает результат, изменение состава с тем же номером даёт 409. Поддержаны
выбор пакетов/веток, пресеты, избранное и управление заданиями. Переустановка
с удалением пока отклоняется.

Очередь сохраняется отдельно на каждую PS5: игра → патчи → DLC, история десяти
очередей, очистка завершённых/ошибок. После ошибки базовой игры зависимые пакеты
пропускаются. Транспорт PKG подготовлен через собственный API: блоки до 4 МиБ по ответу службы (256 КиБ для прежних версий),
BLAKE3 с обеих сторон, докачка и проверка неизменности исходника. Системное
намерение сохраняется до отправки; восстановление читает `/api/v1/install/status`
и не повторяет неизвестную установку. Передача файла не означает подтверждение
установленной версии. Неопределённый результат останавливает продвижение очереди.

## Следующий этап PS5

Каталог и команды подключены к нативному приложению. Собственные обработчики
передачи и установки PKG уже существуют; проверка готовности связывает их с WEB.
Следующие этапы — аппаратная проверка этой интеграции, подтверждение конкретного
компонента и версии, адаптер образов/папок, затем фон и жизненный цикл.
Успешные тесты игр через ShadowMount сохраняются. Они подтверждают прежний
маршрут, но не ещё не реализованный адаптер образов внутри нашего ELF.

Проверки WEB: сборка Nuxt, 31 сценарий прежней очереди, смешанная библиотека,
две одновременные очереди, миграция отметок, автоустановка с закреплённым получателем,
пагинация 2800 пакетов и поиск комплекта игры. Обновлённый API PS5 проходит host-тесты
и собирается в ELF; его установка и новый контракт на приставке ещё не проверялись.

## Нативный Preview PS5

Приложение PS5 `01.000.004` использует `/api/catalog/v2` для чтения каталога,
страниц, поиска и избранных веток. Конфигурация скачивается в «Устройства → Подключение →
Конфигурация приложения PS5»: указать **IP компьютера с WEB**, порт
и выбрать профиль PS5. В файле нет ключей сопряжения. Это подключение приложения
к библиотеке; сопряжение фонового API на 8095 выполняется отдельно.

Каталог принимает `favorites=ps5:PPSAxxxxx,ps4:CUSAxxxxx` (до 512 веток),
`favorites=none` для пустого избранного и обычные `q`, `offset`, `limit`.
Проверяется профиль, платформенная совместимость сохраняется. Поиск продолжает
искать по целым веткам, в том числе среди выбранного избранного.

Новый сетевой UI собран и проверен с реальным ответом WEB на компьютере.
Запуск на приставке, ввод и сохранение настроек будут проверены отдельно.

## Установка сразу на несколько устройств

Любая установка из библиотеки или пресета открывает таблицу получателей. Можно выбрать несколько приставок: видны их имена, типы, модели, свободное место и причины недоступности. Проверяется **весь** набор, включая патчи и DLC. При несовместимости галочка недоступна; файлы не пропускаются молча. Перед запуском WEB повторяет проверки выбранных устройств. Если одно не прошло проверку, набор не отправляется ни на одно из них.

После проверки запускается отдельная очередь на каждой приставке. Новые файлы добавляются к работающей очереди, повторяющиеся задания не отправляются заново. Базовая игра идёт перед патчами и DLC; изменение открытого устройства не меняет адрес работающих очередей. Ошибка одного получателя не отменяет установки у остальных.

В **Заданиях** первым уровнем идут устройства, внутри — прежнее дерево игр или таблица с фильтрами категорий и пагинацией. Есть отмена пакета, всей ветки или очереди конкретного устройства, а также очистка завершённых заданий и ошибок. Активные устройства раскрываются автоматически, но пользователь может свернуть их. Очистка всех списков сохраняет работающие и ожидающие задания. qBittorrent отображается отдельно от очередей приставок.

В общей библиотеке вместо прогресса и ошибок показываются имена устройств, на которых устанавливается игра, и отдельные отметки установленных файлов по устройствам. Источник поиска и пагинации общий; выбранное устройство не скрывает игры другой платформы. Сводка не загружает в браузер весь список пакетов каждой консоли: отметки запрашиваются только для открытой страницы, а задания — для раскрытых устройств.

### API и повторные запросы

- `POST /api/consoles/refresh` — обновить подключения (не более восьми одновременных проверок; повторные проверки объединяются).
- `POST /api/consoles/install-preview` — разрешить набор из идентификаторов, полного выбора библиотеки или пресета и проверить получателей.
- `POST /api/consoles/install-batch` — `requestId` (32 hex), `selection: { packageIds }`, `consoleIds`. Результат раздельный для каждого устройства.
- `GET /api/consoles/install-batch?requestId=…` — получить результат без повторной отправки установки.
- `GET/POST /api/consoles/activity` — компактные сводки очередей; POST принимает только идентификаторы файлов текущей страницы.
- `POST /api/consoles/tasks` — адресовать очистку/отмену через `consoleId`; `queueId` защищает от отмены уже сменившейся очереди.

До отправки очередей сохраняется запись общего запроса. Повтор того же `requestId` возвращает прежние результаты; другое содержимое с этим ID отклоняется. После перезапуска WEB незавершённый запуск помечается как требующий проверки, без автоматической повторной команды. История запросов сохраняется на диске WEB.

Свободное место — результат последней проверки, не резервирование диска. Оценка учитывает текущую очередь, резерв PS4 и два размера исходного PKG для PS5; точный размер установленного содержимого может отличаться. Если сервис не вернул сведения, показывается «Не определено». Модель пока вводится вручную.

Параллельная установка без лимита устройств предусмотрена через **PackageFlowService**. Старый PyLoader имеет одну общую сессию и обслуживает одну приставку за раз; несколько получателей с PyLoader в одном запуске отклоняются. Для PS5 WEB проверяет готовность конкретного маршрута и совместимость всего набора. Подтверждённый PKG или Folder доступен для выбора; неизвестный формат остаётся недоступным. Сопряжение и просмотр каталога не зависят от готовности установки.

Проверки: сборка WEB, реальные очереди production-кода с имитацией ответов двух PS4, проверка совместимости PS5, отсутствие повторной отправки, изоляция отмены и отметок установок, восстановление незавершённого запроса. Новый авторизованный ответ PS5 `/api/v1/system` собран в ELF; проверка на самой приставке ещё предстоит.

## Текущая интеграция Folder и управление приложением

PS5 Folder использует ту же очередь устройства, что и PKG. WEB проверяет каждый
файл BLAKE3, передаёт его с докачкой и сохраняет план папки. Служба проверяет
комплект, собирает временную папку и публикует её целиком. Существующий title
не перезаписывается. Пока копии передачи сохраняются, требуется два размера папки.

Folder допускается отдельно от PKG, только для базовых игр PS5 на проверенной
прошивке 13.60. Образы, Folder-патчи/DLC и PS4 Folder этим маршрутом не разрешаются.
Регистрацию опубликованной папки выполняет установленный ShadowMount. До её
подтверждения задание остаётся в работе; полная передача сама по себе не завершает его.

Подтверждение Folder связывает манифест, исходную папку службы, точные метаданные
в appmeta и постоянную ссылку установленного title на эту папку. Временное
подключение, создаваемое при запуске игры, не требуется. Проверка регистрации
не является проверкой игрового запуска. Для PKG автоматическое подтверждение
базовой игры остаётся отдельным; точное подтверждение патчей и DLC ещё не реализовано.

В карточке устройства PS5 доступны запуск и закрытие закреплённой версии
PackageFlow. Сервер проверяет её Title ID и хеш метаданных, служба закрывает
только соответствующее приложение. Неизвестный результат не вызывает повторной
команды. Установка из WEB работает при закрытом приложении, если фоновая служба
доступна. Закрытие при обновлении службы пока остаётся отдельным действием.
