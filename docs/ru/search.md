## Поиск через Torznab (Jackett / Prowlarr)

Раздел **«Поиск»** в боковом меню работает с любым Torznab‑совместимым API.

1. Установите [Jackett](https://github.com/Jackett/Jackett) или [Prowlarr](https://github.com/Prowlarr/Prowlarr) и добавьте в него трекеры, которыми вы имеете право пользоваться.
2. Скопируйте **Torznab URL** индексатора и **API‑ключ**:
   - Jackett: `http://127.0.0.1:9117/api/v2.0/indexers/<indexer>/results/torznab/`
   - Prowlarr: `http://127.0.0.1:9696/<id>/api`
3. В PackageFlow: **Источник** → название, URL, API‑ключ и категории → **Сохранить**. По умолчанию указана категория `1180` (PS4). Другие категории вводятся через запятую; пустое поле означает поиск по всем платформам. При изменении настроек пустое поле API‑ключа сохраняет прежний ключ.
4. Введите запрос → **Найти** → **Скачать** у нужного результата (уйдёт в qBittorrent, с учётом галочки «Установить после загрузки»).

Показывается до 40 результатов с размером и количеством сидов.

Первый запрос к трекеру может выполняться дольше повторного: WEB ожидает ответ до 60 секунд. Ошибки API‑ключа или ответа Torznab показываются как ошибка поиска, а не как отсутствие результатов.

## Карточки результатов

Результаты отображаются карточками. Выберите карточку, чтобы увидеть размер, сиды и личеры, дату, источник и полное название раздачи. Метки версии, языков и Backport берутся из названия; это сведения автора, а не результат проверки PKG.

При открытии приложение загружает описание и обложку со страницы раздачи, если источник передал ссылку. Если страница требует входа или недоступна, сведения из Torznab остаются доступны. Для RuTracker используется локальный FlareSolverr при блокировке прямого запроса; адрес можно задать переменной `PACKAGEFLOW_FLARESOLVERR_URL` (по умолчанию `http://127.0.0.1:8191`).

«Скачать» передаёт раздачу qBittorrent. «Скачать и установить» дополнительно включает существующую автоустановку PKG через PackageFlowService после загрузки. Открытие карточки не запускает скачивание.
