# Файлы и корзина

[← Содержание](index.md) · [English](../en/files.md)

## Файлы в приложении PS4 (1.72)

Для раздела **«Файлы»** нужны запущенный WEB с новым API и подтверждённое сопряжение. На PS4 доступны просмотр папок, создание папки, копирование файла или папки, переименование, безвозвратное удаление, редактирование текста и установка локального PKG. Используется тот же сервис и журнал операций, что в WEB.

- **Крестик** открывает папку; на файле переводит фокус на действия. **Вправо** из списка — к кнопкам, **вниз** с кнопок — к списку.
- **Круг** переходит в родительскую папку; из корня возвращает фокус в меню. **L1 / R1** переключают страницы папки; на первой странице L1 также поднимается вверх. **Квадрат** обновляет список, **треугольник** открывает ввод пути.
- Для копирования выберите элемент → **«Копировать»**, откройте папку назначения → **«Вставить»**. Копируется один выбранный элемент вместе с содержимым папки.
- Создание папки и переименование используют штатную клавиатуру PS4.
- **«Удалить»** показывает подтверждение: Options удаляет, круг отменяет. Корзина и предыдущие версии доступны в WEB. Если папка содержит защищённую предыдущую версию, сначала удалите эту копию через корзину WEB.
- **«Редактировать»** открывает текст UTF-8 до 128 КиБ. Выберите строку, нажмите крестик и измените её на клавиатуре. Квадрат вставляет строку, треугольник удаляет строку в редакторе. Options открывает подтверждение сохранения, крестик подтверждает. При выходе с несохранёнными изменениями появляется отдельный запрос. Очень длинные строки редактируйте в WEB.
- **«Установить»** проверяет PKG, прошивку и место на диске; установка начинается после подтверждения крестиком. Исходный PKG остаётся в папке. Результат и отмена также доступны в WEB → «Файлы».

Запись разрешена только в `/data` и на USB; системные области доступны для чтения. При потере ответа приложение проверяет прежний идентификатор задания и не отправляет повторную команду автоматически. WEB должен продолжать работать во время файловой операции. Предпросмотр ПК разрешает чтение и проверку PKG, а изменения файлов и установка в нём отключены.

### Файлы

Проводник по каталогам PS4:

- **скачивание** файла на ПК (поддерживается докачка);
- **загрузка** файла в `/data` или на USB‑накопитель (`/mnt/usb0`–`/mnt/usb7`) с кнопкой **«Пауза»**: повторный выбор того же файла продолжит передачу с места остановки, даже после перезапуска сервиса.

**Начиная с PackageFlowService 1.52** доступны:

- создание папок, переименование и выбор нескольких элементов;
- копирование и перемещение файлов и папок: выберите элементы, нажмите **«Копировать»** или **«Переместить»**, откройте папку назначения и нажмите **«Вставить сюда»**;
- фоновое копирование с прогрессом, паузой и продолжением после обрыва связи. WEB должен работать во время передачи; после его перезапуска прежняя операция доступна для продолжения;
- удаление в **корзину** и возврат на прежнее место, если имя свободно;
- загрузка с заменой существующего файла после подтверждения; предыдущая версия сохраняется;
- редактор текстовых файлов UTF-8 до 128 КиБ (TXT, JSON, INI, CFG, CONF, XML, YAML, LOG, CSV, MD). Перед сохранением проверяется, что исходный файл не изменился; предыдущая версия остаётся в корзине.

Запись доступна внутри `/data` и USB. Файлы самого сервиса, ключ сопряжения и незавершённые передачи защищены. Символические ссылки не копируются и не изменяются. Игры удаляйте через **«На консоли»**, а сохранениями управляйте в **«Сохранениях»**.

Корзина и предыдущие версии остаются **на PS4 и занимают место**. Их список и журнал операций находятся в данных WEB (`.data/console-files`), поэтому сохраняйте этот каталог или Docker volume. Для возврата копии с USB нужно подключить исходный накопитель. Перемещение между дисками сначала копирует данные, затем оставляет исходник в корзине; внутри одного диска используется переименование.

**Начиная с PackageFlowService 1.54** PKG, уже лежащий в `/data`, `/user/data` или на USB, можно установить прямо из проводника: нажмите **«Установить»** возле файла, проверьте сведения и выберите **«Установить на PS4»**. WEB читает метаданные частями и проверяет прошивку, размер файла и свободное место. Установка выполняется на консоли без повторной передачи PKG через компьютер; исходный файл остаётся в папке. Ход установки и отмена доступны на странице, результат — в «Истории операций». Во время установки исходный PKG и содержащую его папку нельзя изменить через сервис.

На прежних версиях службы просмотр, скачивание и загрузка новых файлов остаются доступны; новые операции включаются после проверки файлового API. Загрузка PKG в проводнике сама по себе не запускает установку.

**Начиная с PackageFlowService 1.55** доступны кнопки **«Удалить»** для выбранных файлов и папок, **«Удалить»** у каждой копии в корзине и **«Очистить корзину»**. Перед удалением WEB показывает список и просит подтвердить, что элементы будут удалены безвозвратно. Папки удаляются вместе с проверенным содержимым; служебные файлы, ссылки и текущий устанавливаемый PKG защищены. После обрыва связи прежнее задание можно продолжить из истории. Частично удалённую копию из корзины вернуть нельзя.

Загрузка через «Файлы» в 1.55 использует фрагменты до **4 МиБ** вместо 256 КиБ, сокращая количество запросов и принудительных записей на диск. Пауза и докачка сохраняются. На прежних службах WEB продолжает передавать по 256 КиБ.

**В версии 1.57** Исправлено распознавание полных PKG, объединяющих игру и обновление (remaster), при установке с диска. WEB сохраняет исходную причину отказа новой команды вместо сообщения о прежнем задании. Служба сохраняет основной и резервный снимки журнала установок; если основной повреждён, загружает проверенный резервный без повторной отправки команд. При повреждении обеих копий установка блокируется. Проверена установка Stray CUSA24899 версии 01.04 с диска PS4.

С 1.69 установка из «Файлов» также поддерживает приложения `PS4GDE`.
