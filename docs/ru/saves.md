# Сохранения

[← Содержание](index.md) · [English](../en/saves.md)

WEB → «Сохранения» показывает пользователей, игры и слоты сохранений подключённой PS4. Для операций нужен запущенный и сопряжённый PackageFlowService.

1. Выберите пользователя, игру и слот. Перед изменением сохранений закройте игру.
2. Создайте копию слота или «Создать копию игры» для всех слотов. Копии можно скачать в ZIP на компьютер.
3. Нажмите «Восстановить» у ранее созданной копии. Текущий сейв сначала сохраняется для отката.
4. Запустите игру, проверьте прогресс и выберите «Игра читает сейв» для подтверждения либо «Вернуть прежний» для отката. Перед откатом закройте игру. Подтверждение удаляет временный откат на PS4; скачанные копии остаются.

Не отключайте PS4 и не закрывайте WEB во время операции. При обрыве связи проверьте состояние прежде, чем повторять действие. Сохраняйте данные WEB и скачанные архивы при обновлении. Удаление игры в «На консоли» не удаляет её сохранения.

Не переименовывайте слоты вручную через «Файлы». Это резервное копирование/восстановление поддерживаемых файлов, а не универсальная конвертация между чужими аккаунтами и версиями игр.
