Не создавать красивый отдельный demo вместо приложения PackageFlow.

Проверить и сохранить:

1. Каталог WEB v2: точный consoleId/platform/schema, полнота пагинации,
   10/20/30/таблица, фильтры/сортировка, ветки игры/патчи/DLC и их счётчики.

4. Избранное до прежнего лимита, хранение конфигурации и пресеты:

## Дизайн и бренд

Все правила DESIGN.md обязательны. Главный визуальный ориентир — крупные
обложки, тонированное стекло, глубина, спокойные сине-фиолетовые поверхности,
чёткий focus и полноэкранная композиция. Служебные экраны не превращать в ASTRO рекламу.

Использовать только исходные PF logo/wordmark/иконку. В картинках есть generic P,
неверные WEB-пункты и условные значения — их НЕ повторять. На нативном экране
10 текущих пунктов ui_menu_order; поиск через △. Отдельный WEB обслуживает PS4+PS5,
PS5-приложение работает со своей сопряжённой PS5, не управляет чужими PS4.

## Этапы

1. Инвентаризация + тесты baseline. Предложить рендер-путь, совместимый с нашим
   подписанным SELF/runtime/VideoOut. Можно добавить renderer abstraction и
   изучить GPU backend, но не переписывать сеть/модель. Лицензии зависимостей
   зафиксировать; SDK/чужие бинарники/фирменный runtime игры не копировать.
2. Рабочий prototype внутри приложения: стекло, обложки, шрифт, focus, скролл.
   UI остаётся отзывчивым без сети и при медленной обложке. Ограниченный cache,
   нет disk/network/decode в frame. Цель 60 fps — подтвердить аппаратно; не обещать
   fps на основании host-теста. Размытие кешировать/уменьшать в разрешении.
3. Перевести ВСЕ 10 разделов, карточки, модалки, IME overlay, сведения, filters,
   install-review, error/offline/loading/empty, about и поддержку. Общие компоненты
   должны держать единый язык с WEB, не WEB viewport/menu на телевизоре.
4. Полный regression checklist, SDK/imports/build, отдельный кандидат с прежними
   Title ID/Content ID/названием. Не перезаписывать stable artifact.

Новые backend-функции «На консоли» (регистрация/права/редактор) добавляет Codex
по отдельным проверяемым контрактам. Если их ещё нет, сохранить текущий доступный
экран и объяснение; не вызывать напрямую ps5upload/Sony/ShadowMount из приложения.
