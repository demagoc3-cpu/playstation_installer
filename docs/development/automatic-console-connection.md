# Подключение без кода — 2026-10-11

По прямому указанию пользователя удалён PIN из WEB и Windows. Выбранная приставка подключается кнопкой «Подключить», а первоначальная установка PS5 подключает работающий ELF и продолжает установку приложения без отдельного шага с кодом. Авторизация команд Bearer сохранена, ключ не возвращается интерфейсу. Первое подключение проверяет идентичность службы и pairingMode=automatic. Старые службы без нового режима показывают требование обновить службу; код не запрашивается.

PS5: health и pair используют pairingMode=automatic; POST pair — заголовок X-PackageFlow-Pairing-Mode: automatic, без тела. 64 hex ключ сохраняется в WEB. Служба сохраняет новый ключ до ответа; повторное подключение возвращает прежний. Режим проверен на Slim 13.60, другие прошивки этим изменением не добавлены.

PS4: GET install/capabilities должен сообщать pairingMode=automatic. POST install/pair принимает JSON {mode:automatic}, возвращает service=PackegeFlowService, paired=true, pairingMode=automatic и прежний 32 hex token. Реализация службы/нативных приложений поручена Клоду в PS-APPS-022. До его нового PKG уже сохранённые соединения работают; новая служба требуется для первого подключения без кода.

Установка собственного PS5 PackageFlow отличает запись старого экземпляра без доступного источника от подтверждённого присутствия приложения. Восстановление ограничено ровно одним собственным образом PPSA95001 / IV0000-PPSA95001_00-PACKAGEFLOWUI001 и текущим отпечатком данных PS5; состояние повторно проверяется в очереди. Общая перезапись образов не разрешается, защита ELF от существующих файлов/метаданных сохраняется. Неизвестный/чужой источник не считается отсутствующим. Итог аппаратной проверки восстановления дописывается после испытания.

Проверки: шесть серверных интеграционных файлов — PASS; host make test и SDK ELF — PASS; сборка Windows — PASS; на Windows GAMEPAD-PC проверка интерфейса (16 сценариев) — PASS, включая автоматическое подключение/однократное продолжение установки и отсутствие поля кода. Прямые подключения нового ELF на PS5 без PIN подтвердили сохранность прежнего ключа и имя процесса PackageFlow.elf. Код в приложения ещё убирает Клод; новый кандидат приложений не собирался Codex.

## Сквозная проверка и комплект — 2026-10-12

Клод сдал PS-APPS-022: PS4 служба `4f7592d`, интерфейс `c1ffcdd`, кандидат 2.06; PS5 интерфейс `2ccf314`, версия `ac5c8a7`, кандидат 01.000.042. Исходники нативных приложений Codex не менял. Договор PS4 JSON/без Origin повторно сверён с WEB. Аппаратная проверка PS4 2.06 пока не выполнена.

Комплект Windows 1.10.8 обновлён: ELF 015k, PS4 2.06, PS5 UFS2 042. Артефакты проверены размером и SHA256 перед упаковкой. Установщик: `82a10d6b87a0763a1568e7d9ac934bfaec0cecbdef4fcc9cc3105485facbdb74`. Исполняемый мастер: `26c505757e5bd96abf80264ba314926c329c2c6fa5152111e91f8c611e8cee19`.

На GAMEPAD-PC обновлена именно установленная копия `%LOCALAPPDATA%\Programs\PackageFlow\PackageFlow.exe`; хеш проверен. Запуск — из установленного каталога, не тестовой копии. При отказе штатно закрыть прежнюю копию NSIS теперь возвращает код 2; тихий режим не оставляет модальное окно и не сообщает ложный успех.

Автоматический POST подключения из Windows WEB к настоящей PS5 13.60 подтверждён: код не передавался, профиль подключён; повтор прямого подключения ELF сохранял прежний ключ. Перед аппаратными действиями проверялись очередь и процессы приложений. Собственный Preview 007 оставил регистрационные каталоги; идентификаторы, версию 007, ссылку и допустимый состав файлов проверили. Эти каталоги сохранены в отдельной резервной папке вне `user/app` и `user/appmeta`; исходник Preview и пользовательские игры не удалялись.

Полная установка 042 **НЕ подтверждена**. Единственный запрос сохранился в журнале, установка остановилась перед передачей данных. В каталоге передачи обнаружен пустой `.part` без состояния. FTP подтвердил `550 No space left on device` даже при записи 31 байта в `/data`. Сохранился старый отказ публикации Folder на этапе `copy-file`, `systemError=28`; его план относится к Avatar PPSA01576, 188 587 020 676 байт. Очистка этих временных данных запрошена у пользователя отдельно; автоматического удаления кэша/игр не было.

Диагностический ELF 015l прошёл host-тесты и SDK, добавляет системный код отказа передачи и отдельное `transferFreeBytes`. Передан однократно, но запуск не подтверждён: собственного процесса и порта 8095 нет, менеджер и ELF-загрузчик доступны. Повторной отправки не было. Эта сборка в Windows-комплект не включена; комплект содержит аппаратно проверенный 015k. После освобождения места необходимо восстановить нагрузку, повторно проверить подключение и завершить установку/проверку интерфейса 042. Отсутствие места в `/data` не позволяет считать текущую аппаратную сессию рабочей.
