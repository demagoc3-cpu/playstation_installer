## 1. Единое название и обновление существующего приложения

- Не менять Title ID автоматически и не назначать новый ID каждой сборке. Сначала сообщить Codex существующие идентификаторы PS4 и PS5 и предложить постоянную идентичность релиза. Codex согласует маршрут обновления и проверяет регистрацию; смена названия сама по себе не является миграцией установленных копий.
- Не удалять прежние диагностические приложения и пользовательские данные в рамках этого задания.

## 2. Сведения по R3 на PS4

Использовать текущую рабочую реализацию PS5 как образец поведения, адаптировав её к интерфейсу PS4.

- При выделении игры показывать панель сведений; R3 скрывает и возвращает панель. При выделении конкретного пакета показывать его собственные сведения, не подменяя их данными базовой игры.
- Данные брать из действующего каталога WEB и `details`/пакетов: название, обложка, платформа, тип и формат, Title ID, Content ID, версия, размер, требуемая прошивка и другие доступные поля.
- PS4-пакеты показывать как PKG. Неизвестную прошивку, подпись или другое отсутствующее поле обозначать как неизвестное, не выводить выдуманные значения.
- Обеспечить чтение длинных списков и строк; панель не перекрывает основные кнопки. Управление внутри панели явно подсказать пользователю.
- Сохранить счётчики патчей/DLC, выбор пакетов, избранное, пресеты, поиск и существующие действия установки.

## 3. Фильтры и сортировка PS4 по образцу PS5

В текущем PS5 интерфейсе L2 открывает управление платформой и порядком каталога. Перенести понятное пользователю поведение на PS4:

- Название А–Я: `sort=title-asc`.
- Название Я–А: `sort=title-desc`.
- Меньшие сначала: `sort=size-asc`.
- Большие сначала: `sort=size-desc`.
- Платформы: все, PS4, PS5, в соответствии с действующим договором каталога. Просмотр карточки PS5 на PS4 не разрешает установку PS5-пакета на PS4.

Сортировку и фильтр передавать в WEB до постраничной выборки: они действуют на всю библиотеку, а не на загруженную страницу. Проверить каталог, поиск и избранное; поведение пресетов определить по их существующей модели и описать в отчёте. При смене порядка сбрасывать смещение страницы и сохранять поисковый запрос. Размер для сортировки брать по тому же правилу, что действующий PS5/WEB, не выбирать произвольный патч.

Сохранить и проверить навигацию левым стиком, крестовиной и удержанием через границы страниц; отпускание останавливает повтор. Родную клавиатуру PS5 не заменять резервной без реального отказа системы.

## 4. Подготовка к Windows-мастеру — только договор с Codex

Windows-мастер будет открывать модальное окно найденных и сохранённых приставок. Поиск, добавление, сопряжение, проверка загрузчика, kstuff/ShadowMount, отправка ELF и установка приложения реализуются Codex. Claude не реализует эти проверки самостоятельно и не обращается напрямую к Sony API ради мастера.

Сообщить Codex требования приложения к первому запуску, подключению и обновлению. Сохранить существующий путь получения WEB от службы на PS5; ключ сопряжения не включать в приложение или сборку. Новые поля готовности использовать только после публикации согласованного API; сейчас не считать их уже существующими.

Для упаковки передать отдельно для PS4 и PS5: готовый артефакт, платформу, формат, Title ID/Content ID, версию приложения, размер, SHA256, проверенные прошивки и минимальные версии WEB/ELF. Отделить реальную совместимость от предположений; подтверждать запуск на приставках будет Codex.
