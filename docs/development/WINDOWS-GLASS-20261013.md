# Windows PackageFlow 1.10.13 — мастер и стеклянный интерфейс

Основа дизайна: утверждённые [четыре шага мастера](../design/windows-glass-20261013/01-wizard.png), [разделы](../design/windows-glass-20261013/02-launcher-sections.png) и [трей / предупреждение](../design/windows-glass-20261013/03-tray-exit.png).

## Реализация

- Общий Astro-фон из WEB, полупрозрачные тёмно-синие поверхности, градиентные кнопки и выделение фокуса. Оригинальный логотип PackageFlow сохранён. Пиктограммы и силуэты PS4/PS5 нарисованы кодом; сторонние наборы UI-иконок не подключаются.
- Мастер: две карточки выбора рядом; поиск и множественный выбор приставок; защищённые данные RuTracker или вход через браузер после подготовки; итоговый план. Торренты можно пропустить. Этот выбор сохраняется: qBittorrent, Prowlarr, FlareSolverr и Chromium не скачиваются и не запускаются автоматически при отказе.
- Пять разделов: «Главная», «Приставки», «Поиск», «Обновления», «Поддержать проект». Самостоятельного раздела загрузок нет; настройки qBittorrent находятся в «Поиске».
- Дополнительные параметры серверов и компонентов открываются с карточек. Прежние Docker Compose, сетевые адреса, ключи, ручной вход, выбор индексатора, папка qBittorrent и управление приставками сохранены.
- Сверху GitHub, 4PDA, язык и состояние четырёх компонентов. Сопряжение и состояние конкретных приставок находятся в разделе приставок. Домашние карточки PS4/PS5 используют реальное число сохранённых и доступных устройств.
- Проверка Windows-обновления отделена от его скачивания и запуска. Проверка/обновление приставок включает службу и приложение для сохранённых PS4/PS5.
- Поддержка: реальные BTC и USDT/TRC20 адреса из настроек проекта, копирование и QR. QR кодирует соответствующий адрес; для BTC используется bitcoin URI.
- Трей: переключатель автозапуска с Windows. Обычное закрытие окна сворачивает в трей. Остановка/выход проверяют установки, файловые передачи, индексирование и активные торрент-задания PackageFlow. Отмена сохраняет работу. Подтверждение приостанавливает только торренты с меткой PackageFlow и останавливает принадлежащие приложению процессы; чужие загрузки не изменяются. Enter и Escape в предупреждении выбирают продолжение работы.
- Уже принятая приставкой установка может продолжиться на самой приставке после остановки WEB; предупреждение поясняет это.

## Проверки

Проверки выполняются на GAMEPAD-PC в отдельных временных каталогах; тестовые установки не отправляются на приставки.

- Core suite: миграция старых настроек, сохранение отказа от торрентов, защищённые загрузки, координатор PS4/PS5 — PASS.
- WEB desktop-control: занятость при индексировании и защита остановки — PASS.
- WEB desktop-runtime: запуск упакованного сервера и безопасная остановка — PASS.
- Windows runtime: Node + WEB, каталог PS4/PS5, launcher-авторизация, проверка встроенных артефактов, отсутствие установки торрент-компонентов при WEB-only настройке, отказ от остановки активной очереди без подтверждения — PASS.
- Windows UI: мастер и его переходы, сохранение полей при переключении языка, показ пароля, чекбокс в трее, отмена и подтверждение остановки, гонка запуска нового задания, остановка только торрент-заданий PackageFlow, доступность выбора приставок во время поиска, отмена поиска и закрытие окна при наблюдении за принятой командой.
- Компоновка проверяется на 964×721, 964×820, 1280×760 и 1880×940; кадры сохраняются для всех пяти страниц и мастера. При визуальной проверке исправлена перекрывавшаяся главная кнопка.

[Кадры реализации](../design/windows-glass-20261013/implemented/) получены Windows Forms DrawToBitmap с настоящих форм и контролов. Рабочий стол удалённой сессии недоступен для CopyFromScreen. Данные в UI-снимках изолированные тестовые; это не снимки установленной библиотеки пользователя.

## Комплект и ограничения

Windows кандидат: `dist/windows/PackageFlowSetup-1.10.13-x64.exe`. Окончательный SHA256 и результаты установки записываются в evidence рядом с отчётом.

В комплекте аппаратно проверенные PS4 2.14, PS5 ELF 026f и приложение PS5 01.000.042. Кандидат PS5 UI 01.000.044 / 5122c1f принят отдельно; его UFS2 SHA256 `18f64a693842d9136d7703377cd368a1a067fe760d87626b8ba949945e6806e6` совпал с отчётом агента. Версия 044 в Windows-комплект пока не включена: запуск, повторный запуск с меню PS5 и FPS ещё не проверены на аппаратуре.

Внешняя авторизация RuTracker, CAPTCHA и доступ провайдера не имитируются как успешный вход. Эти проверки требуют доступного сайта и действий владельца аккаунта; сохранены прежние реальные методы проверки и ручного входа. QR и карточки не заявляют фиктивных состояний онлайн/обновления.

WEB-репозиторий не коммитился и не отправлялся на GitHub в соответствии с указанием пользователя.
