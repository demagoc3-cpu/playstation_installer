# Восстановление управления PS5 — 2026-10-13

## Состояние

PS5 Slim 13.60 снова доступна. Пользователь сам запустил ShadowMountPlus
1.7-beta5fix1. Проверен кандидат `ps5-service-management-recovery-026e-sse2`,
версия `0.1.26-dev`, SHA256 ELF:
`7d46ab4796a5f27115271a59a624b184c8c86135d5bd2e6e7c424952f08c6188`.

## Причины и исправления

- WEB скрывал папки и образы при отсутствии отметки испытания команд, хотя
  чтение каталога уже работало. Полный каталог теперь читается независимо
  от разрешения на мутации. Неполный/повреждённый ответ не считается пустым списком.
- Getter большого приложения возвращает -1 на этом стенде. Добавлена сверка
  по полному каталогу зарегистрированных Title ID и проверка экземпляра.
  Неизвестная ошибка, пустая/неполная база, несколько экземпляров или несовпадение
  Title ID не означают простой.
- Клиент ShadowMount ожидал закрытия уже полностью прочитанного ответа.
  Завершение теперь определяется проверенным Content-Length.
- Старый фильтр версий принимал только ShadowMount 1.7beta3. Добавлено точное
  значение 1.7-beta5fix1 с API version 1 после сверки исходников и аппаратного чтения.
  Dirty-сборки и неизвестная версия API не принимаются автоматически.
- Диагностический JSON команды сохраняется при отказе.
- Подтверждение запуска отделено от изменения источников:
  `console-launch-tested-v1` включает consoleControl;
  `console-activity-tested-v2` включает consoleActivity.
  `consoleSourceControl` остаётся false без отдельного испытания исходников.
  WEB использует этот флаг для монтирования, удаления, копирования и перемещения.
  Для старых служб без нового поля сохраняется прежнее поведение.

## Сверка с ps5upload

Снимок пользователя соответствует 7.0.14. Дополнительно изучены исходники main
`01afdf8926ede277b8369b0f1976f44825d0de36` (7.0.22) в отдельной копии.
Исходники upstream не запускались на приставке.

- Регистрация использует метаданные sce_sys, bind исходной папки и Sony API;
  полной второй копии игры для этой операции не требуется.
- Исправление прав — отдельная явная операция; автоматический chmod 777
  всего дерева не является частью обычной регистрации.
- Редактирование образа требует checkout: журнал, перемещение на том же
  томе вне каталогов сканирования, ожидание освобождения ShadowMount,
  RW-монтирование, flush/unmount и возврат источника. Обычное монтирование
  RW без координации со сканером не воспроизводит этот механизм.
- У upstream есть ShellUI/ptrace-путь запуска с описанными рисками рестарта
  ShellUI. Он не переносился в PackageFlow.
- Upstream предупреждает о PS5 fake-game PKG выше 11.60. Это их аппаратное
  наблюдение, а не универсальная блокировка всех PPSA, retail, homebrew,
  папок и образов. Пока API не доказывает тип установленного PKG, блокировать
  запуск только по Title ID или пакету из библиотеки нельзя. Следующий
  аппаратный тест базового запуска выбирается в формате Folder/образа.

## Продолжение: запуск через LAN HTTP и установка, 2026-10-13

- На HTTP по IP/0.0.0.0 браузер не предоставляет randomUUID. Ошибка возникала
  до POST и до finally, оставляя acting=true. Команды игр, копий сохранений и
  восстановления теперь используют 128-bit crypto.getRandomValues. Генерация
  внутри try; при локальном отказе нет команды и опроса несуществующей квитанции.
- Перед запуском размонтированного управляемого Folder/образа WEB готовит
  только выбранный источник. У подготовки отдельный устойчивый requestId;
  при потере ответа не отправляет запуск и не повторяет mount.
- В root 026f Folder-монтирование не получает image-only mode:ro. Образы
  по-прежнему запрашивают ro. Полные HTTP 5xx от ShadowMount сохраняются как
  отказ, а не объявляются потерянным ответом. Форматы/сопряжение/128 MiB
  transfer pipeline не изменены.
- На PS5 восстановлен ранее проверенный отдельный Installer 1.4.0, SHA
  c0d208f2b340266bb0177622e60b1685ce9c7941ad51f95d808d764f50748f93.
  Готовы PKG, Folder, UFS2, exFAT, PFS и FFPFSC; доступность Folder/образов
  не зависит от готовности PKG в интерфейсе пресетов.
- PyLoader не запрашивает storage/system snapshot службы и не блокируется
  отсутствующим или старым freeBytes в preview, batch и окне установки.
  Для service проверки места и ограничения параллельной установки сохранены.
- Установлена стеклянная native UI b10e1ac с прежними метаданными 01.000.042;
  образ проверен по SHA256/roundtrip. Резерв прежнего образа сохранён вне
  сканирования. Первый запуск завершился CE-105773-3; после исправления
  подготовки пользователь подтвердил запуск Folder Stream Test и самого
  PackageFlow. Служба подтвердила текущий PPSA95001/appId 49176.
- Увеличение .bss исследовано отдельной копией 043 с direct-memory фоном.
  Host/SDK/import проверки прошли, но этот эксперимент на PS5 НЕ отправлен.
  Причина CE-105773-3 не доказана как проблема памяти. Канонический UI Клода
  не менялся; на PS5 остаётся подтверждённая b10e1ac.
- Ранее неопределённый запрос ASTRO не повторялся. Пользователь сам запускал
  ASTRO во время проверки; это не аппаратный тест, инициированный Codex.
- Astro Bot wallpaper создан image_gen и подключён к общей оболочке WEB.
