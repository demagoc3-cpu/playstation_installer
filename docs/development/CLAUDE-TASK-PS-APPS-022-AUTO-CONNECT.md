# Claude: PS-APPS-022 — подключение без кода

Дата: 2026-10-11. Прямое указание пользователя: полностью убрать код сопряжения из PS4 и PS5. Этот договор заменяет требования о коде в заданиях 019–021. Codex ведёт WEB, Windows и отдельный ELF; Claude — нативные приложения PS4/PS5 и необходимые изменения службы PS4. На приставки ничего не отправлять, push не делать.

## Результат для пользователя

В Windows/WEB пользователь выбирает найденную приставку и нажимает «Подключить» или «Установить». WEB проверяет, что отвечает нужная служба, автоматически получает её ключ, сохраняет адрес WEB на выбранной приставке и продолжает установку отсутствующего приложения. Никаких цифр, таймеров, уведомлений с кодом, кнопок «Новый код»/«Получить код». Удалённое приложение не должно быть обязательным условием подключения к уже работающей службе.

Ключи Bearer остаются: их сохраняют только служба и сервер WEB. В приложения, браузер, отчёт и журнал ключи не передаются. Повторное подключение возвращает существующий ключ и не меняет его: команды, загрузки и другие подключения не должны обрываться. При разрыве сопряжения явной командой ключ отзывается, следующий запрос подключения получает новый ключ. Самостоятельное переподключение после отказа пользователя не запускать.

## PS4: реализовать в службе и запускателе

1. GET /install/capabilities: сохранить service="PackegeFlowService" (именно существующее написание), installApi=1, authentication="bearer", ready/contentTypes/version и добавить pairingMode="automatic". Не объявлять новый режим до реализации.
2. POST /install/pair: JSON {"mode":"automatic"}. Код не принимать как необходимое условие; режим должен быть явным. Ответ 200: {"service":"PackegeFlowService","paired":true,"pairingMode":"automatic","token":"<32 строчных hex>"}. Ключ записать устойчиво до ответа; ошибка сохранения — ошибка API, без ложного успеха. Повтор возвращает тот же ключ; существующие ключи мигрируют без сброса.
3. Сохранить защиту от браузерных cross-origin записей, проверку JSON/метода/размера. Остальные install/apps/files/saves API по-прежнему требуют Bearer. /install/session сохраняет прежний договор. Не менять Sony API установки/удаления ради этого задания.
4. Удалить генерацию, отображение, срок действия и ввод кода из запускателя и экрана подключения. Показать состояние «Ожидаем подключения из WEB или Windows» / «Подключено», адрес WEB, IP приставки. Сохранить возможность явного разрыва подключения с отзывом ключа.
5. Первый запуск после установки через PyLoader должен поднять службу без предварительного кода и без чужого SERVER_URL. Адрес WEB затем приходит через существующий аутентифицированный files/bootstrap-договор Codex. Приложение не хранит Bearer и не запрашивает токен для себя.

## PS5: только нативный интерфейс

ELF меняет Codex. Новый договор ELF:
- GET /health: верхнее pairingMode="automatic"; остальная идентичность serviceReport/apiVersion/consoleVerified сохраняется.
- POST /api/v1/pair: без тела, заголовок X-PackageFlow-Pairing-Mode: automatic; ответ {apiVersion:"v1",pairingMode:"automatic",tokenType:"Bearer",token:"<64 hex>"}. Вызывает WEB, не приложение.
- GET loopback /api/v1/ui/status: pairingMode="automatic", paired bool, pairState=2 если подключено, иначе 0. Для старых клиентов pairCode="", pairSeconds=0. webHost/webPort/webConsoleId/webPaired и договор обновления сохранены.
- POST loopback /api/v1/ui/pairing/revoke сохраняется: разрыв и отзыв; busy возвращает 409. Старый renew возвращает 410, код не генерирует. /pairing/request больше не показывает уведомления с кодом.

Убрать «Новый код», поля кода, таймеры, сообщения об истечении/неверном коде. В «Подключения» оставить текущий WEB, статус и разрыв. Если ELF старый и pairingMode отсутствует, показать «Обновите службу PackageFlow из WEB или Windows»; не возвращать старый кодовый сценарий. После автоматического подключения ui/status должен подхватить новый адрес WEB и обновить каталог без перезапуска приложения. При отзыве очищать старое подключение/запросы штатно.

## Что сохранить

Постоянное название PackageFlow. PS4 PFLS00001/PFLS00002 и прежние Content ID; PS5 PPSA95001 / IV0000-PPSA95001_00-PACKAGEFLOWUI001. Версии увеличить от последних готовых 2.05 / 01.000.041. Сохранить родную клавиатуру PS5, R3 сведения пакета, сортировку/фильтр, счётчики патчей/DLC, непрерывное удержание стика/крестовины через страницы, очередь и отмену 019–021. Системные игры/старые диагностические экземпляры не удалять.

## Проверки и сдача

Host/SDK отдельно от аппаратных испытаний. Проверить первый запуск без приложения/ключа WEB; существующий ключ после обновления; повторное подключение без ротации ключа; потерю ответа подключения; явный отзыв и последующее новое подключение; неверный mode/метод/Origin; повреждённое хранилище ключа; выбранная приставка не меняется при работе с другой. Проверить отсутствие кода и секретов во всех UI, логах, артефактах. Прогнать прежние обязательные тесты и импорты SDK.

Собрать кандидаты в отдельных каталогах, не перезаписывать ELF и общий build/dist Codex.
