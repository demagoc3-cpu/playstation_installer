# Claude: PS-APPS-021 — завершение договора каталога и комплект Windows

Дата: 2026-10-11. Продолжение отчёта PS-APPS-020. Прочитай этот файл и выполни свою часть в нативных приложениях. WEB, Windows и ELF ведёт Codex. На приставки ничего не передавать, push не делать.

## Согласованная идентичность

PS4: сохранить PFLS00001/PFLS00002 и Content ID. PS5: постоянный PPSA95001 / IV0000-PPSA95001_00-PACKAGEFLOWUI001. Название в библиотеке — PackageFlow. Номер версии только в метаданных и «О приложении». Новые Title ID для каждого кандидата не создавать. Старые диагностические копии не удалять.

Подготовить следующий кандидат PS4 с версией выше уже проверенной 2.04 (2.05), PS5 с contentVersion 01.000.041. Пересобрать нативные приложения из исходников 020 в отдельных каталогах; не править ELF и общий build/dist.

## Каталог v1 — договор уже добавлен в WEB Codex

GET /api/catalog/v1:
- без platform — прежний каталог только PS4;
- platform=all|ps4|ps5 — фильтр до пагинации;
- sort=title-asc|title-desc|size-asc|size-desc; ответ содержит sort;
- capabilities.catalogFeatures = {schemaVersion:1,platformFilter:true,gameDetails:true,packageMetadata:true};
- games[].platform и games[].details — та же gameDetails, что v2;
- каждый packages[] содержит platform/format/signature/contentId/sdkFirmware/details;
- details конкретного пакета содержит его собственные данные и packageId, не сведения базы;
- ID веток v1 остаются прежними. schemaVersion остаётся 1.

Доработать чип платформы PS4: при наличии этой capability менять Все/PS4/PS5, передавать platform в каталог, поиск и избранное до пагинации. На старом WEB оставить PS4. На карточке PS5 в клиенте PS4 разрешить только просмотр: никаких install/install-reviewed, также смешанные наборы не отправлять на PS4. Полные сведения брать из details выбранного пакета; сохранить счётчики и управление 019/020. Проверить сортировку, поиск, избранное и непрерывное листание.

## Комплект для Windows

PS5 клиент получает адрес WEB из сопряжённого ELF через loopback ui/status. Никаких Bearer, ключей WEB, частных GitHub токенов и адреса тестового компьютера внутри приложения. Сначала мастер отправляет ELF, затем пользователь вводит код из уведомления PS5, потом установка приложения идёт через штатную очередь WEB/ELF.

Вернуть папку PPSA95001 с названием PackageFlow, версией 01.000.041, контрольные суммы eboot/param/libc и точный размер. Если есть существующий упаковщик образов — подготовить образ UFS2 или ffpfsc, не меняя содержимое игры и не включая тестовый конфиг; иначе сообщить путь папки, упаковку выполнит Codex. Сообщить формат, Title/Content ID, версию, SHA256 целого образа. Codex сверит PARAM и включит его вместе с ELF в проверенный манифест Windows. Не объявлять аппаратную проверку выполненной.

PS4: отчёт должен явно указать, как клиент первого запуска находит WEB до сопряжения. Если общий релизный PKG по-прежнему требует чужой вшитый SERVER_URL, не считать комплект для мастера готовым: описать требуемый bootstrap-договор, согласовать его с Codex, не вводить небезопасную запись адреса по произвольному внешнему запросу.
