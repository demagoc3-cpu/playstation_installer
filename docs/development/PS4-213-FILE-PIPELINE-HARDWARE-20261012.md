# PS4 2.13: аппаратные тесты файлового конвейера

12 октября 2026. PS4 Pro `10.1.10.32`, FW12.50, WEB `10.1.10.47:3000`. Служба `/system/info` подтвердила PKG2.13. Кандидат Claude `5ddbbbc`, SHA256 пакета `69ab2fe564109b6974f3da513dfeca3b38d44a795796f5f4594addf47c2eb135`; пакет ранее установлен через PyLoader. Установленный бинарник заново не извлекался.

Пользователь остановил Far Cry и разрешил тесты. Очередь WEB перед началом `completed`, единственная последняя попытка Far Cry `cancelled`; `/benchmark/info` busy=false. Список собственных заданий службы не содержал активной установки. Последняя пользовательская передача на скриншоте использовала PyLoader, поэтому она не измеряет сокеты файлового API службы. Новые установки в этой серии не отправлялись; ни PyLoader, ни BGFT не использовались для передачи тестовых файлов.

## PUT: sync / async / async / sync

Каждая серия: собственный UUID-каталог, 32 МиБ, случайный блок 4 МиБ повторён восемь раз. Запись через существующий WEB-клиент `consoleFileWrite`, затем finish. Скорость включает finish, исключает mkdir/start. Чтение всего файла проверяет SHA256. Порядок последовательный, без одновременных сетевых benchmark. Кэш диска не сбрасывался.

| Писатель / повтор | PUT + finish, МиБ/с | PUT, мс | finish, мс | write, сумма мс | fsync, сумма мс | max write, мс |
| --- | --- | --- | --- | --- | --- | --- |
| sync / 1 | 64.79 | 457.65 | 36.23 | 95.397 | 53.827 | 5.240 |
| async / 1 | 57.04 | 556.73 | 4.25 | 197.547 | 67.317 | 77.798 |
| async / 2 | 62.05 | 472.36 | 43.39 | 125.437 | 66.561 | 10.932 |
| sync / 2 | 74.99 | 408.06 | 18.66 | 78.529 | 30.764 | 14.803 |

Все восемь native PUT-записей в каждом запуске содержали complete=true, ровно4МиБ, writer соответствовал sync/async; незаметного отката async на sync не было. Асинхронный писатель не выиграл в этой ограниченной серии. По двум повторам нельзя объявить его всегда хуже: write/fsync различались, в первом async был выброс write77.8мс. Оставить sync штатным; async экспериментальным. Для следующего анализа полезны время ожидания свободного кольца, времени ожидания писателя и отдельная отметка готовности durable commit.

## Чтение: один и два клиента

Размер запроса4МиБ, восемь последовательных запросов на клиента. Для двух клиентов каждый прочитал весь32МиБ файл; скорость суммарная рассчитана по64МиБ и общему времени. Все SHA256 совпали.

| Серия | Один клиент, МиБ/с | Два клиента, суммарно МиБ/с |
| --- | --- | --- |
| sync /1 | 52.20 | — |
| async /1 | 49.39 | — |
| async /2 | 44.29 | 73.85 |
| sync /2 | 50.84 | 76.94 |

Писатель указан только как предшествующий режим загрузки файла, он не меняет алгоритм чтения. Результаты двух клиентов не означают74–77МиБ/с каждому.

Для восьми чтений одним клиентом native суммы: readMs46.6–49.1; отдача455–555мс; sendWaitMs448.9–551.2; loopSleepMs428.1–527.0; wouldBlock228–280. `sendWaitMs` считается от первого EWOULDBLOCK до следующего успешного send, поэтому включает сон цикла. Сон и ожидание **перекрываются**, их нельзя складывать или считать доказательством чистого ограничения сети. Для двух клиентов native журнал хранит только последние8 ответов, а всего их16; он не даёт полный счётчик64МиБ этой серии. Выигрыш суммарной скорости показывает, что44–52МиБ/с одного чтения не является общим пределом канала.

## short и локальный источник

Медианы20 последовательных запросов info: short2.22мс → baseline17.02мс → short1.99мс. Кандидат сохранил ожидаемый эффект короткого ожидания.

Far Cry в текущем индексе WEB действительно указывает на `/home/developer/Documents/Far Cry New Dawn Repack [FR_107].pkg`,19683540992байта. `findmnt` показал локальный `/dev/sda2`, ext4. Чтение по256МиБ в начале/середине/конце с тем же1МиБ буфером, что у выдачи PKG WEB, дало1911/1139/1109МиБ/с. Кэш ОС не очищался: это скорость чтения этих диапазонов с возможным кэшированием, **не** паспортная или холодная скорость SSD. Размер/mtime файла сохранились. В этом источнике NAS отсутствует; реальная установка после переноса отдельным запуском в этой серии не измерялась.

## Завершение и ограничения

Четыре тестовых файла и пустые UUID-каталоги удалены через revision/identity, SHA256 каждой полной обратной передачи совпал. Игры/сохранения на PS4 файловыми тестами не читались и не изменялись. Финальные настройки подтверждены: loopWait=short, bgftStart=int, putWriter=sync; busy=false. Windows WEB не обновлялся, производственный код не менялся.

Не проверялись аппаратно отзыв ключа, аварийный разрыв PUT, два одновременных async PUT, CPU/температура. Эти сценарии проходили host-тесты Claude, но это не замена аппаратной квалификации. `test-self-update` в отчёте Claude остаётся прежним FAIL; данный аппаратный тест его не исправляет.

Прыжки30–70МиБ/с при пользовательском скачивании PKG остаются отдельной проблемой BGFT; параметры сокетов файловой службы не управляют соединением Sony. Полная промежуточная копия PKG перед локальной установкой исключена по требованию пользователя. Обход BGFT, прямое размещение конечного app.pkg и регистрация пока только обсуждаются, не реализованы и не квалифицированы. Отдельный оверлей прогресса тоже не реализован.
