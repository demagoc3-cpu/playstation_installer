# PackageFlow Windows 1.10.14 — offline WebView2 + Vue

Видимый интерфейс лаунчера перенесён в отдельный Vue-проект `apps/windows-launcher/desktop-ui`. Windows Forms остаётся хостом WebView2 и адаптером прежних обработчиков; прежние поля и страницы скрыты. WEB-приложение не заменяет окно настроек.

## Интерфейс и сохранённые действия

Пять разделов: Главная, Приставки, Поиск, Обновления, Поддержать проект. Общий утверждённый Astro-фон, оригинальный PackageFlow, компактные статусы WEB/qBittorrent/Prowlarr/FlareSolverr, локальные шрифты, RU/EN и ссылки GitHub/4PDA. На Главной нет карточек приставок; большая кнопка открывает WEB, параметры Windows/Compose, LAN, порты, библиотека, автозапуск и видимый Cloudflare доступны непосредственно.

Мастер имеет независимый выбор приставок и торрентов, обнаружение и ручную проверку IP, множественный выбор, RuTracker с показом введённого пароля и ручным Chromium-входом, итоговое подтверждение и журнал подготовки. До итогового подтверждения консоли не устанавливаются. Подтверждённые цели и идентификаторы команд сохраняются для безопасного повторного наблюдения. Отказ от торрентов не инициирует их скачивание или запуск, в том числе в Compose. Возможная уже работающая внешняя служба показывается по фактическому состоянию.

Приставки: профили PS4/PS5, выбор и пакетная установка, обнаружение, проверка, сопряжение, установка/обновление, удаление PS5-приложения или профиля с отдельным подтверждением. Неизвестная прошивка и недоступность не превращаются в успешный результат. Прежний координатор проверяет версии, SHA256, журналы и подтверждения устройства; уже установленная app044 не пересылается только ради обновления UI.

Поиск: подлинные логотипы RuTracker, qBittorrent, Prowlarr, FlareSolverr; дополнительные параметры раскрываются отдельно. Сохранены API-ключ, URL, индексатор, существующие компоненты, credentials Web UI, папка загрузок, ручная CAPTCHA и реальная проверка входа браузером и Prowlarr. Проверка Windows-обновления отделена от запуска установщика; приставки имеют индивидуальные результаты проверки. Для PS4 проверяется опубликованный GitHub-релиз, установка использует проверенный комплект кандидата.

Поддержка использует существующие адреса и QR из `donations.json`, BTC/USDT PNG извлечены без изменения PS5-репозитория. Трей сохраняет автозапуск, обычное закрытие в трей, остановку сервера и выход. Vue-предупреждение по умолчанию сохраняет работу; Escape и безопасная кнопка отменяют остановку. Подтверждение приостанавливает только активные торренты PackageFlow; при появлении нового задания во время остановки требуется повторная проверка.

## IPC и offline-доставка

В WebView2 отображается только `https://packageflow.local`, виртуально связанный с локальной папкой Desktop. CSP запрещает внешние соединения, фреймы и объекты. Навигация на другой origin, новые окна, разрешения, host objects и DevTools отключены. Подписанный Microsoft Evergreen Runtime включён в installer для первой offline-установки; наличие уже установленного Runtime проверяется прежде. При отсутствии/сбое показывается конкретная ошибка.

IPC принимает только фиксированные команды, типы и ключи JSON, ограниченные размеры и selections; повторные ключи, посторонние поля, произвольные URL, shell/process/file/fetch-команды отклоняются. JS не получает сохранённые пароли, DPAPI blobs, launcher-key или pairing tokens. Введённые секреты передаются C# и очищаются из draft после операции; сохранение остаётся Windows DPAPI, localStorage не используется. Повторный мастер с пустым полем пароля сохраняет данные прежнего аккаунта; новый логин очищает пароль старого аккаунта.

Все Desktop-ресурсы явно исключены из single-file bundle и копируются наружу. Packaging удаляет прежний Desktop payload, копирует текущую сборку и сверяет каждый файл с SHA256-манифестом. Эта проверка обнаружила и исправила промежуточную ошибку с PNG, встроенными внутрь EXE; тот кандидат не устанавливался.

Лицензии и происхождение ресурсов находятся в [asset-provenance.json](../../apps/windows-launcher/desktop-ui/public/asset-provenance.json), [THIRD-PARTY.txt](../../apps/windows-launcher/desktop-ui/public/THIRD-PARTY.txt) и папке licenses. Только изображение консолей создано ImageGen; точный prompt сохранён в provenance. Поиск/загрузка — SVG иллюстрация, остальные элементы — Vue/CSS и подлинные компоненты, без растрового снимка интерфейса.

## Воспроизведение сборки

Node 22, npm, .NET SDK 8 и NSIS. `bash packaging/windows/build.sh --version 1.10.14` собирает WEB, Vue, Core tests, Windows single-file, проверяет встроенные сборки, внешний Desktop, offline Runtime, комплект приставок и NSIS. Windows-путь: `packaging/windows/build.ps1 -Version 1.10.14`. `--skip-web-build` повторно использует существующий `.output`, но Vue всегда пересобирается через отдельный package-lock. `PF_PS5_BUNDLE` / `-Ps5Bundle` указывает на каталог артефактов с проверенным манифестом; сверяемый эталон сохранён в `packaging/windows/console-bundle-1.10.14.json`. Финальный прогон использовал уже собранный `.output`, не меняя его исходники.
