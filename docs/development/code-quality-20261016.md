# Проверки качества кода

Работа продолжается от контрольного коммита `6380612`, сохраняющего принятую
версию PackageFlow. Восстановлены только настройки ESLint/Prettier и инструменты
проверки типов; рабочие исходники из исторических версий не переносились.

Используются ESLint `10.12.0`, Prettier `3.9.10`, TypeScript `5.9.3`
и vue-tsc `3.3.13`. Версии ранее зафиксированных зависимостей сохранены.

Проверки и сборку выполнять в отдельной копии проекта, чтобы не перезаписывать
`.nuxt` работающего dev-сервера:

```sh
npm ci
npm run check
npm run build
npm test
```

`check` включает ESLint без предупреждений, строгую проверку типов и Prettier.
Отдельные команды: `lint`, `lint:fix`, `typecheck`, `format`, `format:check`.

`test` запускает существующие серверные и UI-тесты. TypeScript transforms
передаются также дочерним fixture-процессам. HTTP/runtime-тесты используют
свежую `.output` из предыдущего шага сборки. Игровые установки не запускаются.

JS-заглушки тестов исключены только из серверного TypeScript-контекста:
они проверяются ESLint и исполняются тестовым раннером. Строгие проверки
продуктового кода и TS-тестов сохраняются. Generated outputs, локальные данные,
документация и отдельный Windows launcher не форматируются этими инструментами.
