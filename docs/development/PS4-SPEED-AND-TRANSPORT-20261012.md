# PS4: тест скорости WEB и проверка способов установки

12 октября 2026.

## Изменения WEB

- Модалка скорости использует платформу профиля. Для PS4 доступны задержка, WEB → PS4 без записи, PS4 → WEB без чтения с диска и WEB → PS4 с записью.
- Клиент службы PS4 подготовлен для `/benchmark/info` и потоковых `/benchmark/upload`, `/benchmark/download`, `/benchmark/disk` на 12801. Только Bearer, фиксированные маршруты, без Origin и редиректов. Нет fallback к PyLoader. Потоки генерируются блоками 1 МиБ, объём теста 64/128/256 МиБ.
- Старая/непроверенная служба не позволяет начать тест. Активные установки, удаления и обслуживание не отменяются автоматически ради теста. На время замера новые установки и восстановленный worker на этой PS4 не запускаются, другие сервисные очереди допускаются.
- WEB проверяет Request ID, протокол, полный размер и cleanup. Ответ подтверждения ограничен 4096 байт во время чтения. Неполный ответ/неподтверждённая уборка не становятся успешным результатом.

## Проверка параллельной установки

В исходниках найдено два обхода: смешанный выбор одной PS4 через PyLoader и другой через службу; прямой запуск общего сеанса PyLoader при активной очереди другой PS4. Закрыты preflight и серверный admission для старта/восстановления очередей, прямого запуска PyLoader и сервисных submit. Учитываются также локальные установки и резервирование переустановки.

Две сервисные очереди разных PS4 по-прежнему независимы. Пакеты каждой приставки идут последовательно; отмена одной не отменяет другую. PyLoader используется для одной PS4. Проверка относится к одному экземпляру WEB и его хранилищу; она не координирует несколько независимых WEB серверов.

## Проверки

Семь файлов тестов Node прошли, ошибок 0:

- `ps4-speed.test.mjs`: настоящий WEB клиент и бегунок с подставленным HTTP сервисом; все четыре режима, 64 МиБ на каждый потоковый режим, фиксированный порт/авторизация/отсутствие Origin, старый/занятый/неподтверждённый сервис, активная очередь, неверный Request ID, отмена, изоляция блокировок.
- `console-speed.test.mjs`: неполные данные, cleanup, отмена и прежний путь PS5.
- `ps4-transport-admission.test.mjs`: смешанные/прямые/восстановленные очереди и резервирование операций.
- `device-installation.test.mjs`: параллельные настоящие WEB workers с подставленными HTTP ответами, разделение квитанций и отмены, отказ смешанного выбора до отправки.
- `device-installed-review.test.mjs`, `device-install-modal.test.mjs`, `console-file-install.test.mjs`: регрессии проверки установленного состава, модалки и локального PKG.

Production Nuxt build прошёл. Логи: `/tmp/pf-ps4-final-tests.log`, `/tmp/pf-ps4-web-build.log`.
