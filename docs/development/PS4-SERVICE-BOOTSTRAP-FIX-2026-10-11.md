# Первоначальная установка PS4: исправление 11 октября 2026

## Подтверждённая причина

После удаления сервиса пользователь запустил «Установить» в Windows-мастере
для сохранённой сопряжённой PS4. PyLoader отвечал ready, но очередь
bd9693fb-d8bd-48fc-bc16-a6c748c00e3f оставалась pending, bytesSent=0:
общая проверка установленных компонентов требовала отсутствующий сервис.
Следующая проверка прошивки также читала его /system/info.
Мастер скрывал detail за «0%», отключал все действия и запрещал закрытие.

## Исправление

- Первоначальная установка сохраняет bootstrapArtifactId в очереди.
  Исключение действует только для единственного проверенного PS4GDE
  PFLS00001 / IV0000-PFLS00001_00-PACKAGEFLOWSRV00, с тем же staged path
  и проверенным SHA256, ещё раз проверенным непосредственно перед отправкой.
- Только этот пакет с нулевыми требованиями PARAM/SFO допускается без
  установленного сервиса. Обычные игры через PyLoader сохраняют проверки
  компонентов и прошивки с устройства. HTTP API обычной очереди не принимает
  bootstrapArtifactId из пользовательского тела запроса.
- Windows показывает этап, detail и отправленные МБ / общий объём.
  Ожидание ограничено пятью минутами, отдельные API-запросы — 20 секундами.
  Закрытие модального окна прекращает наблюдение, не отменяет принятую
  передачу и не повторяет POST. Кнопка «Закрыть» остаётся доступна.
- BGFT может читать заголовок, сделать паузу и загрузить тело позже.
  Partial перестал означать delivered; поздняя полная передача снимает
  partial и обновляет текущую завершённую очередь по реальным диапазонам,
  не объявляя пакет установленным. Архивы другой очереди не перезаписываются.
- Запись прогресса и обработчик закрытия HTTP-сокета явно сохраняют IP
  получателя. На Windows была найдена лишняя запись без IP после close.

Нативные исходники Claude для PS4/PS5 и ELF не изменялись.

## Проверки и реальная PS4

- Production Nuxt build — PASS; publish Windows x64 — PASS.
- Admission checks — 9 PASS. Первоначальная установка — 8 PASS, включая
  отсутствующий сервис, запрет обхода для обычной очереди, изменённый PKG,
  повторное нажатие и позднее скачивание. HTTP recipient isolation — PASS.
- Windows UI smoke: 14 PASS, включая возможность закрыть ожидающее окно.
- Старая очередь была отменена до повторной установки: cancelled, 0 байт,
  dispatchedAt отсутствовал. Никакие игровые задания не удалялись.
- Ровно один вызов bootstrap после исправления создал очередь
  7b504207-0510-433f-9f9b-40ef3a9e6e2a для PackageFlow 2.05.
  PyLoader ready=true; payload подключился к Windows:3001; PS4 запросила
  манифест и PKG. Пользователь подтвердил: «Установка завершилась».
- После применения финальной версии WEB текущая очередь подтверждена:
  completed, item delivered, bytesSent=6619136, size=6619136.
  Это подтверждение полной передачи. Установку отдельно подтвердил пользователь.
