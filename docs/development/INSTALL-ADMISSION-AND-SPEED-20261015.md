# Допуск переустановки PS5 и скорость заданий

## Согласованный объём

Пользователь подтвердил успешную новую установку Alan Wake Remastered
(`Folder`, PPSA01925, 01.000.003) и регистрацию на PS5. Запросил сохранить все
маршруты установки, разрешить выбор приставки для установки/переустановки и
исправить исчезающую скорость/ETA. Переустановку PS4 повторно не проверять.

## Выбор устройства

Локальная история `397c4bd` ввела зависимость допуска PKG от live readiness.
Последующая независимая поддержка Folder/образов сохранила её. В текущем
снимке PS5 13.60 / root027 имела `installer_unavailable` для PKG и готовые
Folder/образы. Выбранный ASTRO's PLAYROOM PPSA01325 в библиотеке — настоящий
`pkg`, 11016536064 байт; это отличается от работающего Folder Alan Wake.
Наличие базовой игры позволяло явную переустановку, но readiness делал
`eligible=false` ещё до постановки в очередь.

Для проверенной PS5 13.60 и известного `installer_unavailable` разрешён
допуск PKG в существующую очередь. Подтверждение переустановки передаётся
через прежний `overwriteApproved`. Offline, отсутствие подключения, неверная
платформа/прошивка, неизвестный ответ службы и проверки места не обходятся.
Сам worker, его readiness, hash/передача/регистрация и все другие маршруты
сохранены. Если PKG-компонент ещё не готов, прежний worker ожидает его до
чтения и передачи файла. Его сообщение теперь описывает PKG, а не готовые
образы ShadowMount.

Новые способы запуска компонентов, изменения ELF и автоматические загрузки
не включены. PS4-ветви текущего исправления не изменены.

## Скорость и ETA

`9caf9dc` использовал 5 секунд до обнуления; `e56040d` сохранил измеритель
между промежуточными проверками Folder. Последующие большие durable-блоки
до 128 MiB (`acb3f7a`) могли подтверждаться дольше этого порога. Браузер
дополнительно применял такой же порог к времени последнего ACK.

Для PS5 сохраняется живое измерение до 15 секунд между ACK с учётом реально
прошедшего времени. Публичная телеметрия помечается временем измерения;
потеря опросов WEB по-прежнему гасит устаревшие данные через 5 секунд.
PS4-измеритель, сами передачи и протоколы не изменены. Пауза, завершение,
отмена и реальный stall не показывают прежнюю ETA.

## Проверки

- `ps5-install-admission.test.mjs`: встроенная зарегистрированная база,
  разрешённый выбор, явная переустановка, принятие batch, исходный worker
  ожидает readiness, ни одного POST на приставку/ELF/передачу.
- `ps5-install-readiness`, `device-install-modal`, `library-selection`:
  host regression PASS.
- `transfer-speed`: 7 fake-clock сценариев, в том числе ACK через 8 секунд,
  snapshot, Folder device-check, stale WEB, stall, pause/resume и ETA.
- Агент также завершил 17 queue, 1 task-controls и 2 glass host теста;
  Vue-компонент с ETA компилируется.
- Production WEB build PASS. Результат реальной установки Alan Wake сообщён
  пользователем; повторную установку игр этим исправлением не запускали.
