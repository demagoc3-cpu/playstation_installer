# Windows: комплект Claude 021 и таблица добавленных приставок

Дата: 11 октября 2026. Локальный кандидат Windows 1.10.8; не опубликован.
Нативные приложения подготовлены Claude. В этой работе изменены только WEB,
Windows, упаковка и проверки; нативные исходники и ELF не редактировались.

## Изменения

- На основной странице «Приставки» показана таблица всех сохранённых профилей,
  включая отключённые приставки. Столбцы: название, PS4/PS5, IP, модель,
  прошивка, связь, сопряжение, версия службы, доступные форматы, свободное место.
- Выбор строки кнопкой «Выбрать» или двойным щелчком переключает активный
  профиль WEB и настройки мастера. Есть кнопка обновления; открытие страницы
  проверяет сохранённые приставки, одновременно не более двух.
- Поиск новых устройств и сопряжение остаются отдельным окном.
- Прошивка, сопряжение, свободное место и форматы отключённого устройства
  не выдаются за актуальные. WebKit/kstuff остаются «Не проверено».
- GET и POST `/api/catalog/v1` теперь используют общий договор: платформа,
  возможности каталога и собственные сведения каждого пакета. Избранное
  PS4-клиента получает фильтр PS4/PS5; установки по-прежнему защищены платформой.
- В Windows включён проверенный PKG PS4 2.05. Защищённый маршрут
  `/api/desktop/ps4-setup-artifact` проверяет SHA256, размер, SFO и версию,
  затем передаёт его существующему маршруту PyLoader. Если комплекта нет,
  сохраняется загрузка опубликованного пакета с GitHub.
- Включён полный комплект PS5: ELF, образ приложения и манифест. Первоначальная
  отправка остаётся однократной и требует проверенной прошивки и загрузчика;
  загрузка приложения требует сопряжения и подтверждённого маршрута образа.

## Поиск без блокировки и первый запуск PS5, поздняя проверка 11 октября

Исправлено ожидание отключённой приставки в Windows. Открытие окна поиска
больше не ждёт общего опроса состояния и не включает курсор ожидания во всей
программе. Поиск показывает результаты постепенно; таблица и поля остаются
доступными, кнопка «Найти» становится «Остановить поиск». Другая операция
сначала отменяет поиск; закрытие окна прекращает наблюдение. Ограничены
время общего поиска, отдельных запросов и обновления сохранённых профилей.

В WEB кнопка перезапуска PS4 теперь показана также для сохранённого профиля
PyLoader, включая отключённую приставку. Нажатие сначала проверяет живую
готовность службы, затем использует существующий защищённый API перезапуска.
При активной очереди действие недоступно. Кнопка проверена в браузере локального
WEB; настоящий перезапуск PS4 не выполнялся.

На этой PS5 закрытый порт 8095 из Windows даёт таймаут вместо ECONNREFUSED.
Первоначальная попытка поэтому завершилась до отправки ELF. Мастер теперь
требует явного подтверждения остановки старой службы и проверяет TCP-порт:
только таймаут HTTP вместе с неподключившимся TCP допускает первый запуск.
Ответившая служба, принявший соединение зависший HTTP и повреждённый ответ
по-прежнему блокируют отправку. Автоматических повторов нет.

Проверки: Production Nuxt, публикация .NET Windows, NSIS, Core tests,
bootstrap/artifact tests — PASS. На Windows интерактивный UI-тест содержит
15 PASS, включая отмену зависшего поиска с доступными таблицей и полями.
`git diff --check` — PASS.

Промежуточный кандидат поиска: `dist/windows/PackageFlowSetup-1.10.8-x64.exe`,
94 035 589 байт, SHA256
`bc399052267f3aaea883d2a5aa260a05ad02cb8f121fdfd2603054dd712cfe8d`.
Он установлен поверх основной программы Windows штатным installer; задача
завершилась с кодом 0. SHA256 установленного `PackageFlow.exe`:
`92b57023633f4b551eecf7a13323f9cdbe06f5dff3a435c5039412390d6fc372`.
Это замена основной установки, не параллельный тестовый запуск.

С разрешения пользователя через Payload Manager остановлен только старый
PackageFlow PID 96. Windows API мастера отправил проверенный ELF 015h;
flow `ad0e8bb460c1ad5e813e2601c487c029` завершился `completed`,
`/health` подтвердил версию 0.1.15-dev, build ps5-service-management-015h,

этот наш PID; следующий flow `a93ed140bbbeeb8b4ef6379b1602a98f`

Служба сохранила прежнее сопряжение, поэтому перезапуск не создаёт новый код.

имеющейся WEB 040. Перенос сохранённого ключа не выполнялся: автоматическая
проверка отклонила чтение секрета. Установка приложения 01.000.041 пока
не отправлена; подтверждение ELF не является подтверждением его установки.

### Завершение установки приложения из Windows

Пользователь получил новый код в WEB 040. Через штатный `/api/consoles/pair`
Windows сопряжена с PS5; подтверждены FW 13.60, ShadowMount+ и все шесть
маршрутов установки. Ключ из файлов PS5 не читался и не переносился.
После закрытия WEB 040 отсутствие `eboot.bin` проверено в Payload Manager.

Аппаратная проверка выявила две ошибки WEB мастера:

- Он передавал новый `queueId` как идентификатор существующей очереди для
  добавления пакетов. Теперь внутренний `newQueueId` создаёт очередь с номером
  уже сохранённой квитанции; добавление в существующую очередь сохраняет прежний
  договор. Тест проверяет сохранённый номер, единственную отправку и запрет
  повторного создания как работающей, так и завершённой очереди.
- В списке разрешённых заголовков PS5 отсутствовал `X-PackageFlow-Image-Protocol`.
  Команда регистрации отклонялась локально до HTTP, хотя намерение отправки
  уже было сохранено. Заголовок добавлен. Новый тест проходит через настоящий
  транспорт `ps5OperationRequest` и проверяет метод, путь и протокол; посторонний
  заголовок по-прежнему блокируется до сети.

Первая попытка `b1d2a066170944f185dd9a74f8c2a21e` не создала очередь.
Следующая очередь `d93678eba9cb04594b3a68f77fc89ace` передала и проверила
5 963 776 байт, но регистрация не отправилась из-за локального заголовка.
Отсутствие image receipt, registration intent и исходного образа на PS5
проверено. Перед восстановлением только этого тестового задания сохранена
копия `queue-before-local-header-recovery.json` в Windows Downloads.
Из-за замены исходного файла installer защитная проверка source stamp
завершила восстановленное задание до публикации; прежние журналы сохранены.

Окончательная попытка `f648b9b0e1494573bd24eb07bf9d7261`, очередь
`a11531d59bd6d0c46c0c13f1679b09db`, создана через защищённый API Windows-мастера.
PS5 вернула квитанцию `image-registration`, transfer ID
`1541d7c0d1e1203b20ecf6656e313a6f`, state `registered`, installed/registered=true,
Title ID PPSA95001, Content ID из манифеста, version 01.000.041, format ufs2.
Очередь завершилась `completed`, пакет `installed`. Это подтверждение системной
регистрации; запуск нового интерфейса пользователем ещё не проверялся.
Пользовательские игры и сохранения не изменялись.

Окончательный installer после этих двух исправлений: 94 033 857 байт,
SHA256 `9ba9052ea55304f22e8c33d7e3114398db98d393350603fecd0d8e60ff7d90c4`.
Передан и применён к основной Windows-установке; installer LastTaskResult=0.
Production Nuxt, queue/bootstrap/artifact tests, NSIS и diff check — PASS.
Исходники и бинарники нативных приложений Claude и ELF при исправлениях
WEB не менялись. Push не выполнялся.
