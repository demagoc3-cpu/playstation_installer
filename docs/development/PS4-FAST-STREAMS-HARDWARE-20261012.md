## Изменение HTTP-источника в WEB

Источник пользователя — GVFS/FUSE сетевой диск. Read-only проходы одинакового256 МиБ диапазона с SHA256: первый64 КиБ59,07 МиБ/с; при повторных проходах146–174 МиБ/с, включая64 КиБ155,22. **Кэш мешает чистому A/B**, ограничение только размером блока не доказано.

Codex увеличил блок getPackageStream и буфер counting Transform до1 МиБ, малый Range ограничивает выделение своим размером. Сохранены потоковая отдача без полного копирования, backpressure, HEAD/Range, отмена и изоляция приставок. Добавлены журнал прихода запроса до доступа к источнику, время подготовки манифеста и чтения первого блока. Это изменение отдачи PKG для BGFT/PyLoader; оно не перенастраивает сокет Sony. Реальное ускорение и устранение30 секунд **после этой правки ещё не подтверждены**.

Проверки:8 тестов PASS (ps4-delivery-url, package-readonly, transfer-speed), включая Range через границу1 МиБ, HEAD/полную передачу/изоляцию/поздний body. HTTP-тест запускался вне sandbox, где разрешён listen. Production Nuxt build PASS. Действующий WEB подхватил правку: HEAD200 с верным Content-Length и новый лог обработчика, без передачи тела и новой установки.
