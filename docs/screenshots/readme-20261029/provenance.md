# README screenshots — 29 October 2026

The WEB screenshots in this directory show the **actual current PackageFlow Vue application**, not a drawn mockup. They were captured through the Codex in-app browser from a separate local host fixture. The complete application frame, navigation, components, localization, CSS and background are taken from this repository; library data, console profiles, installed markers, queues, sizes, versions, space figures and transfer rates are explicitly synthetic examples. The overlay `HOST PREVIEW · DEMO DATA · NO CONSOLE CONNECTION` identifies these examples in every new WEB image.

No console was contacted. No game was installed, reinstalled, launched or removed. No ELF was sent and no console service was restarted. The running development server, its `.nuxt`, source files and production `.data` were not changed.

## WEB fixture isolation and reproduction

Host scripts are kept separately at `/tmp/pf-readme-20261029/{build.mjs,runtime.ts,serve.mjs}`. The source checkout was `/home/developer/projects/web/playstation_installer`, Git HEAD `deb958980e289482e49eb68ec036ec7d5f8d2746` at capture time. `source-sha256.json` records the exact Vue, composable, localization and CSS source hashes used.

`build.mjs` reads the current `app/app.vue` and every current `app/components/*.vue`, compiles them using the existing `@vue/compiler-sfc` and esbuild dependencies and registers the real components. It also includes the actual `useAppLocale`, `useConsoleRequest`, `useGamePreview` and localization implementation. Small host adapters provide Nuxt's state, cookie, runtime configuration and head APIs. No Nuxt development or production build runs. No source or dependency directory is replaced.

All `$fetch` calls are fulfilled by an explicit, method-aware, in-memory fixture allowlist. Unrecognized endpoints throw. Native browser `fetch` is disabled, the page has a `connect-src 'none'` content security policy, and external font imports are excluded; the actual CSS fallback fonts apply. The separate HTTP server listens only on `127.0.0.1:4179` and serves an explicit static resource allowlist, including local fixture icons. It has no proxy, console transport, filesystem browser or installation endpoint. The browser used the normal 1280 × 720 viewport; no viewport override or UI redesign was applied. Browser error/warning logs were empty after visual checks of the captures.

To regenerate in the same local workspace: run `node /tmp/pf-readme-20261029/build.mjs`, then `node /tmp/pf-readme-20261029/serve.mjs`, and open `http://127.0.0.1:4179/?lang=ru` through the browser. Use normal UI buttons to expand Cyberpunk 2077, change RU/EN and open Tasks, Presets or On console. Only fixture reads are enabled; action endpoints are rejected. Captures are saved from the browser screenshot API without pixel editing.
