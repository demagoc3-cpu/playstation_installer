# Проверка управления приложениями — PackegeFlowService 1.20

На PS4 с 1.19 список игр, названия и обложки работают. Запрос `GET /apps/runtime/{TITLE_ID}` возвращал HTTP 503 / `0x80020003`, поэтому WEB оставлял кнопки управления выключенными. В 1.20 демон использует те же штатные импорты Lnc, что уже работают в запускателе. На реальной PS4 через WEB подтверждены запуск и остановка Trials Fusion; пользователь также подтвердил результат на экране консоли.

1. Дождаться окончания текущей установки. Установить [PKG 1.20](../PackegeFlowService/build/PackegeFlowService-1.20.pkg) поверх 1.19, один раз открыть запускатель и дождаться HTTP READY. Удалять предыдущий PKG и повторно вводить код сопряжения не требуется.
2. Обновить и перезапустить WEB. В «О системе» ожидать сервис 0.6.1 / PKG 1.20.
3. В «На консоли» открыть небольшую тестовую игру. Ожидать «Остановлено» и активную кнопку «Запустить» либо «Запущено» и активную кнопку «Остановить». Для системного PFLS00001 кнопок не будет: он остаётся защищённым.
4. Запустить тестовую игру, проверить её экран и состояние в WEB. Затем остановить через WEB и проверить возврат на рабочий стол. Несохранённый прогресс игры при остановке потеряется.
5. Если кнопки остаются серыми, снять видимое сообщение рядом с ними и строку запроса `/api/ps4/apps/runtime` в журнале. Оставить сервис запущенным: остальные функции не зависят от этой проверки.

SHA-256 PKG: `c1c8f1ed24e5a47209bdbc62e9c8bfefed6c50103a0efca9e553bb3e317b06b1`.

Техническая причина: 1.19 использовал отдельный `sceKernelLoadStartModule("/system/common/lib/libSceSystemService.sprx")` при уже загруженном системном модуле. В 1.20 вызов убран. Штатные импорты `libSceLncUtil.so` в ELF преобразуются OpenOrbis в `libSceSystemService.prx` в SELF, как в успешном запускателе. Код не использует смещения функций, `libkernel_sys` или нестандартный конвертер.

Первичные сведения по Lnc и запуску демона: [PS4 daemon writeup](https://github.com/LightningMods/PS4-daemon-writeup/blob/main/writeup.md); [OpenOrbis Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain). Полные возможности версии 1.19 описаны [здесь](console-management-1.19.md).
