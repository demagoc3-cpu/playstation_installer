# Установка PKG с диска PS4 — PackageFlowService 1.54

## Как установить

1. Запустите установленный PackageFlowService 1.54 на PS4 и откройте «Файлы» в сопряжённом WEB.
2. Откройте папку с полностью загруженным PKG в `/data`, `/user/data` или `/mnt/usb0`–`/mnt/usb7`.
3. Нажмите «Установить» у файла. WEB прочитает название, тип, версию и требования к прошивке из PKG, проверит его размер и свободное место на PS4.
4. Нажмите «Установить на PS4». Прогресс и отмена появятся на странице. Завершённое задание доступно в «Истории операций»; уведомление скрывается автоматически.

Установку выполняет системный установщик PS4 с локального диска. WEB читает только нужные части для проверки метаданных и обложки; весь PKG обратно на компьютер не скачивается. Исходный файл остаётся в папке. Для установки необходимо дополнительное место; во время неё сервис защищает исходник и его папку от изменения.

Поддерживаются обычные пакеты игры, патча и DLC. Обновление самого PackageFlowService выполняется через «О системе». При несовместимой или неизвестной прошивке, неполной загрузке, изменившемся файле либо нехватке места установка не запускается. Если PS4 уже зарегистрировала задание для этого PKG, WEB показывает ошибку дубликата, а не успешную установку.

## Проверка 02.10.2026

На PS4 Pro 12.50 со службой 1.54 установлен созданный отдельно тестовый пакет `PackageFlow Local Install Test`, `PFLT00001`, размером 6 619 136 байт. Источник: `/data/PackageFlow-PKG-Test-20261002/PackageFlow Local Install Test.pkg`. Системное задание №525 завершилось с состоянием `installed`, ошибкой 0, копированием 100%; наличие приложения отдельно подтверждено в составе установленных игр. Размер и ревизия исходного PKG после установки не изменились. Пользователь подтвердил появление установленного приложения на PS4.

Маленький DLC, уже зарегистрированный консолью, корректно получил `0x80990015`; этот результат не считался успешной установкой. Новая установка DLC и установка с реального USB в этом этапе не испытывались.

Локальные проверки охватывают ABI системного установщика, выбор слота приложения, преобразование пути `/data` для системного процесса, подтверждение завершения, защиту активного источника, тип и ревизию PKG, отказ связанным файлам, проверку размера/прошивки/места, восстановление задания после потерянного ответа без повторной отправки команды и отмену. Прежняя сетевая очередь прошла все 18 сценариев; WEB собирается успешно.

Журнал локальных установок хранится в `.data/console-file-installations.json`. Сохраняйте данные WEB или соответствующий Docker volume, чтобы после перезапуска можно было продолжить проверку принятого задания.
