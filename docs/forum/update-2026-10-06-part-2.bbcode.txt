[b]Обычная установка на компьютер[/b]

Добавили EXE для Windows 10/11 x64. WEB, Node.js и среда .NET входят в комплект: отдельно устанавливать инструменты разработки и собирать проект обычному пользователю больше не требуется. В конце установки предлагается создать ярлык на рабочем столе.

В мастере доступны обычный запуск Windows и Docker Compose. Docker Desktop для режима контейнеров устанавливается отдельно. Настройки и данные находятся отдельно от заменяемых файлов приложения и сохраняются при установке новой версии поверх старой.

[b]Автоматическая первая настройка[/b]
[list]
[*]При первом запуске мастер подготавливает библиотеку, запускает WEB, устанавливает и запускает Prowlarr и FlareSolverr, устанавливает qBittorrent при его отсутствии и подключает загрузки к проекту.
[*]Ход подготовки отображается по этапам: видно, какой компонент скачивается, распаковывается или запускается. При установке qBittorrent Windows может запросить права администратора.
[*]Прерванную настройку можно продолжить при следующем запуске либо повторить кнопкой «Подготовить компоненты». Причины ошибок показаны в журнале.
[*]Для нового подключения qBittorrent создаётся отдельный профиль PackageFlow. Уже сохранённое подключение проверяется с его существующими настройками. Остановка WEB оставляет qBittorrent работать.
[/list]

[b]Настройки и интерфейс[/b]
[list]
[*]На всех страницах показаны отдельные статусы WEB, сопряжения, qBittorrent, Prowlarr и FlareSolverr. Они обновляются после действий и периодически. Внизу находятся текущий этап, проценты и журнал событий с временем.
[*]«Применить» сохраняет настройки и сразу индексирует выбранную папку PKG. Папки игр и загрузок qBittorrent можно выбрать кнопкой. Смена адреса WEB передаётся сопряжённой приставке.
[*]Логин и сохранённые данные RuTracker отображаются в мастере. У паролей и API-ключей есть переключатель «Показать»; секреты мастера защищены учётной записью Windows.
[*]Добавлены карточки, иконки меню, закруглённые кнопки и расположение действий в один ряд. Исправлены обрезание подписей, артефакты при перемещении окна и закрытие мастера при работе с выпадающим меню.
[/list]

Добавлены автозапуск, работа в трее и обновление Windows-приложения из GitHub с проверкой файла. Активные задания блокируют остановку для обновления. В шапке расположены логотипы 4PDA/GitHub, ссылки, версия WEB и звёзды репозитория.
