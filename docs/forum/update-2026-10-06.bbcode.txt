[size=3][b]PackageFlow — большое обновление. Часть 1/3: сервис PS4[/b][/size]

Собрал изменения с момента появления самостоятельного обновления сервиса на PS4 до последнего исправления библиотеки. За это время добавили установщик Windows, мастер первой настройки, автоматическую подготовку компонентов и первоначальную установку сервиса на приставку.

[b]Версии компонентов: Windows-установщик 1.10.6, PackageFlowService для PS4 1.92.[/b]

[b]Обновление прямо на PS4[/b]
[list]
[*]В «Настройки → Обновить» приставка сама проверяет GitHub, скачивает новый PKG и запускает обновление после подтверждения. Для этого не нужны работающий WEB на компьютере и предварительное сопряжение.
[*]На экране отображается прогресс загрузки. Проверяются размер, контрольная сумма SHA-256, идентификаторы приложения и версия внутри пакета. Одинаковая или старая версия повторно не устанавливается.
[*]Перед установкой интерфейс закрывается, после успешного обновления новая версия запускается автоматически. Активные установки и передачи блокируют замену сервиса. Доработано восстановление состояния обновления после перезапуска.
[*]Исправлены ошибки HTTPS при обращении к GitHub: обработка перенаправлений и доверенных корневых сертификатов. Обновление через WEB и ручная установка PKG также доступны.
[/list]

[b]Сопряжение и поддержка[/b]
[list]
[*]При переходе на другой компьютер PS4 получает его актуальный адрес WEB. Исправлена ситуация, когда WEB уже видел приставку, а сервис продолжал обращаться к старому адресу. Новый адрес подхватывается без перезапуска интерфейса.
[*]Состояние сопряжения проверяется отдельно от запуска WEB. Сохранённый ключ подключения сам по себе не означает, что приставка сейчас доступна.
[*]Временная ошибка связи больше не стирает полученные данные раздела поддержки. BTC и Tether получили полноценные иконки-картинки.
[/list]

[b]Первоначальная установка сервиса[/b]

На шаге «PS4» мастер умеет обнаружить приставку в локальной сети, показать наличие сервиса или PyLoader и подставить выбранный IP. Ручной ввод адреса остаётся доступен.

Если PackageFlow ещё не установлен, включите GoldHEN и PyLoader на порту 9090, затем нажмите «Установить сервис». Мастер скачает проверенный PKG и отправит его без предварительного сопряжения. После передачи дождитесь завершения установки в «Уведомления → Загрузки», запустите PackageFlow и введите код из «Подключений» в мастере.


[size=3][b]PackageFlow — часть 2/3: Windows-установщик и мастер[/b][/size]

[b]Обычная установка на компьютер[/b]

Добавили EXE для Windows 10/11 x64. WEB, Node.js и среда .NET входят в комплект: отдельно устанавливать инструменты разработки и собирать проект обычному пользователю больше не требуется. В конце установки предлагается создать ярлык на рабочем столе.

В мастере доступны обычный запуск Windows и Docker Compose. Docker Desktop для режима контейнеров устанавливается отдельно. Настройки и данные находятся отдельно от заменяемых файлов приложения и сохраняются при установке новой версии поверх старой.

[b]Автоматическая первая настройка[/b]
[list]
[*]При первом запуске мастер подготавливает библиотеку, запускает WEB, устанавливает и запускает Prowlarr и FlareSolverr, устанавливает qBittorrent при его отсутствии и подключает загрузки к проекту.
[*]Ход подготовки отображается по этапам: видно, какой компонент скачивается, распаковывается или запускается. При установке qBittorrent Windows может запросить права администратора.
[*]Прерванную настройку можно продолжить при следующем запуске либо повторить кнопкой «Подготовить компоненты». Причины ошибок показаны в журнале.
[*]Для нового подключения qBittorrent создаётся отдельный профиль PackageFlow. Уже сохранённое подключение проверяется с его существующими настройками. Остановка WEB оставляет qBittorrent работать.
[/list]

[b]Настройки и интерфейс[/b]
[list]
[*]На всех страницах показаны отдельные статусы WEB, сопряжения, qBittorrent, Prowlarr и FlareSolverr. Они обновляются после действий и периодически. Внизу находятся текущий этап, проценты и журнал событий с временем.
[*]«Применить» сохраняет настройки и сразу индексирует выбранную папку PKG. Папки игр и загрузок qBittorrent можно выбрать кнопкой. Смена адреса WEB передаётся сопряжённой приставке.
[*]Логин и сохранённые данные RuTracker отображаются в мастере. У паролей и API-ключей есть переключатель «Показать»; секреты мастера защищены учётной записью Windows.
[*]Добавлены карточки, иконки меню, закруглённые кнопки и расположение действий в один ряд. Исправлены обрезание подписей, артефакты при перемещении окна и закрытие мастера при работе с выпадающим меню.
[/list]

Добавлены автозапуск, работа в трее и обновление Windows-приложения из GitHub с проверкой файла. Активные задания блокируют остановку для обновления. В шапке расположены логотипы 4PDA/GitHub, ссылки, версия WEB и звёзды репозитория.


[size=3][b]PackageFlow — часть 3/3: RuTracker, библиотека и обновление[/b][/size]

[b]RuTracker и FlareSolverr[/b]
[list]
[*]Мастер помогает добавить RuTracker по логину и паролю либо подключить существующий индексатор Prowlarr. После проверки его Torznab подключается к поиску PackageFlow. Настройки других индексаторов сохраняются.
[*]Добавлена кнопка «Войти вручную». Если RuTracker требует капчу, открывается отдельное окно Chromium, в котором можно самостоятельно войти. Оно остаётся открытым до подтверждения «Я вошёл — проверить».
[*]После ручного входа мастер отдельно проверяет индексатор Prowlarr. Cookies браузера в индексатор не переносятся; ручной вход доступен для локальной установки Windows.
[*]Доработано повторное использование настроенного прокси и браузерной сессии. Если Cloudflare блокирует проверочный сайт Prowlarr, мастер отдельно проверяет доступность RuTracker. Ошибка одного сайта не считается доказательством недоступности другого.
[/list]

[b]Карточки и загрузка описаний[/b]

Описания и обложки сначала запрашиваются по HTTP, успешные данные сохраняются в кэше. Фоновая подготовка карточек не открывает Chromium для каждой найденной ссылки. Если источник требует проверку, FlareSolverr может использоваться при открытии карточки.

В карточке доступны сведения о раздаче, размер, сиды и личеры, дата, метки из названия и ссылка на источник. Описание прокручивается внутри карточки. По умолчанию результаты сортируются по новинкам; «Показать ещё» загружает следующую страницу без повторов, если индексатор поддерживает страницы.

[list]
[*]Убран жёсткий предел в 500 пакетов. Сканируются все корректные PKG/FPKG в выбранной папке и вложенных каталогах.
[*]Проверено на 800 пакетах и повторном сканировании после добавления 801-го. Стабильные идентификаторы и отметки установки сохраняются.
[*]Обновлены главный README, инструкции RU/EN и скриншоты мастера. Подготовлены новый баннер и руководство локальной сборки Windows-установщика.

[/list]

[b]Как обновиться[/b]

Установите новый EXE поверх текущей версии и нажмите «Применить», чтобы пересканировать папку без прежнего ограничения. На PS4 используйте «Настройки → Обновить», обновление через WEB или ручную установку PKG. Перед обновлением завершите активные установки и передачи.
