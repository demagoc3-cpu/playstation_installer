[size=3][b]PackageFlow — автообновление PS4, Windows-установщик и мастер настройки[/b][/size]

Собрал изменения с момента появления самостоятельного обновления сервиса на PS4 до последнего исправления библиотеки. Теперь настроить PackageFlow на Windows можно через обычный EXE, без ручной установки Node.js и .NET.

[b]Версии компонентов: Windows-установщик 1.10.6 · PackageFlowService для PS4 1.92.[/b]

[spoiler=Обновление сервиса PS4 и сопряжение]
[list]
[*]В «Настройки → Обновить» можно проверить GitHub, скачать и установить новую версию прямо на PS4. Запущенный WEB и сопряжение для этого не требуются. Обновление через WEB также сохранено.
[*]Добавлены прогресс загрузки, проверка размера, SHA-256 и версии PKG. Перед установкой интерфейс закрывается, после успешного обновления новая версия запускается автоматически. Активные установки и передачи блокируют замену сервиса.
[*]Исправлены ошибки HTTPS при проверке и скачивании с GitHub: обработка перенаправлений и доверенных корневых сертификатов. Доработано восстановление состояния обновления после перезапуска.
[*]При сопряжении с другим компьютером PS4 получает его актуальный адрес WEB. Больше не остаётся старый URL от предыдущего подключения; адрес подхватывается без перезапуска интерфейса.
[*]Сопряжение проверяется отдельно от работы WEB. Кратковременные ошибки связи больше не стирают уже полученные данные поддержки. Для BTC и Tether добавлены иконки-картинки.
[/list]
[/spoiler]

[spoiler=Windows-установщик и мастер настройки]
[list]
[*]Добавлен EXE для Windows 10/11 x64. WEB, Node.js и среда .NET входят в комплект. Доступны обычный запуск Windows и Docker Compose; Docker Desktop устанавливается отдельно.
[*]При первой настройке мастер сам запускает WEB, подготавливает Prowlarr и FlareSolverr, устанавливает qBittorrent при его отсутствии и подключает загрузки. Остаётся ввести данные RuTracker и настроить приставку.
[*]Прерванную подготовку можно продолжить при следующем запуске или повторить кнопкой «Подготовить компоненты». Для нового подключения qBittorrent создаётся отдельный профиль PackageFlow; сохранённое подключение не заменяется.
[*]В шапке видны статусы WEB, сопряжения, qBittorrent, Prowlarr и FlareSolverr. Внизу — текущий этап, проценты загрузки и журнал событий.
[*]Добавлены автозапуск, работа в трее, ярлык на рабочем столе и обновление Windows-приложения через GitHub с проверкой скачанного файла. Настройки, библиотека и сопряжение сохраняются при установке поверх предыдущей версии.
[*]Кнопка «Применить» сохраняет изменения и сразу индексирует папку PKG. Папки игр и загрузок можно выбирать кнопкой; у паролей появилась галочка «Показать», введённые данные сохраняются в интерфейсе.
[*]Переработан внешний вид: карточки, иконки, закруглённые кнопки, действия в один ряд. Исправлены обрезание подписей при уменьшении окна, артефакты перерисовки и закрытие мастера при работе с выпадающим меню.
[*]В шапку добавлены логотипы и ссылки 4PDA/GitHub, версия WEB и звёзды репозитория.
[*]Исправлена сборка EXE в GitHub Actions. Windows-установщик собирается отдельным workflow, без повторной сборки контейнера в нём; добавлена инструкция локальной сборки.
[/list]
[/spoiler]

[spoiler=Найти PS4 и впервые установить сервис]
[list]
[*]Кнопка «Найти PS4» обнаруживает приставки в локальной сети и показывает наличие сервиса или PyLoader. Ручной ввод IP остаётся доступен.
[*]Если PackageFlow ещё не установлен, мастер может скачать проверенный PKG с GitHub и отправить его через PyLoader без предварительного сопряжения.
[*]Для этого на PS4 должны быть включены GoldHEN и PyLoader на порту 9090. После передачи дождитесь установки в «Уведомления → Загрузки», запустите PackageFlow и введите код сопряжения в мастере.
[/list]
[/spoiler]

[spoiler=RuTracker, FlareSolverr и библиотека]
[list]
[*]Добавлена кнопка «Войти вручную»: при капче можно войти в RuTracker в отдельном Chromium. Окно ждёт подтверждения «Я вошёл — проверить», затем мастер отдельно тестирует индексатор Prowlarr. Ручной вход доступен для локальной установки Windows.
[*]Доработано повторное использование прокси и браузерной сессии. Блокировка проверочного сайта Prowlarr больше не приравнивается к недоступности RuTracker.
[*]Описания и обложки сначала запрашиваются по HTTP и используют кэш. Фоновая загрузка карточек не открывает Chromium; при необходимости проверка через FlareSolverr выполняется при открытии карточки.
[*]Поиск по умолчанию сортируется по новинкам; следующая страница загружается через «Показать ещё». Доступное количество зависит от поддержки страниц самим индексатором.
[*][b]Убран предел в 500 пакетов.[/b] Сканируются все корректные PKG/FPKG, включая вложенные папки. Проверено на 800 пакетах и повторном сканировании с добавлением 801-го; отметки установки сохраняются.
[*]Обновлены главный README, инструкции RU/EN и руководство локальной сборки. Добавлены свежие скриншоты мастера и новый баннер.
[/list]
[/spoiler]

[b]Как обновиться:[/b] установите новый EXE поверх текущего и нажмите «Применить» для повторного сканирования папки. На PS4 используйте «Настройки → Обновить» либо обновление через WEB. Для первоначальной установки или установки поверх остаётся доступен PKG вручную.
