# Приставка для управления и сохранений

Актуальное состояние ELF015 и WEB, включая восстановление с откатом:
[console-management-015.md](console-management-015.md). Разделы ELF014 ниже
фиксируют прежние этапы; их запись «восстановление отключено» историческая.

В разделах «На консоли» и «Сохранения» есть общий выбор конкретного профиля:
имя, PS4/PS5 и IP. Выбор сохраняется через `/api/consoles/active`, совпадает
с профилем в «Устройствах» и остаётся при переходе между разделами.
Смена профиля размонтирует старое представление, очищает фокус игры и создаёт
новое с отдельным состоянием. Уже принятая команда относится к прежнему
адресу; запоздавший ответ не запускает дальнейшие запросы закрытого вида.
Многошаговое копирование фиксирует адрес и список слотов до первого запроса.
Выбор устройства не отправляет установку и не переносит очередь другой PS4.

Новые отдельные копии PS4 содержат `sourceIp` в metadata.json. Список фильтруется
по адресу выбранной приставки, профилю пользователя и игре. Восстановление
отклоняется до связи с PS4, если источник не совпал или не записан. Старые
копии без `sourceIp` не удаляются и не получают выдуманный источник: они
выведены отдельным списком для скачивания. Именные наборы уже содержали
`sourceIp`; теперь их список также относится к выбранной PS4. Существующие
проверки keystone, закрытой игры, копии перед восстановлением и отката сохранены.
Известный профиль PS5 отклоняется клиентом PS4 API, независимо от активного
профиля браузера. При выборе PS5 WEB использует собственный backend ELF014. На старом ELF
раздел сообщает о необходимости обновления; обращения к PS4 API не выполняются.

## Исследование ps5upload

Проверено 2026-10-10, upstream main
`39bace23a21e5d0cd0f8f890b691e60307be0198` (сверено `git ls-remote`,
прочитано через `git show origin/main`, а не прежний checkout).

Первичные источники:

- [payload/runtime.c](https://github.com/phantomptr/ps5upload/blob/39bace23a21e5d0cd0f8f890b691e60307be0198/payload/src/runtime.c), `append_saves_for_root`, `handle_list_saves`.
- [saves.rs](https://github.com/phantomptr/ps5upload/blob/39bace23a21e5d0cd0f8f890b691e60307be0198/engine/crates/ps5upload-core/src/saves.rs), контракт списка.
- [save_archive.rs](https://github.com/phantomptr/ps5upload/blob/39bace23a21e5d0cd0f8f890b691e60307be0198/client/src-tauri/src/commands/save_archive.rs), архив и нормализация.
- [Saves/index.tsx](https://github.com/phantomptr/ps5upload/blob/39bace23a21e5d0cd0f8f890b691e60307be0198/client/src/screens/Saves/index.tsx), `handleDownload`, `handleRestore`.

PS5-native читаются из `/user/home/<8 hex>/savedata_prospero/<title>`,
PS4 на той же PS5 — из `savedata`. Для построения пути payload сохраняет
исходное hex-имя пользователя. Список сообщает platform/kind, путь, время
изменения и приблизительный размер; размер считается только на двух уровнях,
поэтому не может служить проверкой полноты архива.

Копирование использует обычный файловый download, затем ZIP с верхней папкой
Title ID. Это копия контейнеров и внешних метаданных, а не расшифрованный
экспорт через Sony SaveData. В `backup_finalize` сохраняются верхние файлы и
`sce_sys`, разворачиваются вложенные обёртки, остальные подкаталоги удаляются
из временной копии. Для образа формата byte0=0x01 (PS4) убирается `sdimg_`;
для byte0=0x02 (PS5) имя остаётся. Указание embedded sealed key на 0x800
дано в комментариях upstream; на нашей приставке это отдельно не проверено.

Восстановление проверяет структуру ZIP и выбранный host, сохраняет папку игры,
удаляет её содержимое и передаёт распакованные файлы. Сам интерфейс upstream
предупреждает о потере сейва при обрыве без автоматического отката. Для PS4
на PS5 также описана необходимость закрыть/открыть игру либо перезапустить
консоль. Наличие функции в upstream не доказывает надёжность восстановления
на нашей PS5 13.60. Мы не переносим удаление действующего сейва перед upload.

## Последовательность собственной реализации PS5

1. ELF: авторизованный read-only список двух корней сохранений, точные hex-ID,
   явная неполнота/пагинация, отсутствие обхода symlink и выхода из корня.
   Проверить реальные файлы 13.60 без монтирования и записи.
2. Backup: зафиксировать consoleId/IP, userId, kind, Title ID; убедиться, что
   приложение закрыто и нет установки/обновления службы. Полная копия исходных
   имён и подкаталогов, включая `sce_sys`, в отдельную временную папку WEB.
   Манифест путей/размеров/SHA-256; повторная проверка состава и изменений
   источника после чтения. Публиковать копию только целиком. Незнакомый формат
   не нормализовать и не удалять части по примеру upstream автоматически.
3. Hardware: сравнение состава и хешей с исходником, проверка ZIP, повторный
   backup. До этого capability backup=false. Нельзя считать копию
   восстанавливаемой только потому, что ZIP скачался.
4. Restore — отдельный этап. Сначала доказать на собственном тестовом сейве
   существующего слота возможность подготовки, замены и отката с его ключами,
   внешними метаданными и записью регистрации. Предварительная копия и
   проверка всех файлов до изменения действующего сохранения; никакого
   wipe-then-upload. Обрыв/перезапуск должны сохранять исходник либо давать
   проверяемый откат. Не обещать перенос между приставками и пользователями.

Восстановление PS5 остаётся отдельной непроверенной задачей и отключено.
Native UI040 (Claude UI017, 97e68ce) принято пользователем; Codex реализовал
WEB и read-only backend каталога и копирования в ELF014.

## Проверка на своей PS5 13.60

2026-10-10: профиль PS5 выбран явно по ID, health подтвердил настоящую
приставку и firmware 13.60. Через существующий FTP выполнены только NLST
известных корней: один hex-профиль, 9 каталогов игр в `savedata_prospero`
и 5 в `savedata`. Проверены по две папки каждого типа. В двух PS5-папках
нашлись соответственно 2 и 3 файла `sdimg_…`, отдельных `.bin` не было;
в двух PS4-папках — 1 и 4 пары image/bin. `sce_sys` в этих четырёх образцах
не обнаружен; нельзя требовать его наличия в каждом сохранении.
Личные ID и имена файлов в отчёт не включены. Образы не скачивались,
монтирование/запись/удаление не выполнялись. Это подтверждение структуры,
а не проверка полноценного backup/restore.


## ELF014 и полные копии через WEB — 2026-10-10

Корневые GET API требуют сохранённый bearer сопряжения. Каталог читает
`tbl_contentinfo` app.db через SQLite READONLY. Список всех регистраций
PS4/PS5 постраничный; ревизия всех строк обнаруживает изменения между
страницами. Поля TITLE и CONTENT_VERSION берутся из реальной AppInfoJson
13.60; личные пути метаданных в браузер не выдаются. Запись в базе не
приравнивается к подтверждённому запуску.

Список сохранений сохраняет исходные hex-ID пользователя и разделяет native
и legacy. Манифест включает все файлы и пустые папки в пределах 512 узлов,
64 ГиБ, глубины 8 и пути 240 байт; превышение явно отклоняется, а не выдаёт
частичный успех. Все компоненты открываются с O_NOFOLLOW; symlink, hardlink
и специальные файлы отклоняются. Блочное чтение до 1 МиБ проверяет identity
файла до и после каждого чтения; манифест проверяется повторно после копии.
Это проверка неизменности закрытого сохранения, а не транзакционный snapshot
через Sony SaveData. Игра должна быть закрыта, очередь и обновление — свободны.

WEB хранит копии в data/ps5-save-backups, задания в data/ps5-save-jobs.
Копия включает неизменённые файлы, деревья и metadata.json с consoleId,
sourceIp, userId, Title ID, kind, размерами и SHA-256. UUID команды фиксируется
до первого чтения; повтор возвращает журнал и не запускает второй экспорт.
При ошибке временная копия не публикуется. После перезапуска незавершённое
задание становится ошибкой без автоматического повторного чтения.
Старые незавершённые временные папки могут остаться на диске после аварийного
завершения WEB; они не отображаются как готовые копии.

Протокол — ps5-encrypted-save-backup-v1: исходные контейнеры без расшифровки,
нормализации имён и обещания переноса между пользователями/приставками.
ZIP создаётся после проверки локальных SHA-256. Восстановление отключено.

На Slim13.60: 20 регистраций, 14 папок сохранений (9 native, 5 legacy).
По одной полной копии каждого типа сравнено с независимым FTP-чтением;
через фактический WEB проверены ZIP CRC/SHA-256, повтор команды и отказ другого
consoleId. Источники не изменены, сохранения не монтировались и не восстанавливались.
Ни одного персонального ID или имени контейнера в этом документе нет.
Возможности публикуются только с маркером аппаратной проверки ELF014 и
совпадением прошивки 0x13600007; savesRestore всегда false.

## Видимость списка в WEB — 2026-10-10

Сверен актуальный ps5upload main `7f724d3399f37d930aa420aaf15af66cc6f4edb9`
(`payload/src/runtime.c`, `client/src/screens/Saves/index.tsx`). Upstream
обходит исходные hex-имена всех пользователей, читает отдельно
savedata_prospero и savedata, затем группирует записи по Title ID. Наш ELF014
уже читает оба корня и на реальной приставке отдаёт 14 записей (9 native,
5 legacy); замена ELF для исправления отображения не требуется.

WEB загружает список с PS5 независимо от списка локальных резервных копий:
ошибка копий отображается отдельно и больше не прерывает чтение сохранений.
При обновлении старые строки снимаются с экрана, при ошибке нет ложного
пустого успешного списка. Добавлены группировка по игре, все пользователи
по умолчанию, отдельные фильтры платформы/пользователя, счётчик показано/всего
и PS5/PS4. Пустая приставка отличается от списка, скрытого фильтром; доступны
сброс фильтров и «Показать все сохранения». Переход из бокового меню очищает
фокус игры, установленный переходом из раздела «На консоли».

Регрессия проверяется через скомпилированный script setup настоящего
Ps5ConsoleSaves.vue: отказ списка копий, группировка двух пользователей
одной игры, комбинация фильтров, изменение/очистка фокуса игры и снятие
старых строк при ошибке обновления. Изменения касаются WEB, исходные
сохранения на PS5 не изменяются.

Обновление WEB применено на существующем GAMEPAD-PC, build
`d7e1d64150c0`, ZIP SHA-256
`48e02533c837e5a43452c148c473a8b16a8cdfeb4a4004edbdfc6d29f525b417`.
Предыдущая сборка сохранена; библиотека до/после содержит 603 игры.
Браузер подтвердил 14/14, фильтр PS5 — 9/14, PS4 — 5/14; поиск отсутствующего
Title ID показывает кнопку «Показать все сохранения», которая возвращает
14/14. Ошибок в списке нет; профиль PS5 оставлен выбранным. Исходные сейвы,
резервные копии и ELF014 не изменены. Nuxt build, тест настоящего Vue view,
PS5 management, console save ownership, console catalog и game details прошли.
