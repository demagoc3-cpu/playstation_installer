# Next development steps

[← Contents](index.md) · [Русский](../ru/roadmap.md)

These are planned features, not current capabilities.

1. Validate 1.68 on PS4: card progress/cancellation, system keyboard and persistent pairing revocation; fix findings.
2. Connect native On console to the existing installed-app inventory/control API.
3. Persist favorites and editable game packs. A pack references library package IDs; it does not copy PKGs. Install packs sequentially.
4. Introduce an external JSON catalog API for covers, descriptions, versions, patches, DLC and permitted magnets. Keep internal WEB library and external sources distinct.
5. Research a PS4 torrent client with resume, disk/network limits and installation through the same daemon. WEB and PS4 downloads stay separate sources.
6. Add multiple PS4s: connected-console inventory, recipient selection, independent queues and installation of one pack on several consoles.

Remote screen/Internet tunnel work is paused and the placeholder section has been removed from WEB. Automatic HEN activation by the unsigned PKG is not implemented.
