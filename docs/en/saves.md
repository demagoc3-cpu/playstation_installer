# Save backups and restoration

[← Contents](index.md) · [Русский](../ru/saves.md)

WEB → Saves lists console users, games and save slots through the paired service.

1. Select the user, game and slot. Close the game before modifying its save data.
2. Create a backup for one slot or Create game backup for all slots. Download the copies as ZIP archives to your computer.
3. Choose a stored backup and Restore. Current save files are copied first for rollback.
4. Launch the game and check its progress. Select Game reads save to finalize, or Return previous to restore the pre-restoration save. Close the game before rollback. Finalizing removes the temporary rollback on PS4, not downloaded backups.

Do not disconnect PS4 or close WEB during an operation. If communication fails, check operation state before repeating it. Keep the WEB data folder and downloaded backups during upgrades. Removing an installed game does not remove its saves.

This is backup/restore of supported save files, not a universal converter between arbitrary accounts or game versions. Do not rename slots manually in Files.
