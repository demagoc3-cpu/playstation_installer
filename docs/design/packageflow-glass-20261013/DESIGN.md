## Как читать картинки

Картинки — направление оформления, а не источник контрактов API, идентификаторов,
платформ, размеров, версий и доступных операций. Их данные иллюстративны.
В генерациях есть ошибки: generic P вместо PF, лишние/повторённые пункты меню,
PS4 помеченная EXFAT, условные ISO, выдуманные размеры. Не переносить эти ошибки.
Нативные обзорные картинки также ошибочно унаследовали WEB-меню; обязательный
список приложения приведён ниже. Спецификация и существующий код имеют приоритет.

Все изображения лежат рядом с этим файлом. `web-*.png` — WEB, `native-*.png` —
приложение. `*-board.png` — четыре экрана на одной картинке, слева направо,
сначала верхний ряд. Сначала прочитать подписи и правила, затем смотреть макеты.

## Общий визуальный язык

- Фон #071122 / #0B1730, мягкое атмосферное свечение синего и фиолетового.
  Artwork выбранной игры допустим в каталоге; служебные страницы — спокойный фон.
- Поверхности: тонированное стекло rgba(18,34,61,.82), светлая тонкая граница
  rgba(151,193,255,.20), радиус карточек 16–20 px. Blur только в нужных слоях,
  не десятки полных экранов. Текст не должен теряться на artwork.
- Основное действие — градиент #35C9FF → #7863FF. Focus — чёткий контур,
  цвет дополняет текст/иконку. Ошибка, ожидание и успех различаются словами.
- Не перегружать свечение. На длинных таблицах важнее читаемость и плотность.
- Размеры, свободное место, скорость и завершение — исключительно реальные данные.
  100% передачи не означает установленную или зарегистрированную игру.
- Сохранить состояния loading, empty, offline, stale, error, busy, unsupported,
  unknown result. Никаких фиктивных кнопок или сообщений об успехе.
- Анимации короткие и необязательные; учитывать reduced motion. Сеть, диск,
  декодирование обложек и клавиатура не блокируют отрисовку.

## WEB: все разделы

Постоянное меню: Библиотека, На консоли, Сохранения, Загрузки, Поиск, Журнал,
Задания, Пресеты, Хранилище, Устройства, Настройки, Файлы, О системе, Поддержать.
Последний раздел сохраняет существующее условие наличия настроенных адресов.

| Раздел | Что должно остаться доступно |
|---|---|
| Библиотека | Поиск/фильтры/форматы, страницы, сетка и таблица, ветки игра/патчи/DLC, галочки, избранное, массовая установка, пресеты |
| На консоли | Выбор устройства, PS4/PS5 адаптеры, зарегистрированные игры и исходные файлы, сведения, доступные команды и подтверждения |
| Сохранения | Профиль/игра, список, резервные копии и только подтверждённые восстановление/экспорт |
| Загрузки | qBittorrent, настройка подключения, magnet/torrent, файлы/приоритеты, пауза/продолжение, доступная автоустановка |
| Поиск | Источник, категории PS4/PS5, компактный поиск, результаты/пагинация, скачивание |
| Журнал | События, ошибки, повторения, время, очистка; без раскрытия ключей |
| Задания | Отдельные очереди всех устройств, этапы/скорость, история, дерево/таблица, выбор, отмена/удаление записей, PS4 переустановка |
| Пресеты | Создание/изменение, состав, доступность, импорт/экспорт, установка набора |
| Хранилище | Локальные/SMB/NFS/WebDAV источники, подключение, индексация, статус/отмена |
| Устройства | Онлайн/сопряжение для каждой приставки, версии, добавление/редактирование, тест скорости и обновление компонентов |
| Настройки | Все существующие настройки и проверки, языки, методы установки и интеграции |
| Файлы | Выбранная приставка, навигация, реальные разрешённые операции, ошибки и журнал результатов |
| О системе | Корректные данные выбранной платформы; не подставлять PS4 telemetry для PS5 |
| Поддержать | Настроенные кошельки/сети, существующие QR, копирование и предупреждения |

В шапке нет «единственной сопряжённой PS»: сопряжение принадлежит устройству.
При выборе устройства меняется только соответствующий контекст. Многоприставочные
очереди через службу; PyLoader сохраняет свою отдельную модель.

Адаптация: широкий desktop, ноутбук 1366×768, планшет и телефон 390 px. На узких
экранах все пункты остаются в открываемом меню; таблицы прокручиваются в своём
контейнере, кнопки и модалки доступны без горизонтального скролла всей страницы.
Сохранять keyboard navigation, фокус, семантику и существующие aria/status.

## PS5-приложение: фактическое меню

В порядке `ui_menu_order`: **Каталог, Избранное, Пресеты, Задания, Загрузки,
Файлы, На консоли, Настройки, Подключения, Поддержать**.
Поиск вызывается △ внутри каталога; не заменять его WEB/Torznab поиском.
В настройках есть «О приложении». WEB-файлы и файлы PS5 — разные источники;
приложению нельзя обещать консольную запись, если её backend не реализован.

Сохранить каждый экран, переход, окно, клавиатуру и настройки существующей версии.
Устанавливаем на эту PS5 (профиль от службы), а не переключаем чужую приставку
в интерфейсе приложения. В каталоге PS5 возможны совместимые PS4 пакеты —
платформа пакета и назначение установки не одно и то же.

TV: виртуальный layout 1920×1080, адаптировать к реальному VideoOut; важный текст
не мельче ~22 px, заголовки 32–44 px, фокус виден на расстоянии. Проверить 1080p
с живым DualSense. Не выдавать картинку 4K за аппаратно подтверждённый рендер 4K.
Сохранять фактические shortcuts (△ IME, L2 фильтры, R3 сведения, L3 избранное,
L1/R1 страницы, R2 вид, Options подтверждение, ○ назад) и корректный возврат фокуса.

## Приёмка

Красивый скриншот не заменяет функциональную проверку. Сравнить старую и новую
версию по таблице функций; привести evidence для каждого пункта. Состояния и API
не меняются ради оформления. Host/build/настоящий HTTP/аппаратные результаты
перечисляются отдельно. Пока PS5 недоступна или запуск не подтверждён, это честно
отмечается, qualification flags автоматически не включаются.

## Реализованные рабочие страницы — 2026-10-13

В `implemented/` сохранены снимки действующего WEB. «Сохранения» — таблица,
выбор записи и панель копирования/восстановления; именные наборы PS4 сохранены.
«Загрузки» — фильтры, таблица, управление файлами, автоустановка и путь загрузок.
«Поиск» — компактная форма, таблица/сетка, источники и прежняя подробная карточка.
«Журнал» — уровни, поиск и раскрываемые детали. «Задания» — карточки передачи,
этапы, отдельные очереди и сводка устройств. «На консоли» — сетка/таблица,
табличные источники и боковая панель выбранной игры. Источник вне текущей вкладки
снимается с выбора; неизвестный результат команды не повторяется.

Скриншоты `active-cards-fixture-*` используют явно обозначенные искусственные
данные в отдельном тесте вёрстки. Они не доказывают аппаратную скорость.
Передача ещё не начинается на этапе проверки исходного файла; установка и
регистрация не считаются завершёнными только из-за заполненного индикатора.
Все значения берутся из API; отсутствующие размеры, метрики или команды
не подменяются примерами макета. WEB остаётся общим для PS4 и PS5.

Production-сборка и семь профильных тестовых файлов проходят. На ширине 390 px
проверены все шесть страниц без переполнения документа. Длинный путь qBittorrent
переносится; пустые таблицы читаемы без горизонтального пролистывания.
