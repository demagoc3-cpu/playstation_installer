# Установка PKG из «Файлов» — исправление 1.56

## Причина отказа Stray

PKG CUSA24899 версии 01.04 содержит CATEGORY=gd и флаги заголовка 0x6a700000. Полный пакет (REMASTER 0x00400000) может одновременно содержать признаки патча. Проверка в службе учитывала только признаки патча и ошибочно отвергала игру до регистрации задания.

Теперь REMASTER имеет приоритет при проверке типа полного пакета. Такая же логика применяется к сведениям о типе тома в WEB. Источник описания флагов: [LibOrbisPkg](https://github.com/maxton/LibOrbisPkg/blob/master/PS4PKG.bt).

## Ответы WEB

- Служба сохраняет HTTP 403/422 для отказов проверки вместо подмены на HTTP 500.
- Явный отказ службы завершает новую команду с исходной причиной, в том числе для старых сборок с неверным HTTP статусом.
- При потерянном ответе WEB проверяет номер новой команды; её отсутствие не заменяет исходную ошибку текстом о «прежнем задании». Автоматически повторная установка не отправляется.
- Недоступная служба сообщает об отсутствии связи; WEB не предлагает обновление версии только из-за выключенной консоли.

## Проверено

Локальные проверки обычной игры, обычного патча и полного пакета с флагами Stray; восстановление состояния команды после потерянного ответа; сохранение исходного отказа HTTP 500/422. Сборки WEB и PKG прошли.

PKG 1.56 установлен на PS4, системное задание 530 подтверждено. Во время ручного запуска службы пользователь сообщил о выключении консоли. Последующая проверка WEB не получила доступную службу; новая команда установки Stray не отправлялась. Проверка на 1.56 была остановлена. После восстановления журнала и запуска 1.57 Stray установлен с диска, задача 534 подтверждена PS4; подробности в [files-1.57.md](files-1.57.md).
