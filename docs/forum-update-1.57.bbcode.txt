[size=4][b]PackageFlow — обновление файлового менеджера и PackageFlowService 1.57[/b][/size]

Доработан раздел [b]«Файлы»[/b]: теперь через WEB можно управлять файлами PS4 и устанавливать PKG, которые уже находятся на диске консоли. Для работы используется наш PackageFlowService; отдельный FTP-сервер не требуется.

[b]Что нового[/b]
[list]
[*]Создание папок, переименование, копирование и перемещение файлов и папок. Можно выбрать сразу несколько элементов.
[*]Корзина с возвратом на прежнее место. При замене файла сохраняется его предыдущая версия.
[*]Безвозвратное удаление выбранных файлов и папок, удаление отдельных копий из корзины и кнопка «Очистить корзину». Перед удалением показывается список для подтверждения.
[*]Редактор текстовых файлов UTF-8 до 128 КиБ: TXT, JSON, INI, CFG, CONF, XML, YAML, LOG, CSV, MD. Перед сохранением проверяется, что файл не изменился; предыдущая версия сохраняется.
[*]Ускорена загрузка с компьютера на PS4: в новых версиях службы увеличен размер передаваемого фрагмента. Пауза и докачка после обрыва связи сохранены.
[*]Установка PKG прямо из «Файлов»: игры, патчи и DLC из /data, /user/data или с USB. Не нужно повторно передавать весь пакет через компьютер. Исходный PKG остаётся в папке.
[*]Уведомления об операциях автоматически скрываются. Завершённые и прерванные задания доступны по кнопке «История операций».
[*]В разделе «Поддержать» QR-коды скрыты по умолчанию: при выборе одного кошелька второй QR не показывается.
[/list]

[b]Исправления в 1.57[/b]
[list]
[*]Исправлено распознавание полных пакетов, объединяющих игру и обновление: такой PKG больше не отклоняется как обычный патч при установке с диска.
[*]WEB показывает исходную причину отказа новой команды вместо ошибочного сообщения о «прежнем задании».
[*]Добавлен резервный снимок журнала установок. Если основной журнал повреждён, служба загружает проверенную резервную копию без автоматической повторной отправки установок. При повреждении обеих копий установка блокируется.
[*]Недоступность службы больше не выдаётся в «Файлах» за необходимость обновить её версию.
[/list]

[spoiler=Как обновиться и пользоваться]
[b]Обновление[/b]
1. Обновите WEB PackageFlow. Для Docker обновите образ и пересоздайте контейнер с прежним постоянным volume.
2. Установите [b]PackageFlowService 1.57[/b]. В WEB: «О системе» → «Выбрать PKG на компьютере» → «Установить обновление на PS4».
3. После установки перезагрузите PS4, активируйте используемый jailbreak/HEN и откройте PackageFlowService вручную. Дождитесь готовности службы; запускатель закроется автоматически. Ключ сопряжения при обновлении сохраняется.

[b]Установка PKG с диска PS4[/b]
1. Откройте «Файлы» и папку с полностью загруженным PKG.
2. Нажмите «Установить» возле нужного файла.
3. WEB прочитает сведения о пакете, проверит его размер, требования к прошивке и свободное место.
4. Нажмите «Установить на PS4». Прогресс и отмена доступны на странице, результат — в истории.

[b]Копирование и перемещение[/b]
Отметьте элементы → «Копировать» или «Переместить» → откройте папку назначения → «Вставить сюда». Для продолжения прерванной операции используйте прежнее задание в истории.

[b]Корзина и удаление[/b]
«В корзину» позволяет вернуть файл или папку. «Удалить» удаляет безвозвратно после подтверждения. В корзине можно удалить отдельную копию либо очистить выбранный список целиком.
[/spoiler]

[b]Полезно знать[/b]
[list]
[*]Изменения файлов доступны в /data и на USB. Системные области и служебные файлы защищены. Игры удаляйте через «На консоли», сохранениями управляйте в «Сохранениях».
[*]Корзина и предыдущие версии занимают место на PS4. Их каталог и история операций хранятся в данных WEB — сохраняйте каталог .data или Docker volume. Для возврата копии с USB нужен исходный накопитель.
[*]Во время фоновых файловых операций WEB должен работать. После перезапуска WEB прерванное задание можно продолжить из истории.
[/list]

[b]Проверено на PS4 Pro с прошивкой 12.50:[/b] файловые операции, докачка, редактирование, корзина, удаление и установка Stray CUSA24899 версии 01.04 из локального PKG размером около 6,1 ГиБ. PS4 подтвердила установку, исходный пакет остался на месте. Работа с физическим USB в этом этапе не проверялась.
