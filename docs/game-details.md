# Сведения об игре

WEB: наведите мышь только на название игры в библиотеке. При навигации
мышью панель открывается справа от текущей точки курсора и следует за ним
в пределах названия. При входе в саму панель положение сохраняется,
чтобы можно было нажимать вкладки. У края экрана размеры и положение
ограничиваются видимой областью. Положение не зависит от ширины строки игры.
При навигации
клавишей Tab панель открывается на фокусе названия. Панель можно просмотреть,
переключить на список пакетов и закрыть крестиком или Escape. Прокрутка
работает внутри панели; колесо над ней не прокручивает страницу библиотеки.
Обложка, метаданные и цветные теги строки не открывают панель. На сенсорном
экране касание названия открывает сведения вместе с существующим списком.

В обзоре показаны платформа, формат, подпись, Title ID, Content ID, версии,
требуемая прошивка, SDK, категория, имя файла и размер. Выбран основной пакет;
при нескольких базовых вариантах выбор устойчив по порядку установки, имени
файла и ID. Это размер выбранного файла/папки источника, а не размер игры
в системном хранилище приставки. Размер базового пакета не включает патчи и DLC. Если базы нет,
панель прямо сообщает, что описывает первый пакет ветки.

Пустые поля обозначены «—». Требуемая прошивка — метаданные источника,
а не гарантия запуска. Отметки WEB не выдаются за проверку системной базы
приставки. Регион, DRM, языки и дата сборки не выводятся, пока источник
библиотеки не предоставляет эти данные.

Для приложения PS5 предусмотрено совместимое дополнение catalog/v2:
`games[].details` (необязательный объект). Контракт:

```ts
{
  packageId: string; hasBase: boolean;
  titleId: string; contentId: string; fileName: string;
  platform: 'ps4' | 'ps5' | 'unknown';
  format: 'pkg' | 'folder' | 'ufs2' | 'exfat' | 'pfs' | 'ffpfsc' | 'unknown';
  signature: 'fake' | 'retail' | 'unknown';
  version: string; masterVersion: string;
  firmware: string; sdk: string; category: string; size: number;
}
```

Объект содержит только разрешённые поля, без путей, ключей и конфигурации
сервера. Старый catalog/v1 и прежние поля v2 сохраняются. Панель приложения PS5 реализована Claude и проверена пользователем в 040:
выделение игры показывает сведения, R3 скрывает панель.

В строках игр и пакетов есть отдельные цветные теги: PS4 — синий, PS5 —
фиолетовый; PKG — бирюзовый, Folder — янтарный, UFS2 — зелёный, exFAT —
голубой, PFS — розовый, FFPFSC — индиго. Текст сохраняет смысл без различения
цветов. В строке игры перечисляются форматы её пакетов без повторов.
