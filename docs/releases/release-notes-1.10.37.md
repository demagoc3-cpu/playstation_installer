# PackageFlow 1.10.37 · PS5 service 030i

Режим покоя PS5, продолжение застрявшей передачи, понятная ошибка при нехватке места и очистка временных файлов отменённых передач. Новая служба PS5 сборки 030i с отчётами о падениях.

Релиз 1.10.36 был собран с более ранней версии и этих изменений не содержит. Устанавливайте 1.10.37.

## Служба PS5 030i

- Если служба упадёт, она сохранит короткий отчёт: сигнал, адрес и операцию, которая шла в этот момент. Хранятся последние пять отчётов. Ключи, токены и пути к файлам в них не попадают.
- Отмена неполной передачи удаляет её временный файл на приставке. Если пакет уже отдан установщику, файл не трогается.
- Ошибка записи из-за нехватки места больше не останавливает службу. Задание получает ответ «нет места».
- Если API ShadowMount не отвечает, служба сообщает об этом. Список игр показывается из системной базы.

## Очередь установки PS5

- PS5 в режиме покоя отображается как «В режиме покоя», а не «Нет связи». Спящую приставку не опрашивают и не запускают на ней службу. Очередь ждёт её пробуждения.
- Если передача стоит без движения 90 секунд, она сама продолжается с места, которое PS5 уже подтвердила. Установка повторно не отправляется.
- Если на PS5 нет места, задание завершается ошибкой «На PS5 нет места» и отправка не повторяется бесконечно.
- Задание, убранное из очереди во время паузы или до своей очереди, теперь отменяется и на приставке. Временные файлы старых отменённых передач, которые не дошли до установки, удаляются автоматически, когда приставка на связи. Принятые установщиком задания не трогаются.
- Упавшую службу PS5 можно снова запустить, даже если в очереди осталось незавершённое задание.

## Исправления

- Если API ShadowMount не отвечает, вкладка игр показывает зарегистрированные игры с предупреждением «API ShadowMount недоступен». Раньше вместо списка была общая ошибка.
- Если ShadowMount на PS5 завис, окно установки называет причину: «ShadowMount на PS5 не отвечает» и что сделать. Раньше было непонятное «Установка этого формата ещё не подтверждена сервисом». PKG при этом ставятся как обычно.

## Обновление

Установите новую версию поверх существующей, предварительно дождавшись завершения активных заданий. Настройки, библиотека и сопряжение сохраняются. Затем обновите службу на каждой PS5: «Устройства» → «Сервис ▾» → «Проверить обновления».

## Проверено

Тесты сервера WEB (501) и службы PS5 на компьютере, сборка службы на GitHub.

На PS5-Жека 13.60 со службой 030i из CI проверены:
- запуск и штатный перезапуск, служба стабильна;
- отчёты о падениях: хранилище открывается, ложных отчётов нет;
- список из 23 игр и системный каталог;
- готовность установки всех форматов (без новой установки) и список сохранений;
- тест скорости в обе стороны и записи на диск;
- отмена неполной передачи удаляет временный файл.

Новые установки, запуск игр и восстановление сохранений на 030i не проверялись. На 12.20 сборка 030i не проверялась. Режим покоя и автоматическая очистка временных файлов из WEB на приставке ещё не проверялись.
