# PackageFlow 1.10.34

Исправления очереди установки на PS5. Файлы для приставок те же, что в 1.10.33.

## Очередь PS5

- Во время установки игры в очередь снова можно добавить другую игру. Раньше окно «Установить на устройства» опрашивало PS5, пока она принимала пакет; приставка не успевала ответить и становилась недоступной для выбора. Теперь во время передачи используется последнее подтверждённое состояние приставки. Кнопка «Проверить» в «Устройствах» по-прежнему опрашивает приставку напрямую.
- Подтверждение состава очереди больше не сбрасывается, если текущий пакет завершился, пока вы выбирали игры.
- Последний DLC в очереди подтверждается, когда системный установщик прочитал его целиком без ошибки. Раньше он оставался без подтверждения, хотя был установлен.

## Обновление

Установите новую версию поверх существующей, предварительно дождавшись завершения активных заданий. Настройки, библиотека и сопряжение сохраняются. Службы и приложение на приставках обновлять не нужно, если на PS5 уже стоит служба 029e.

## Проверено

Тесты сервера, в том числе новые для подтверждения последнего DLC и для проверки приставки во время передачи; проверка типов и ESLint. На приставке эти изменения не проверялись.
