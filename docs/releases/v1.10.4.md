# PackageFlow v1.10.4

Самостоятельное обновление сервиса на PS4, Windows-установщик с мастером настройки и доработки подключения, поиска и библиотеки.

**Версии компонентов:** Windows-установщик **1.10.6**, PackageFlowService для PS4 **1.92**. Версия установщика определяется отдельно от тега релиза.

## Сервис PS4

- Проверка GitHub, загрузка и установка обновлений непосредственно на PS4 через **«Настройки → Обновить»**, без запущенного WEB. Обновление через WEB сохранено.
- Прогресс загрузки, проверка размера, SHA-256 и версии PKG; автоматическое закрытие интерфейса перед установкой и запуск после успешного обновления.
- Исправлены ошибки HTTPS, перенаправлений и корневых сертификатов при работе с GitHub; доработано восстановление состояния обновления.
- При смене компьютера актуальный адрес WEB передаётся сопряжённой PS4 и подхватывается без перезапуска интерфейса.
- Сохранение данных поддержки при временных ошибках соединения; новые изображения BTC и Tether.

## Windows-установщик и мастер

- EXE для **Windows 10/11 x64** со встроенными WEB, Node.js и .NET. Режимы Windows и Docker Compose.
- Автоматическая подготовка WEB, Prowlarr, FlareSolverr и qBittorrent при первом запуске; продолжение прерванной настройки и повторная подготовка компонентов.
- Отдельный профиль qBittorrent для нового подключения; сохранение уже настроенного подключения.
- Статусы WEB, сопряжения, qBittorrent, Prowlarr и FlareSolverr; этапы настройки, проценты загрузки и журнал событий.
- Автозапуск, трей, ярлык на рабочем столе и обновление Windows-приложения из GitHub с проверкой файла и безопасной остановкой.
- **«Применить»** сохраняет настройки и индексирует выбранную папку. Выбор папок кнопкой, отображение сохранённых данных и переключатель видимости паролей.
- Иконки, карточки, закруглённые кнопки, адаптация уменьшенного окна; исправлены артефакты перерисовки и ошибка выпадающего меню. Логотипы 4PDA/GitHub, версия WEB и звёзды репозитория в шапке.
- Исправлена упаковка установщика в GitHub Actions. Сборка Windows независима от Docker workflow; добавлены инструкции локальной сборки.

## Первоначальная настройка PS4

- **«Найти PS4»** обнаруживает приставки в локальной сети, показывает доступность сервиса/PyLoader и сохраняет возможность ручного ввода IP.
- **«Установить сервис»** скачивает проверенный PKG и отправляет его через PyLoader без предварительного сопряжения.
- Требуются включённые **GoldHEN и PyLoader, порт 9090**. Передача файла не заменяет проверку итоговой установки: дождитесь завершения в **«Уведомления → Загрузки»**, запустите PackageFlow и выполните сопряжение.

## Поиск и библиотека

- Ручной вход RuTracker при капче: отдельное окно Chromium ждёт подтверждения пользователя, после чего индексатор Prowlarr проходит собственный Test. Доступно при локальной настройке Windows.
- Доработаны повторное использование прокси и браузерной сессии, обработка блокировки проверочного сайта Prowlarr.
- HTTP и кэш описаний/обложек используются перед FlareSolverr; фоновая подготовка карточек не открывает браузер.
- Сортировка по новинкам и **«Показать ещё»** для индексаторов с поддержкой страниц.
- **Снят предел в 500 пакетов:** полное сканирование PKG/FPKG во вложенных папках. Проверено на 800 пакетах, повторном сканировании и добавлении 801-го; сохранены стабильные ID и отметки установки.
- Обновлены README, документация RU/EN, скриншоты мастера и баннер проекта.

## Обновление

Установите `PackageFlowSetup-1.10.6-x64.exe` поверх текущей версии. Настройки и данные сохраняются. После обновления нажмите **«Применить»**, чтобы повторно просканировать папку без прежнего ограничения.

PS4: **«Настройки → Обновить»**, обновление через WEB или ручная установка `PackageFlowService-1.92.pkg`. Перед обновлением завершите активные установки и передачи. Docker Desktop устанавливается отдельно.
