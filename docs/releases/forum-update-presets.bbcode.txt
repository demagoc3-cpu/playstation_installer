[size=3][b]PackageFlow: пресеты, общие задания и сервис PS4 1.95[/b][/size]

[b]Пресеты.[/b] Теперь можно собирать свои подборки: «Гонки», «Для двоих», «Пройти позже». Название и описание вводятся в отдельном окне. Карточки показывают до пяти обложек, количество игр, файлов и общий размер. Устанавливайте весь пресет или отмеченные пакеты из WEB и PS4. Доступны редактирование, импорт и экспорт списка; PKG в файл пресета не включаются.

[b]Библиотека.[/b] Больше места для игр: сопряжение и способ установки перенесены в «Настройки». Загружается только текущая страница — 25/50/100 игр; прокрутка внутри списка, поиск остаётся на месте. Поиск по названию находит всю ветку игры с патчами и DLC. «Передано PS4» учитывает выбранные файлы.

[b]Задания.[/b] Единое дерево как в библиотеке или таблица, активные задания сверху, фильтры состояний. Можно отменить один пакет, снять ожидающий из очереди галочкой, отменить очередь и очистить завершённые записи и ошибки. Сохраняются десять предыдущих очередей. Убрана фиолетовая заливка строк, возвращены привычные шрифты и цвета статусов.

[b]На PS4.[/b] Избранное сохраняется между запусками и обновлениями, есть установка всего списка. У пресетов новый значок контейнера и кнопка установки. [b]R2[/b] переключает 10/20/30 карточек; в заданиях [b]L1[/b] очищает завершённые и ошибки, [b]R1[/b] меняет страницы. Добавлены компактные строки и фильтры.

Обновите WEB и установите [b]PackageFlowService 1.95[/b]. WEB доступен через Windows EXE с мастером настройки, Docker Compose и исходники. ПК/NAS должен работать при установке пакетов из его библиотеки.
