## Подготовленный архив

Локальный архив: `output/publication/PackageFlow-PS4-screenshots-2026-10-10.zip`.
Распакованный набор: `output/publication/ps4-screenshots-2026-10-10/`.
Каталог `output/` исключён из Git; существующие изображения не дублируются в истории.

В архиве шесть изображений с нумерацией, README с подписями, BBCode с существующими
ссылками релизного тега, манифест происхождения и размеров, а также SHA-256 файлов.
Три исходных WEB-файла названы `.png`, но содержат JPEG. В архиве их расширение
исправлено на `.jpg` без перекодирования. Остальные изображения сохранены как PNG.

Загрузите изображения в сообщение форума и вставьте их через редактор, сохраняя
подписи. Код вложений назначит форум после загрузки. Готовые ссылки из файла
`screenshots.bbcode.txt` можно использовать вместо форумных вложений.

Архив проверен на целостность, изображения в нём побайтово совпадают с исходниками.
Материалы подготовлены локально; на форум и в GitHub ничего не загружено.
