## Как вставить на форум

1. Прикрепить PNG к первому сообщению темы и вставить изображение в начало
   шапки штатной кнопкой форума. В заготовке нет выдуманного номера вложения
   и ссылки на ещё не опубликованный баннер.
2. Скопировать содержимое файла `.bbcode.txt` в режим BBCode редактора под баннером.
3. Посмотреть предпросмотр: раскрываются ли спойлеры, читается ли баннер,
   открываются ли ссылки на EXE/PKG и скриншоты.
4. Если шапка должна содержать только доступные функции, убрать целиком спойлер
   «Что готовится для PS4: пока не опубликовано». Остальной текст описывает
   опубликованный выпуск.

Материалы подготовлены локально. Сообщение на 4PDA не редактировалось, файлы
на форум не загружались, коммиты в GitHub не отправлялись.

## Содержание шапки

- Описание программы и маршрут PKG от ПК/NAS до приставки.
- Библиотека, установка игры/патчей/DLC, очередь, отмена и история.
- Пресеты, импорт/экспорт и избранное.
- Нативное приложение PS4, системная клавиатура и кнопки геймпада.
- Установленные игры, запуск/остановка, удаление и сведения о системе.
- Файлы, докачка, копирование, редактор, корзина и локальная установка PKG.
- Резервные копии сохранений, ZIP, восстановление и откат.
- Prowlarr/Jackett, qBittorrent и установка после скачивания.
- Требования, LAN-адреса и порты.
- Windows EXE, поиск PS4, сопряжение, Firewall, трей, автозапуск и обновления.
- Отдельные инструкции Compose для Linux/NAS и режима Windows-мастера.
- Запуск из исходников опубликованного тега, FAQ и скриншоты.
- Явно отдельный блок ещё не выпущенных изменений для PS4.

## Что проверено

Публичный [релиз v1.10.7](https://github.com/demagoc3-cpu/playstation_installer/releases/tag/v1.10.7)
проверен через GitHub API 2026-10-10: опубликован 2026-10-07, не draft/prerelease,
содержит `PackageFlowSetup-1.10.7-x64.exe`, `PackageFlowService-2.01.pkg` и
файлы контрольных сумм. Функции сверены с документацией и исходниками тега
`v1.10.7` (`84c7422`), а не только с рабочей веткой, где уже есть новые изменения.

Docker Hub API подтвердил `demagoc3/packageflow:latest`, Linux amd64/arm64,
последнюю публикацию 2026-10-07. `latest` — изменяемый тег, он не привязан
в тексте к номеру Windows EXE. Образ при подготовке материала не скачивался
и не запускался.

Заголовок темы и раскрытые разделы старой шапки прочитаны в браузере.
Основные недостатки прежнего текста: отсутствуют установщик Windows и Compose,
пресеты, актуальные возможности приложения PS4, подробности файлов/сохранений.
Уточнена лицензия: MIT относится к WEB, исходники службы PS4 не публичны.

BBCode проверен на баланс тегов; все шесть скриншотов существуют в указанном
релизном теге. YAML минимального Compose разобран и проверен: host network,
фиксированный callback 3001, отдельный том данных, read-only папка PKG.
Запуск Compose на чистом NAS/Windows и отображение в редакторе 4PDA этим
исследованием не проверялись. Баннер визуально проверен: шесть функциональных
групп, схема компонентов, корректные подписи и отсутствие анонсов других платформ.

Множество приставок, параллельные установки, скорость/объём возле прогрессбара
и новый раздел «Хранилище» оставлены только в блоке будущего выпуска. На баннере
их нет. Возможности обновления службы и установки PKG не объявлены гарантией
запуска произвольной игры или совместимости любой прошивки.
