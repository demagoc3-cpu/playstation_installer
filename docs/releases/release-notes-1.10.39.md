# PackageFlow 1.10.39

Очистка остатков на PS5, уведомления о новых версиях, сведения о свободном месте в очереди и обновлённое оформление интерфейса. Изменения после 1.10.38.

## Очистка PS5

- В разделе «На консоли» появилась вкладка «Очистка».
- Можно найти остатки, созданные PackageFlow: недокачанные передачи, неопубликованные Folder и образы, остатки после установки и регистрации игр без файлов.
- Показаны возможный объём освобождения и причины, по которым отдельные элементы нельзя удалить.
- Удаление выполняется после подтверждения. Для регистраций игр без файлов диалог перечисляет Title ID.
- Передачи незавершённой очереди защищены от удаления. При потере ответа команда очистки повторно не отправляется: WEB уточняет результат у приставки.

Для очистки требуется **служба PS5 030j или новее с поддержкой этой функции**. Установленные игры и сохранения в список очистки не входят. Перед удалением служба повторно проверяет каждый выбранный элемент.

## Уведомления об обновлениях

- В верхней панели появился колокольчик с уведомлением о новой версии PackageFlow и ссылкой на релиз. Непрочитанное уведомление отмечено точкой.
- В настройках доступны установленная и последняя версии, кнопка «Проверить сейчас» и переключатель автоматической проверки.
- Автоматическая проверка включена по умолчанию: первый запрос выполняется через 30 секунд после запуска сервера, следующие — каждые шесть часов.
- Загрузка и установка обновления выполняются пользователем.

Уведомления относятся к самому PackageFlow. Для сравнения нужна известная установленная версия: установщики Windows и Linux сохраняют её в `release.json`. При запуске из исходников или Docker без указанной версии автоматическое сравнение недоступно.

## Задания

- У активной приставки отображаются общий объём незавершённых пакетов очереди и последнее известное свободное место, если способ установки поддерживает проверку места.
- Если расчётного места недостаточно, появляется предупреждение «может не поместиться».
- «Ждёт установки» включает полный размер текущего пакета и следующих незавершённых пакетов. Это предварительная оценка; проверка места перед установкой сохраняется.

## Интерфейс и исправления

- Пресеты, хранилище и диалоги устройств приведены к общему стеклянному оформлению.
- Улучшены кнопки, подсветка при наведении и расположение кнопок закрытия.
- Кнопка «Открыть» для PS5 открывает страницу PLDMGR на порту `8084` и выбирает эту приставку для управления.
- Исправлено обрезание строки прогресса в тесте скорости.
- Убраны дублирующие карточки переходов из настроек. Настройки qBittorrent и источника поиска доступны из разделов «Загрузки» и «Поиск».
- Устранены предупреждения сборки WEB о ключах компонентов, дублирующем экспорте и записи BigInt.
- Исправлена проблема сборки AppImage из-за изменившегося runtime: закреплена конкретная версия с проверкой контрольной суммы.
- Исправлена обработка ожидаемых ошибок API в режиме разработки, вызывавшая ошибки недоступности dev-сервера.

## Обновление

Перед обновлением дождитесь завершения активных заданий. Установите новую версию поверх существующей: настройки, библиотека и сопряжение сохраняются.

Для новой очистки PS5 нужна служба 030j или новее. Обновление WEB само по себе не обновляет службу на приставке.

## Проверено

На компьютере прошли тесты уведомлений об обновлениях, очистки PS5 и расчёта очереди, а также выбранные регрессионные тесты библиотеки, окна установки и представлений игр и сохранений PS5. Vue-шаблон компилируется; переключение разделов PS5 «На консоли» и «Сохранения» проверено в браузере при недоступной приставке.

Очистка на реальной PS5 и итоговые сборки Windows/Linux этого выпуска пока не проверены. Host-тесты используют тестовые данные и не подтверждают аппаратную готовность службы.
