# Материалы обновления

## Подготовка выпуска 1.10.39

- [Описание GitHub Release 1.10.39](release-notes-1.10.39.md).
- Автоматизация выпуска: [`.github/workflows/release.yml`](../../.github/workflows/release.yml).

Workflow запускается при push тега `vX.Y.Z`. Для `v1.10.39` он создаёт релиз
с заголовком `PackageFlow 1.10.39` и читает описание из
`docs/releases/release-notes-1.10.39.md` в коммите этого тега. Файл должен быть
закоммичен до создания тега. Обычный push ветки `main` релиз не запускает.

После коммита описания и остальных изменений выпуска:

```bash
git tag -a v1.10.39 -m "PackageFlow 1.10.39"
git push origin main v1.10.39
```

Сначала workflow готовит комплект для приставок, затем создаёт релиз и
прикрепляет этот комплект. После этого сборки Windows и Linux добавляют
установщик EXE, пакеты DEB/AppImage и контрольные суммы в тот же релиз.
Создание релиза зависит от успешной подготовки комплекта для приставок.
Если релиз уже существует, текущий workflow загружает файлы, но не заменяет
его описание. При отсутствии Markdown-файла используется автоматический
список изменений GitHub.
