## Предыдущий выпуск: пресеты и сервис PS4 1.95

- [Основной пост для 4PDA — BBCode](forum-update-presets.bbcode.txt).
- [Отдельный пост с подробностями — BBCode](forum-details-presets.bbcode.txt).
- [Описание для GitHub Release](release-notes-presets.md).
- [Баннер PNG](../assets/packageflow-banner.png) · [баннер JPG](../assets/packageflow-banner.jpg).

Посты разделены, чтобы не перегружать одно сообщение. Ссылки на изображения
станут доступными после отправки коммитов WEB в GitHub. Вместо внешних ссылок
можно прикрепить изображения к сообщению 4PDA и вставить выданные форумом
ссылки на вложения. Заготовки не содержат неизвестных номеров вложений.

Для GitHub описание не привязано к новому номеру WEB: его выбирают при выпуске.
Версия сервиса — 1.95. Скриншоты WEB используют тестовую библиотеку;
изображения PS4 получены из текущего render/model в предпросмотре.
