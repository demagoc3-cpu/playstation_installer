# PackageFlow 1.10.31

Исправления переустановки игр на PS5 и удаления устройств. Файлы для приставок те же, что в 1.10.30.

## Переустановка на PS5

- Собственные образы и Folder снова можно отметить для переустановки в окне «Уже установлено на приставке». Раньше WEB разрешал это, только если сам ставил игру, поэтому Windows отказывал для игр, поставленных из Linux или другой копии WEB. Теперь решение принимается по ответу службы PS5: она управляет файлами игры, а изменение файлов игр на этой приставке разрешено.
- После галочки кнопка называется «Переустановить» и сразу запускает переустановку, без отдельного «Установить на устройства».
- Если переустановка недоступна, указана причина: не разрешено изменение файлов игр на этой PS5 или игра установлена не через PackageFlow.

## Удаление устройства

- Устройство удаляется, если с ним сейчас не идёт работа. Раньше удаление блокировали очереди других приставок, индексация хранилищ, давние незавершённые записи и очередь PS5, ожидающая выключенную приставку.
- Ожидающая очередь PS5 при удалении ставится на паузу. Удаление не даёт только уже принятая приставкой системная установка, установка или обновление службы на PS4 и операция, которая шла последние 15 минут. В сообщении сказано, что именно мешает.
- В WEB появилась кнопка «Удалить устройство» в окне «Изменить устройство». Удаляются профиль и ключ сопряжения на этом компьютере; игры и файлы на приставке сохраняются.

## Обновление

Установите новую версию поверх существующей, предварительно дождавшись завершения активных заданий. Настройки, библиотека и сопряжение сохраняются. Службы и приложение на приставках обновлять не нужно.

## Проверено

Тесты сервера, включая новые для переустановки образа, поставленного другим WEB, и для правил удаления устройства; проверка типов и ESLint. На приставке и в установщике Windows эти изменения не проверялись.
