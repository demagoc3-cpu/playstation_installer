[spoiler=Что такое PackageFlow и как он работает]
PackageFlow объединяет [b]WEB на компьютере или NAS[/b] и [b]PackageFlowService на PS4[/b]. Добавьте свои PKG, найдите игру, выберите патчи и DLC и отправьте установку из браузера либо приложения на приставке.

[b]Папки с PKG → библиотека WEB → общая очередь → установка на PS4.[/b]

PS4 скачивает пакет с сервера PackageFlow по HTTP. Для установки по сети не нужно предварительно переносить PKG на флешку. Файлы могут лежать на внутреннем или внешнем диске компьютера, а также в сетевой папке, доступной серверу.

WEB можно открыть на ПК, телефоне или планшете. На PS4 доступен собственный интерфейс с управлением геймпадом и штатной клавиатурой. Библиотека, пресеты и задания общие для WEB и приложения.

[b]Поиск и торрент-клиент — дополнительные компоненты.[/b] Если у вас уже есть PKG, для работы с библиотекой Prowlarr, Jackett и qBittorrent не требуются.

Компьютер или NAS с WEB должен работать во время передачи. Закрытие вкладки браузера не останавливает сервер и очередь. Это установка файлов на диск PS4; игра не запускается непосредственно из сетевой папки.
[/spoiler]

[spoiler=Приложение PackageFlow на PS4: управление с геймпада]
Один PKG содержит [b]нативный интерфейс и фоновую службу[/b]. После активации GoldHEN запустите PackageFlow и выполните сопряжение с WEB.

[list]
[*]Каталог с обложками, карточка игры и выбор пакетов.
[*]Поиск по всей библиотеке WEB, избранное и пресеты.
[*]R2 переключает 10/20/30 карточек и таблицу. Вид сохраняется после перезапуска и обновления.
[*]Родная клавиатура PS4 для ввода; резервный ввод доступен, если системный диалог не открылся.
[*]Общая очередь и история, выбор заданий галочками, отмена пакетов и веток игр.
[*]Файловый менеджер: просмотр, копирование, переименование, редактор текста и установка локальных PKG.
[*]Сопряжение, настройки, выбор языка RU/EN, обновление приложения с приставки.
[/list]

[b]Основные кнопки:[/b]
[list]
[*]Стрелки / левый стик — перемещение; крестик — открыть или выбрать; круг — назад.
[*]Треугольник — поиск в каталоге; квадрат — избранное. Подписи кнопок меняются по разделу.
[*]R2 — вид каталога; R1 — установка пресета или всего избранного с подтверждением.
[*]В «Заданиях»: крестик отмечает пакет, Options открывает действия отмены; L1 очищает завершённые и ошибки, R1 переключает страницы истории.
[/list]

Разделы управления установленными играми и сохранениями используйте в WEB. Само приложение PS4 не заменяет все операции браузерного интерфейса.

Чтобы закрыть только интерфейс, выйдите из карточки кругом, затем используйте Options и кнопку закрытия. Фоновая служба продолжит работу. После перезагрузки PS4 снова активируйте GoldHEN и запустите PackageFlow.
[/spoiler]

[spoiler=Поиск, qBittorrent и установка после скачивания]
[b]Prowlarr / Jackett → поиск в WEB → qBittorrent → библиотека → очередь PS4.[/b]

[list]
[*]Поиск через Torznab-совместимый индексатор: Prowlarr или Jackett.
[*]Карточки результатов с названием, размером, источником, сидами/личерами и доступным описанием/обложкой.
[*]Действия «Скачать» и «Скачать и установить».
[*]Добавление magnet-ссылки или ссылки на .torrent.
[*]Прогресс qBittorrent, остановка/продолжение, выбор файлов внутри раздачи.
[*]Автоимпорт найденных PKG в библиотеку и установка после завершения скачивания.
[*]Автоустановка выполняется сервером и работает при закрытой вкладке браузера. WEB и нужная приставка должны оставаться доступными.
[/list]

qBittorrent может работать на том же ПК, другом компьютере, NAS или в Docker. Но папка загрузок должна быть доступна [b]серверу PackageFlow[/b]: одного подключения к API qBittorrent недостаточно.

[b]Пример:[/b] qBittorrent на NAS видит /volume1/downloads, Windows видит эту папку как Z:\. В настройках укажите обе стороны: «Папка загрузок на этом ПК» — Z:\, «Та же папка в qBittorrent» — /volume1/downloads. В контейнере используйте пути внутри контейнера.

В списке PackageFlow отображаются задачи qBittorrent с тегом packageflow. Удаление такой задачи через WEB не удаляет скачанные файлы.

Поиск — необязательный компонент. Учётные данные трекера вводятся только при настройке соответствующего индексатора. FlareSolverr помогает обработать поддерживаемые проверки страниц, но не гарантирует доступ к любому сайту и не заменяет вход пользователя.

[spoiler=Требования и сеть]
[b]Приставка:[/b] PS4 / Slim / Pro с совместимой средой запуска homebrew и активным GoldHEN. Для основных функций нужен установленный и запущенный PackageFlowService. Программа сама не активирует GoldHEN.

[b]Компьютер:[/b]
[list]
[*]Готовый установщик: Windows 10/11 x64. WEB, Node.js и среда .NET входят в комплект.
[*]Из исходников: Windows, Linux или macOS; рекомендуется Node.js 22 LTS и pnpm.
[*]Docker: Linux-ПК, совместимый NAS или сервер с Docker Compose. Для Windows есть отдельный режим Compose в мастере.
[*]Достаточно свободного места на PS4 и доступные серверу PKG.
[*]qBittorrent с Web UI, Prowlarr/Jackett и FlareSolverr — только для соответствующих дополнительных функций.
[/list]

[b]Сеть:[/b] сервер и PS4 должны видеть друг друга в локальной сети. Для быстрой передачи желательно проводное подключение обоих устройств. Скорость тарифа интернета не определяет скорость установки локальных PKG.

[b]Основные порты:[/b]
[list]
[*]TCP 3000 на ПК/NAS — WEB и выдача файлов, если порт не изменён.
[*]TCP 12801 на PS4 — PackageFlowService.
[*]TCP 9090 на PS4 — PyLoader, только для этого маршрута.
[*]TCP 3001 на ПК — обратное подключение PyLoader в стандартной настройке Windows и в примере Compose ниже. При самостоятельном запуске без фиксированного порта он может быть выбран автоматически.
[/list]

Для PS4 используется [b]LAN-адрес[/b] сервера, а не localhost. С телефона открывайте http://IP_СЕРВЕРА:3000. Закрепление адресов ПК и PS4 в роутере поможет избежать повторной настройки.

WEB рассчитан на вашу доверенную сеть. Не публикуйте его и вспомогательные API напрямую в интернет. Сопряжение защищает команды к службе PS4, но не заменяет защиту самого WEB.
[/spoiler]

[spoiler=Windows 10/11: установка без Node.js и командной строки]
[b]1. Скачать и установить[/b]
Откройте [url=https://github.com/demagoc3-cpu/playstation_installer/releases/latest]Releases[/url] и скачайте [b]PackageFlowSetup-1.10.7-x64.exe[/b]. Запустите установщик, выберите язык и установите программу. Отдельно устанавливать Node.js и .NET не требуется.

[b]2. Настроить WEB[/b]
В мастере выберите режим [b]Windows[/b], папку с PKG и LAN IPv4 компьютера. Нажмите «Применить» и дождитесь готовности WEB. Открыть его можно из мастера или по адресу http://localhost:3000.

По кнопке [b]«Разрешить доступ PS4»[/b] мастер создаёт правила Windows Firewall для частной сети и выбранных портов. Для этой операции Windows запросит права администратора. Не отключайте брандмауэр целиком.

[b]3. Подключить PS4[/b]
Включите консоль, активируйте GoldHEN. В мастере откройте «PS4», нажмите [b]«Найти PS4»[/b] или введите IP вручную. Поиск не включает приставку из режима покоя.

Если служба ещё не установлена, запустите на PS4 [b]PyLoader на порту 9090[/b] и нажмите «Установить сервис». Мастер загрузит PKG релиза с проверкой SHA-256 и отправит его на приставку. Дождитесь результата в «Уведомления → Загрузки». Можно также установить PKG вручную.

Запустите PackageFlow на PS4, откройте «Подключения», получите код и введите его в мастере. После сопряжения добавьте PKG и отправьте установку.

[b]4. Дополнительные компоненты[/b]
Мастер умеет подготовить Prowlarr, FlareSolverr и qBittorrent либо подключить существующие установки. Поиск можно настроить позже: библиотека собственных PKG не зависит от результата проверки индексатора.

[b]5. Ежедневная работа[/b]
Закрытие окна оставляет программу в трее и не останавливает WEB. Используйте отдельную команду остановки. Есть автозапуск и проверка обновлений; активные операции блокируют остановку и замену WEB.

Данные находятся в [b]%LOCALAPPDATA%\PackageFlow\data[/b]. Сохраняйте эту папку при переносе на другой компьютер.

[b]Если установлена ошибочная версия 10.x.x:[/b] завершите активные операции и один раз вручную установите 1.10.7 поверх. Настройки, библиотека и сопряжение сохранятся. Переименование EXE проблему не исправляет.

[spoiler=Docker Compose: Linux, NAS и сервер]
[b]Минимальный запуск только PackageFlow[/b]
На Linux-хосте создайте папку проекта и файл compose.yml. Замените /srv/ps4-pkg на реальный путь к папке с PKG на хосте. Если это NAS, сначала подключите его папку к системе либо запускайте контейнер прямо на NAS.

[code]
services:
  packageflow:
    image: demagoc3/packageflow:latest
    restart: unless-stopped
    network_mode: host
    environment:
      PACKAGEFLOW_PAYLOAD_PORT: "3001"
    volumes:
      - packageflow-data:/app/.data
      - /srv/ps4-pkg:/games:ro

volumes:
  packageflow-data:
[/code]

Из каталога с compose.yml выполните:
[code]
docker compose up -d
[/code]

Откройте [b]http://IP_NAS_ИЛИ_СЕРВЕРА:3000[/b]. В выборе папки/настройках сканирования укажите [b]/games[/b] — это путь внутри контейнера, а не /srv/ps4-pkg с хоста. Установите PKG службы на PS4 и выполните сопряжение по коду.

[b]Что важно:[/b]
[list]
[*]Этот пример с network_mode: host предназначен для Linux. Раздел ports не нужен; порты слушают на хосте.
[*]Каталог /games подключён только для чтения. Каталог, очередь, ключи сопряжения и кэш WEB находятся в отдельном томе /app/.data.
[*]Образ опубликован для amd64 и arm64; фактическую поддержку Docker на вашем NAS проверьте отдельно.
[*]Несколько доступных папок можно добавить отдельными bind-mount и сканировать по их путям внутри контейнера.
[*]Prowlarr, Jackett и qBittorrent не требуются для локальной библиотеки. Они подключаются отдельно для поиска и загрузок.
[/list]

[b]Обновление контейнера:[/b]
[code]
docker compose pull
docker compose up -d
[/code]
Сохраняйте том packageflow-data и исходные PKG. Для диагностики используйте docker compose logs --tail=100 packageflow. Не запускайте down -v, если хотите сохранить настройки и сопряжение.

В репозитории есть [url=https://github.com/demagoc3-cpu/playstation_installer/blob/v1.10.7/docker-compose.yml]расширенный Compose с Prowlarr и FlareSolverr[/url]. Перед запуском измените путь к папке игр. qBittorrent подключается отдельно, его папку загрузок нужно смонтировать в PackageFlow и сопоставить пути.

[b]Docker Compose на Windows[/b]
Docker Desktop устанавливается и запускается отдельно. В мастере PackageFlow выберите [b]Docker Compose[/b], укажите папку игр и LAN IPv4 компьютера, затем примените настройки. Мастер создаёт отдельную конфигурацию с опубликованными портами, собирает локальный образ из готового WEB установщика и запускает контейнеры; установка исходников и npm не нужна.

Для поиска можно включить Prowlarr в Compose. Существующие компоненты на Windows доступны из контейнера через host.docker.internal, если их сетевые настройки разрешают такое подключение. Для Windows используйте конфигурацию мастера, а не Linux-пример с host network выше.

[spoiler=Запуск из исходников: Linux, macOS и Windows]
Нужны Git, Node.js 22 LTS и pnpm. Чтобы начать с опубликованного выпуска, используйте тег v1.10.7; ветка main может содержать ещё не выпущенные изменения.

[code]
git clone --branch v1.10.7 --depth 1 https://github.com/demagoc3-cpu/playstation_installer.git
cd playstation_installer
pnpm install
pnpm build
pnpm start
[/code]

Откройте http://localhost:3000, разрешите доступ из локальной сети, укажите папку с PKG и выполните сопряжение со службой на PS4. На сервере без рабочего стола путь к папке вводится вручную; установка графического диалога не нужна.

Для постоянной работы используйте production-сборку, а не pnpm dev. Каталог .data содержит состояние приложения — сохраните его при обновлении. Node.js/pnpm нужны только для запуска из исходников, в EXE и готовом контейнере они уже предусмотрены.

[spoiler=Сопряжение и обновление PackageFlowService]
[b]Первая установка:[/b] скачайте PackageFlowService-2.01.pkg из [url=https://github.com/demagoc3-cpu/playstation_installer/releases/latest]Releases[/url], установите на PS4 через доступный установщик или мастер Windows и запустите после GoldHEN.

В приложении PS4 откройте [b]«Подключения»[/b]. В WEB → «Настройки» выберите PackageFlowService, введите код с экрана приставки и подключитесь. Код действует ограниченное время; если он истёк, получите новый. В старых подписях приложение может называться PackegeFlowService.

WEB сохраняет сопряжение. Повторный ввод кода при обычном перезапуске не требуется. Если изменился IP, была переустановка/сброс данных или проверка связи не проходит, выполните повторное сопряжение. Ключ доступа к службе хранится на сервере WEB, не передаётся в браузер.

[b]Обновить службу можно:[/b]
[list]
[*]Из WEB → «О системе» → «Обновление PackageFlowService»: опубликованный релиз или локальный PKG.
[*]На PS4 → «Настройки» → «Обновить»: нужен интернет на приставке, WEB и сопряжение для этого обновления не требуются.
[/list]
Завершите активные операции перед обновлением. Для разных частей продукта номера версий могут различаться: WEB/Windows 1.10.7 и служба PS4 2.01 — это нормально.
[/spoiler]

[spoiler=Частые вопросы и решение проблем]
[b]Нужен ли интернет для установки своих PKG?[/b]
Для передачи уже имеющихся файлов достаточно локальной сети. Интернет нужен для скачивания компонентов, поиска, торрентов и проверки/загрузки обновлений.

[b]Нужно держать браузер открытым?[/b]
Нет. Должен работать сервер WEB. Если WEB на NAS, включённый компьютер для просмотра страницы не требуется.

[b]Можно брать файлы с NAS, а WEB запускать на Windows?[/b]
Да, подключите папку NAS к Windows и добавьте её в библиотеку. Файлы читаются по маршруту NAS → ПК с WEB → PS4. Если WEB работает прямо на NAS, передача идёт NAS → PS4.

[b]Нужен ли гигабит?[/b]
Программа работает и в более медленной сети. На 100 Мбит/с теоретический предел — 12,5 МБ/с до учёта накладных расходов. Реальная скорость зависит от сети, дисков и установки на PS4. Не обещаем, что сеть всегда быстрее USB; гигабит и Ethernet предпочтительны для больших пакетов.

[b]PKG отправлен, но загрузка PS4 не начинается.[/b]
Проверьте доступ PS4 к LAN-адресу WEB, брандмауэр, службу и сопряжение. Убедитесь, что сервер работает и исходный файл доступен. Для PyLoader проверьте порт 9090 и разрешённое обратное подключение. Перед повторной отправкой посмотрите «Уведомления → Загрузки» на PS4.

[b]После отмены в уведомлениях осталась старая задача.[/b]
Проверьте её на приставке и при необходимости удалите. Не отправляйте один пакет многократно, пока состояние предыдущей операции не выяснено.

[b]qBittorrent подключён, но PackageFlow не видит скачанные файлы.[/b]
Проверьте, что папка доступна серверу WEB, подключён сетевой диск и верно сопоставлены пути qBittorrent и PackageFlow.

[b]Игра требует более новую прошивку.[/b]
PackageFlow не делает бэкпорт и не исправляет несовместимый PKG. Проверка требований не гарантирует запуск; совместимость пакета и среды проверяется отдельно.

[b]После обновления пропали настройки.[/b]
Проверьте, что сохранена прежняя папка данных или Docker volume и сервер запускается с ней. Не публикуйте эти файлы: они могут содержать ключи и настройки подключений.

Для сообщения об ошибке укажите версии WEB и службы, ОС/способ запуска, что нажимали и точный текст ошибки. Скриншоты и журналы публикуйте без паролей, API-ключей и кодов сопряжения.

[/spoiler]
