# PackageFlow 1.10.28 · PS5 service 0.1.29 · PS5 app 01.000.044 · PS4 service 2.14

Изменения после WEB / Windows 1.10.7 и сервиса PS4 2.01. Первый выпуск с поддержкой PS5 и первый с пакетами для Linux.

## PS5

- Установка на PS5 из библиотеки WEB: PKG, Folder и собственные образы (UFS2, exFAT, PFS, FFPFSC). У каждой приставки своя очередь, PS4 и PS5 не мешают друг другу.
- Скорость передачи и оставшееся время для каждого задания, прогресс внутри пакета видно сразу.
- Размер порций передачи подстраивается под сеть. Если служба не успевает принять порцию, она уменьшается, и передача продолжается.
- Очередь переходит к следующей игре, даже если установка предыдущей не подтверждена или образ отклонён. Причина показывается в «Заданиях».
- Переустановка уже установленных собственных образов и Folder из окна проверки установки. Свою «осиротевшую» регистрацию служба убирает перед повторной публикацией.
- Устройства → «Сервис ▾» для PS5 через PLDMGR: запуск и проверка службы, автозапуск, проверка обновления по GitHub Releases. Приставки офлайн пропускаются сразу.
- Нативное приложение PackageFlow для PS5 (01.000.044): библиотека, поиск, фильтры и общая с WEB очередь установок.
- «На консоли» и «Сохранения» для PS5: список установленного, резервные копии сохранений с проверкой SHA-256.

Служба PS5 рассчитана на прошивку **13.60**.

## PS4

- Сервис 2.14: более крупные чтения файлов, один стабильный путь установки через BGFT.
- Скорость загрузки и переданный объём в «Заданиях» WEB.
- Сервис сообщает версию 2.14 и не предлагает обновление на ту же версию.

## WEB и приложения

- Новый интерфейс «стекло» для библиотеки, заданий и устройств.
- Подключение выбранных приставок без ввода кода сопряжения; первичная настройка PS4 и PS5 из Windows.
- Сетевые хранилища SMB, NFS и WebDAV в библиотеке; на Linux — SMB.
- Диагностика скорости приставки: сеть и диск отдельно, с временем замера.
- Windows: приложение на WebView2 + Vue вместо прежнего окна.
- **Linux: новые пакеты `.deb` и AppImage** с тем же WEB и тем же комплектом для приставок.

## Обновление

Установите новую версию поверх существующей, предварительно дождавшись завершения активных заданий. Настройки, библиотека и сопряжение сохраняются. Начиная с этого выпуска, каждая версия публикуется одним релизом `vX.Y.Z`, и проверка обновлений в программах берёт файлы из последнего релиза.

## Проверено

Тесты службы PS4, приложения PS5 и скриптов сборки WEB на компьютере; сборки Windows, Linux, PKG PS4 и FFPKG PS5 из чистых копий. Служба PS5 этой сборки загружена через PLDMGR на одну PS5 13.60. Сервис PS4 2.14 с исправленной версией на приставке не проверялся. Поведение на других прошивках и со всеми играми не проверялось.
