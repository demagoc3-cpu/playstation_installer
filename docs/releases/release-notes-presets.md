# Пресеты и общие задания · PackageFlowService 1.95

## WEB

- Пресеты: название и описание в отдельном окне, карточки с веером до пяти обложек, количество игр и файлов, общий размер.
- Установка всего пресета или выбранных PKG, редактирование состава, импорт и экспорт списков без файлов игр и приватных настроек.
- Единое дерево игры, патчей, бэкпортов и DLC в библиотеке, пресетах и заданиях; одинаковые сведения о PKG, шрифты уведомлений и цвета статусов. Убрана фиолетовая заливка строк.
- Библиотека занимает основную область окна; способ установки и сопряжение перенесены в «Настройки». Внутренняя прокрутка сохраняет доступ к поиску и кнопкам.
- Поиск охватывает всю библиотеку и возвращает полную ветку найденной игры. Страницы по 25/50/100 игр; «Передано PS4» учитывает выбранные пакеты.
- Раздел «Задания»: активные записи сверху, дерево или таблица, фильтры, отмена отдельного пакета и очереди, снятие ожидающего пакета галочкой, очистка завершённых записей и ошибок. История десяти очередей.

## PS4 — сервис 1.95

- Пресеты доступны из WEB: новый значок контейнера, кнопка установки всей подборки и выбор отдельных пакетов.
- Избранное сохраняется между запусками и обновлениями; установка всего избранного включает пакеты со всех страниц. Значок на карточке совпадает со значком раздела.
- **R2** переключает каталог на **10/20/30 карточек** с загрузкой страниц.
- Компактные задания, фильтры и история очередей: **L1** — очистить завершённые и ошибки, **R1** — следующая страница, крестик на ожидающем пакете — убрать из очереди.
- Команды установки и управления очередью сохраняют защиту от повторного выполнения после потери ответа.

## Обновление

Обновите WEB и установите `PackageFlowService-1.95.pkg`. Для Windows соберите установщик из этих коммитов с номером нового релиза; WEB также запускается через Docker Compose или из исходников. ПК/NAS должен оставаться включённым для установки пакетов из его библиотеки.

Новые функции прошли автоматические проверки WEB и сервиса, сборку Nuxt и упаковку PKG. Проверка новых сценариев на реальной PS4 ещё требуется.
