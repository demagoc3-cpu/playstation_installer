# PackageFlow WEB / Windows 1.10.7 · PS4 service 2.01

Изменения после WEB с пресетами и сервиса PS4 1.95.

## Пресеты

- Более узкие карточки в WEB и PS4, до пяти миниатюр с раскрытием веера по доступной ширине.
- На PS4 — четыре карточки в ряд, подложка, скруглённые рамки обложек и поворот вокруг нижнего центра, как в WEB.
- Количество игр, файлов и размер в одной строке; меньше пустого пространства.
- R1 «Установить» внизу устанавливает выбранный пресет из списка или весь открытый пресет, с подтверждением. Убрана верхняя дублирующая кнопка.

## Каталог и избранное PS4

- R2: 10 / 20 / 30 карточек или таблица с обложкой, названием, общим размером, числом патчей и DLC.
- Выбранный вид сохраняется после перезапуска и обновления PKG.
- Убраны дополнительные подписи CUSA под компактными карточками.
- Исправлено сопоставление ID избранных игр с библиотекой WEB при установке всего списка.
- R1 «Установить» для избранного перенесена в нижнюю панель. R2, R1 и L1 используют иконки в общем стиле и стоят после поиска.

## Очередь

- Крестик на PS4 отмечает отдельные активные и ожидающие задания; выбор сохраняется при переходах между страницами текущей очереди.
- Options: отмена отмеченных пакетов, их веток игр, текущего задания или всей очереди.
- WEB позволяет отменить всю ветку игры с её патчами и DLC.
- После удаления системной задачи очередь продолжается, когда PS4 подтверждает, что задача отсутствует. Если удаление не подтверждено, новые пакеты не отправляются; отсутствующая задача не помечается установленной.
- Выбор нескольких пакетов или веток применяется одним изменением очереди, без сдвига индексов работающего обработчика.
- При закрытии интерфейса PS4 завершаются и ожидаются его фоновые потоки перед освобождением экрана и выходом. Единственный сообщённый случай выключения консоли не воспроизведён; это не подтверждение устранения его причины.

## Windows: восстановление обновлений

Установщики **10.1.7** и **10.1.8** случайно опубликованы в релизах `v1.10.5` и `v1.10.6`. Их номера выше любой правильной версии 1.x.x.

**Если уже установлен 10.x.x, один раз вручную запустите `PackageFlowSetup-1.10.7-x64.exe` поверх существующей установки.** Завершите активные задания. Настройки, библиотека и сопряжение сохраняются; удалять папку данных или переименовывать старый EXE не нужно.

Исправленный клиент игнорирует ошибочные 10.x.x при выборе EXE из стабильных GitHub Releases. Сборки на Windows и Linux отклоняют такой номер до подготовки пакета. Сравнение учитывает три числа версии EXE и не предлагает повторно тот же четырёхкомпонентный номер сборки .NET.

Релиз должен содержать пересобранный `PackageFlowSetup-1.10.7-x64.exe` и `SHA256SUMS.txt` как обычные вложения. Windows workflow сохраняет их в артефакт; загрузите файлы из него в Release. PKG сервиса: `PackageFlowService-2.01.pkg` и его `.sha256`.

## Проверено

Тесты каталога, пресетов и очереди WEB; сборка Nuxt; тесты Windows Core и компиляция Windows-приложения; тесты интерфейса PS4 с проверкой памяти, сборка PKG и его метаданные. Скриншоты PS4 получены из текущего renderer на тестовых данных. Для поведения на реальной Windows/PS4 нужна проверка соответствующих сборок на устройствах.
