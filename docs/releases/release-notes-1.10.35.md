# PackageFlow 1.10.35 · PS5 service 030c

Все функции PS5 на любой прошивке, более быстрая и стабильная очередь. Новая служба PS5 сборки 030c.

## Служба PS5 030c

- Функции больше не привязаны к прошивке. Если служба запустилась и системные компоненты готовы, на любой прошивке доступны установка PKG для PS4 и PS5, Folder, образы UFS2, exFAT, PFS и FFPFSC, управление играми, сохранения, удаление и тест скорости.
- Если системная функция на конкретной прошивке не сработает, задание завершится ошибкой. Повторной отправки не будет.
- На PS5 12.20 проверены установка, запуск и удаление PS4-игры и тест скорости. На 13.60 проверены запуск игр, тест скорости по сети и чтение сохранений.
- Образы ставятся при любой версии ShadowMount, которую служба поддерживает.

## Очередь установки

- Пакеты, отправленные на установку, снимаются с выбора в библиотеке. Следующая «Установить выбранное» больше не ставит их повторно.
- Если одна приставка принимает пакет, окно установки для другой приставки больше не ждёт её ответа.
- Приставка, которая сейчас принимает пакет, остаётся доступной для новых установок: проверка уже установленного выполняется в очереди перед отправкой.
- Если в очереди остались только пакеты без подтверждения, очередь завершается через 2 минуты перепроверок. Новая установка начинает свою очередь, а неподтверждённые пакеты остаются в «Заданиях» с кнопками «Установлено на PS5» и «Снять ожидание».
- Контрольная сумма игры перед передачей считается в отдельном потоке. Пока считается сумма большой игры, интерфейс и другие приставки не тормозят.

## Исправления

- Записи о прежних незаконченных запусках службы PS5 закрываются сами, если на приставке уже работает служба. Они мешали запустить службу, провести тест скорости и закрыть приложение Windows. Такие запуски помечаются как неподтверждённые, ничего не отправляется повторно.
- Установщики Windows и Linux принимают службу PS5 без списка проверенных прошивок.

## Обновление

Установите новую версию поверх существующей, предварительно дождавшись завершения активных заданий. Настройки, библиотека и сопряжение сохраняются. Затем обновите службу на каждой PS5: «Устройства» → «Сервис ▾» → «Проверить обновления».

## Проверено

Тесты сервера, приложения Linux и службы PS5 на компьютере; сборка WEB с отдельным потоком подсчёта суммы. На PS5 12.20 и 13.60 проверены перечисленные выше функции службы 030c. Установка каждого формата Folder и образов и восстановление сохранений на 030c на приставке ещё не проверялись; переустановка ASTRO на 13.60 была отклонена системой (код 0x80B21104).
