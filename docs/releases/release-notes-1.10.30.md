# PackageFlow 1.10.30

Изменения после 1.10.29: полный английский перевод, исправления приложения Linux. Файлы для приставок те же, что в 1.10.29.

## Английский язык

- Добавлен перевод для 1104 строк, которые оставались на русском после выбора English: разделы «Устройства», «Задания», тест скорости, игры и сохранения на PS5, обновление приложения и службы, установка на устройства.
- Переведены сообщения сервера: ошибки, состояния заданий и события журнала, в том числе с IP, путями и размерами внутри текста.
- В журнале текст события и подробности ошибки переводятся отдельно. События, записанные до обновления, переводятся как раньше.
- Единицы измерения (МиБ → MiB, с → s, /с → /s), тип пакета, подсказки и сообщения из состояний тоже переключаются вместе с языком.

## Linux

- Пакеты `.deb` и AppImage снова собираются: сборка на GitHub падала на Python 3.12.
- Карточка раздачи в «Поиске» больше не открывается пустой в окне приложения: показываются обложка, сведения и описание, как в браузере.
- Если порт WEB занят другой программой или другой копией PackageFlow, приложение сообщает об этом в меню, в окне и при настройке поиска. Раньше в окне открывалась чужая страница, а служба молча перезапускалась.

## Обновление

Установите новую версию поверх существующей, предварительно дождавшись завершения активных заданий. Настройки, библиотека и сопряжение сохраняются. Службы и приложение на приставках обновлять не нужно.

## Проверено

Проверка перевода по всем строкам интерфейса и сервера, ESLint, проверка типов, сборка WEB и 484 теста сервера; тесты приложения Linux на Python 3.12 и 3.14; исправление карточки раздачи проверено на упрощённом макете в WebKitGTK. Английский интерфейс целиком в браузере не просматривался.
