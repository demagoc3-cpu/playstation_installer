# Сверка управления играми с ps5upload 7.0.0

2026-10-10: `git ls-remote` и fetch отдельной исследовательской копии подтвердили
актуальный main `1d47c778f5da072bf91c0a37e4f391e0e6da3eb9`, версия 7.0.0.
Снимки пользователя относятся к интерфейсу 6.6.1; изучены свежие исходники,
а не только подписи прежних кнопок. Код upstream не запускался на приставке.

## Меню и реализация

| Операция | Реализация upstream | Состояние PackageFlow |
| --- | --- | --- |
| Готово к запуску / Файлы игр | Две отдельные инвентаризации в общем Games | WEB015: 21 регистрация, 3 папки, 8 образов на тестовой PS5 |
| Запуск / закрытие | Системные команды с проверкой состояния выбранной приставки | Проверены на нашем 040; сведения DB-only исправлены в ELF015f |
| Удаление регистрации | Отличает свою nullfs-регистрацию от Sony-owned установки | Управляемые источники через ShadowMount; Sony-owned удаление пока отключено |
| Удаление файлов / перемещение | Файловые задания с состоянием и подтверждением | Проверены на отдельном собственном образе; пользовательские игры не удалялись |
| Добавить на рабочий стол | Регистрация из sce_sys; отдельный вариант меняет DRM metadata | Монтирование/регистрация есть; отдельное восстановление регистрации папки требует дальнейшей реализации |
| Восстановить значок | Только отсутствующие appmeta-файлы, ограниченное чтение и завершённая запись | Планируется отдельная команда, без перезаписи пользовательских метаданных |
| Резервная копия игры / скачать | Копия исходной игры на компьютер отдельным заданием | Не путать с уже работающим резервным копированием сохранений; отдельной команды копии игры пока нет |
| Исправить права | Явная операция chmod с подтверждением | Не включать глобальное рекурсивное 777 как автоматическое исправление всех отказов |
| Редактировать образ | Журнал сессии, временное правило image_rw, возврат read-only | Не реализовано; нашу распаковку после EACCES также нельзя назвать готовой |

Для регистрации и удаления важна разница между исходной папкой/образом и
установкой, которой управляет Sony. Upstream проверяет mount.lnk перед
размонтированием своего nullfs; для Sony-owned установки использует системный
uninstall. Вызов Sony сериализован с установками. На 13.x upstream содержит
специальную обработку нескольких install records после AppInstallAll. Это
наблюдение их проекта, не доказательство необходимости или безопасности
повторов на нашем стенде. Наш журнал не допускает повтор мутации после
неопределённого ответа.

Восстановление метаданных ограничено icon0.png, param.json, param.sfo и snd0.at9.
Существующие файлы сохраняются; верхний предел одного файла — 16 МиБ. Это
подходящий пример для отсутствующего значка, а не причина повторно устанавливать
всю игру или править всю базу.

Сессия редактирования образа сначала сохраняет журнал и отдельное временное
правило ShadowMount image_rw. Завершение восстанавливает режим, удаляет только
свой блок конфигурации и возвращает образ read-only. Это отдельная операция
с восстановлением после сбоя; показ кнопки «Edit files» не доказывает, что
обычная распаковка ShadowMount работает на нашем образе.

## Что полезно из свежего обновления

На передачу напрямую влияет сокращение фоновых запросов к выбранной консоли:
у upstream чтение процессов пропускается при активной загрузке и скрытом окне.
Компактные обновления прогресса не пересылают весь список файлов. Это стоит
применять при последующей работе над скоростью, сохраняя необходимые подтверждения
текущего задания и контрольные суммы. Один пропущенный опрос не считается
доказанным провалом и не запускает вторую передачу.

Также актуальны единая привязка операции к консоли, сохранение предыдущего
успешного состояния при временной ошибке чтения и проверка фактического результата
отмены. SDK v0.44 и AMPR LZ4 относятся к отдельным изменениям сборки/форматов:
мы не обновляли SDK Клода или работающий ELF лишь из-за новой версии upstream.

## Порядок продолжения

1. Довести прямую регистрацию папки и целевое восстановление её значка.
2. Отдельно проверить Sony-owned uninstall на собственном тестовом экземпляре;
   включать возможность только после подтверждённого результата на 13.60.
3. Копирование игры на компьютер с прогрессом/докачкой и проверкой состава.
4. Целевое исправление прав с понятным списком изменений.
5. Редактор образа с журналом сессии и возвратом read-only; отдельно разобрать
   EACCES распаковки на тестовом образе. Эти операции пока не включены.

WEB и ELF реализует Codex. Claude получает задания на приложение PS5 через
общий файл; подготовка задания сама по себе не запускает Claude. Задание018
на детерминированный тест native-ui остаётся отдельной работой.
