# Управление PS5 и восстановление сохранений — тестовая сборка 015

Управление и восстановление 015f проверены 2026-10-10 на PS5 Slim 13.60.
Новый кандидат 015g с проверкой активной игры ещё не подтверждён на приставке.
Изменения ещё не опубликованы.
Приложение PS5 040 принадлежит Claude и не пересобиралось: Codex изменял WEB
и корневую полезную нагрузку ELF, проверял интеграцию и готовил задания Claude.

## Что доступно в WEB

Общий выбор конкретной приставки сохраняется для «На консоли» и «Сохранения».
Управление относится к выбранному consoleId и IP, включая незавершённые команды.
PS4 использует прежний backend с управлением патчами/DLC, runtime и файлами;
для обоих типов приставок используются общие карточки в стиле PackageFlow.

PS5: вкладки «Готово к запуску» и «Файлы игр», обложки, поиск, платформенные
фильтры, сортировка и сведения об источнике. Проверено 21 системное приложение,
3 папки и 8 образов. Регистрация не приравнивается к проверенному запуску.
Сведения получают измеренный размер источника; системные 63 МБ не выдаются
за размер всей игры. В исходном списке размер может отсутствовать до запроса
«Сведения», поэтому сортировка по размеру использует только известные значения.

Проверены запуск и остановка своего приложения 040; на отдельном собственном
тестовом образе — монтирование/размонтирование, копирование, перемещение и
удаление исходника. Пользовательские игры не удалялись. Удаление регистрации
отдельно сохраняет источник, поэтому последующее сканирование может вернуть
карточку; удаление игры и файлов удаляет именно управляемый источник.

Для 10 регистраций, отсутствующих в ответе старого ShadowMount, ELF читает
метаданные app.db в READONLY. Их сведения и запуск доступны; удаление и
управление источниками отключены. Измерение неизвестного источника не выдумывается.
Редактор содержимого образа пока не реализован. Распаковка отключена: аппаратный
тест получил Permission denied; исходный образ сохранился без изменений.

Команда фиксируется до отправки. После потери ответа WEB читает журнал и
состояние привязанного задания, не отправляя мутацию повторно. HTTP 202 с
job_id принимается как начало работы, а не как окончание копирования.

Исправлен запуск игр при восстановлении, ожидающем проверки прогресса.
Если PS5 подтвердила завершённое применение (`pending`), WEB разрешает запуск
и остановку игр, сохраняя копии для отката. Передача, применение и неизвестный
результат по-прежнему блокируют команды; ожидающая проверка не разрешает удаление
или перемещение. Первоначальная причина отказа больше не заменяется `ENOENT`:
WEB явно сообщает, если команда не отправлялась, и UI не опрашивает несуществующий
журнал. При потере ответа выполняется только чтение результата; отсутствующая
запись не вызывает повторную отправку. Проверки API и поведения Vue проходят.

## Проверка запущенной игры — кандидат 015g

При открытии «На консоли» WEB запрашивает активную игру выбранной PS5 и
обновляет это состояние каждые 5 секунд, пока раздел виден. У запущенной игры
карточка показывает «Запущено» и «Стоп» вместо «Запустить». Если состояние
неизвестно, запуск отключён до подтверждённого ответа службы.

Перед запуском состояние читается повторно. Для другой активной игры появляется
подтверждение с её названием и предупреждением о несохранённом прогрессе.
Отмена не посылает команд. Подтверждение привязано к Title ID и экземпляру
приложения: WEB сначала останавливает именно его, ждёт подтверждённого закрытия
и затем запускает выбранную игру. При смене приложения, потере ответа или уходе
из раздела незавершённый запуск прекращается. ELF дополнительно отказывает в
запуске при обнаружении работающего приложения, чтобы гонка не закрыла его молча.

Контекст Sony LaunchApp приведён к форме из исходников ps5upload: размер
структуры 32 байта и пустой argv; отрицательный код Sony сохраняется в результате
команды и показывается в WEB. Это аппаратно не подтверждённое исправление:
единственный повторный запуск ASTRO на прежнем 015f был отклонён, без доступного
кода Sony. Предыдущий успешный запуск своего приложения 040 не доказывает
работоспособность ASTRO.

Новый API определения активной игры также требует проверки на 13.60. В
подготовленном 015h он включается только по отдельной отметке аппаратной проверки;
старое подтверждение каталога и запуска не включает новый API автоматически. Host-тесты
проверили карточки, отмену, порядок stop/launch, смену экземпляра приложения и
смену выбранной консоли; SDK сборка проходит. 015g отправлен ровно один раз после
подтверждённой остановки 015f, но ответ health не получен. После этого Payload
Manager, FTP и loader также недоступны; пользователь видит обычное меню PS5.
Причина недоступности пока не установлена. Повторной отправки или попытки
закрыть пользовательскую игру не было.

## Восстановление PS5

Кнопка «Восстановить» работает для проверенных копий в хранилище WEB этой
приставки, пользователя и игры. Поддержаны исходные контейнеры native и legacy
в уже существующих слотах с совпадающим составом. ZIP импорт, расшифровка,
переподпись и перенос между приставками или пользователями не реализованы.

WEB сверяет SHA-256 копии, передаёт файлы с BLAKE3 и проверяет состав текущего
сохранения перед применением. ELF готовит новые файлы рядом с прежними,
сохраняет права/владельца и журнал. Атомарно заменяются отдельные файлы;
всё сохранение не является одной атомарной файловой транзакцией.
Прежние файлы остаются для отката до отдельного подтверждения пользователя.
При неопределённом результате выполняется чтение журнала без повторного применения.

На реальной PS5 проверены две неизменённые копии: native — 1 файл/3 145 728
байт, legacy — 2 файла/3 145 824 байта. Прошли передача, применение, повторное
чтение результата и откат, включая полный путь через фактический WEB.
Независимые FTP SHA-256 совпали до применения, после применения и после отката.
Прогресс в игре отдельно не загружался: тест подтверждает сохранность байтов
и протокол, а не совместимость любых сохранений.

Финальное подтверждение с удалением прежних файлов прошло host-тесты, но
ещё не испытано на PS5: автоматическая проверка разрешений отклонила этот
шаг, поскольку пользователь разрешил восстановление с откатом. Шаг не выполнялся.
Для аппаратного завершения потребуется отдельное разрешение на удаление
только созданных тестом файлов отката; резервные копии WEB сохранятся.
