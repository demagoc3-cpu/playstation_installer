# Восстановление журнала установщика — 1.57

После выключения PS4 файл `/data/PackegeFlowService/install-jobs-v1.bin` оказался пустым (0 байт). Служба 1.56 отвечала на `/status`, но корректно блокировала установщик и сопряжение с ошибкой `0xFFFFD8D2`. Повторная установка Stray не была отправлена. Причина самого выключения консоли не установлена.

## Исправление

- Перед публикацией основного журнала служба записывает полный резервный снимок `.prev`. Обе копии записываются через временный файл с проверкой полной записи, fsync файла, rename и fsync каталога.
- Резервный снимок сохраняет намерение до вызова системного установщика. После потери основного файла он позволяет загрузить известные номера заданий; автоматически повторных команд установки нет.
- При повреждении основного снимка загружается только полностью проверенная резервная копия с прежним ABI. Если обе копии повреждены, запись блокируется; история не сбрасывается автоматически.
- При ошибке загрузки очищается только непроверенное состояние в памяти, чтобы повреждённое поле count не использовалось как длина массива.
- Ключ сопряжения не меняется.

## Ручное восстановление этой консоли

По разрешённому временному FTP прочитаны журнал и лог. Исходный журнал пуст; временной копии нет. Создан резервный журнал из четырёх проверенных завершённых записей WEB: две неуспешные команды DLC без принятого задания, успешная установка тестового приложения PFLT00001 и подтверждённое обновление PFLS00001 до 1.56 (задача 530). Очередь WEB завершена; все восстанавливаемые записи терминальные. Полная прежняя история из пустого файла невосстановима; новые установки не добавлялись.

Сформированный снимок проверен валидатором C с тем же размещением структур: 39 952 байта, четыре записи, размер записи 1 248 байт. На PS4 загружена только новая резервная копия `.prev`; прочитана обратно и побайтово сверена. Исходный пустой файл и ключ сохранены. SHA-256 резервной копии: `4227e25aca2e50ad3c58c933a7cf0f3a4d6997d1de586f765cee7867ca42e022`.
