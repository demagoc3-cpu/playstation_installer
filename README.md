# PackageFlow — PS4 PKG Installer

**PackageFlow** — локальное веб‑приложение для установки `.pkg` / `.fpkg` на PlayStation 4 по сети прямо с компьютера и управления приставкой из браузера. Без USB‑флешек и без копирования многогигабайтных файлов: PKG остаются в вашей папке, а консоль скачивает их с ПК по HTTP.

- **Библиотека** пакетов с обложками, сгруппированная по играм: игра, патчи, бэкпорты и DLC.
- **Установка** по очереди в правильном порядке — через **PackageFlowService** или через **PyLoader**.
- **На консоли**: установленные игры, их патчи и DLC, удаление, запуск и остановка, переустановка.
- **О системе**: прошивка, модель, GoldHEN, свободное место; обновление сервиса из веба.
- **Файлы**: проводник по PS4 с загрузкой и скачиванием файлов.
- **Торренты** через qBittorrent с автоустановкой после загрузки и поиском через Torznab.

> ⚠️ Нужна PS4 с активным **GoldHEN**. PS5 не поддерживается.

## Возможности

**Библиотека пакетов**
- Рекурсивное сканирование папки с `.pkg` / `.fpkg` (до 500 пакетов за проход); системный диалог выбора папки на Windows, macOS и Linux.
- Метаданные прямо из PKG: `PARAM.SFO` (название, `TITLE_ID`, `CONTENT_ID`, категория) и обложка `icon0.png`.
- Автоматическое определение типа: **Игра**, **Патч**, **Бэкпорт** (по слову `backport` в имени), **DLC**; группировка по `CUSA`.
- Кэш сканирования и сохранение библиотеки между запусками. Файлы **никогда не копируются** — только читаются и раздаются по HTTP.

**Установка на PS4**
- Один пакет, выбранные, все DLC или вся библиотека; порядок очереди **игра → патчи / бэкпорты → DLC**.
- Два способа установки:
  - **PackageFlowService** (по умолчанию) — фоновый сервис на PS4: сообщает этап установки, ошибки и подтверждение завершения, умеет ставить игры, патчи и DLC;
  - **PyLoader** — через загрузчик payload на порту `9090`, ничего ставить на приставку не нужно.
- Прогресс передачи в реальном времени, отмена установки, сброс статуса для повторной установки.
- Очередь сохраняется на диск и продолжает работу после перезагрузки страницы или сервера.

**На консоли** *(через PackageFlowService)*
- Список установленных игр с обложками и составом: базовая игра, патч / бэкпорт, отдельные DLC, версии, размеры, внутренний или внешний диск.
- Удаление патча, отдельного DLC, всех DLC или игры целиком — с подтверждением. Сохранения не удаляются.
- Запуск и остановка игры.
- Переустановка игры из библиотеки: удаление прежней версии с патчами и DLC и установка выбранного PKG.

**О системе и обслуживание сервиса**
- Прошивка, модель (PS4 / Pro), версия GoldHEN, место на дисках, версия и время работы сервиса.
- Обновление PackageFlowService прямо из веба: из релиза на GitHub или из локального PKG; перезапуск сервиса.

**Файлы консоли** *(через PackageFlowService)*
- Проводник по каталогам PS4, скачивание файлов на ПК (с докачкой).
- Загрузка файлов в `/data` и на USB‑накопители с паузой и продолжением после обрыва связи.

**Торренты**
- qBittorrent на этом ПК, на NAS, в Docker или на другом компьютере в сети.
- magnet‑ и `.torrent`‑ссылки, выбор файлов, пауза / продолжение.
- **Автоустановка**: после загрузки сервер сам добавляет пакеты в библиотеку и отправляет их на PS4 — страница может быть закрыта.
- Поиск через Torznab (Jackett, Prowlarr).

**Интерфейс**
- Боковое меню: Библиотека, На консоли, Загрузки, Поиск, Журнал, Файлы, О системе.
- **Журнал** событий сервера: запросы PS4, передача пакетов, ошибки qBittorrent и API — прямо на странице.
- IP приставки и настройки запоминаются; открытый раздел сохраняется в адресе (`/#console`, `/#log` …).

## Как это работает

PS4 всегда скачивает PKG **с сервера PackageFlow** по HTTP (сервис загрузок BGFT). Способ установки определяет только то, **кто даёт приставке команду** и как PackageFlow узнаёт результат.

```
┌──────────────────────── ПК ─────────────────────────┐              ┌──────────── PS4 ────────────┐
│                                                     │              │                             │
│  Браузер ──► PackageFlow (Nuxt / Nitro, порт 3000)  │              │  GoldHEN                    │
│                 │                                   │              │                             │
│                 │  PackageFlowService (по умолч.)   │              │                             │
│                 ├── HTTP API :12801 + ключ ─────────┼─────────────►│  PackageFlowService         │
│                 │   установка, статус, консоль      │◄─────────────┼─ этап, ошибки, результат    │
│                 │                                   │              │                             │
│                 │  PyLoader                         │              │                             │
│                 ├── payload (.bin) на :9090 ────────┼─────────────►│  загрузчик payload          │
│                 │                                   │              │                             │
│   /json/<id>.json      (манифест)  ◄────────────────┼──────────────┤  BGFT скачивает PKG         │
│   /api/packages/<id>   (Range)     ◄────────────────┼──────────────┤  и устанавливает            │
│                                                     │              │                             │
│   qBittorrent Web UI (этот ПК или NAS) ◄── API      │              │                             │
└─────────────────────────────────────────────────────┘              └─────────────────────────────┘
```

**Через PackageFlowService.** PackageFlow передаёт сервису на приставке ссылку на манифест пакета (`http://<IP ПК>:3000/json/<id>.json`). Сервис ставит задачу в BGFT и сообщает этап установки, ошибки и подтверждение завершения. Для этого WEB и сервис один раз сопрягаются кодом с экрана PS4 — см. [раздел ниже](#packageflowservice-и-сопряжение-с-web).

**Через PyLoader.**
1. Проверяется загрузчик: `GET http://<PS4_IP>:9090/status` → `{"status":"ready"}`.
2. PackageFlow вшивает `IP:порт` компьютера в payload `public/ps4-pkg-installer.bin` и отправляет его на `PS4:9090`; payload подключается обратно к ПК.
3. Для каждого пакета передаётся команда с URL манифеста, консоль скачивает PKG, PackageFlow считает переданные байты и двигает очередь. Итог установки PyLoader не сообщает — его видно на экране PS4.

## Требования

### Компьютер

| Компонент | Версия / примечание |
|---|---|
| ОС | Windows, Linux, macOS |
| Node.js | **20.19+** или **22 LTS** (требование Nuxt 4) |
| Пакетный менеджер | `pnpm` (рекомендуется) или `npm` |
| Диалог выбора папки | Windows и macOS — встроенный; Linux — `zenity` или `kdialog` (опционально) |
| qBittorrent | Опционально, 4.2+ с включённым Web UI (поддерживаются и 5.x) |
| Сеть | ПК и PS4 в одной локальной сети |

### PlayStation 4

- Прошивка с поддержкой эксплойта и загруженным **GoldHEN**.
- Для способа **PackageFlowService** — установленный PKG сервиса (см. [ниже](#packageflowservice-и-сопряжение-с-web)).
- Для способа **PyLoader** — загрузчик payload, который слушает TCP `9090` и отвечает на `GET /status` → `{"status":"ready"}`.
- Достаточно свободного места: для установки игры нужно примерно вдвое больше размера PKG.

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/demagoc3-cpu/playstation_installer.git
cd playstation_installer

# 2. Установить зависимости
pnpm install          # или: npm install

# 3. (Linux, опционально) диалог выбора папки — на Windows и macOS не нужен
sudo apt install zenity          # Debian / Ubuntu
sudo dnf install zenity          # Fedora
sudo pacman -S zenity            # Arch
```

> Если `pnpm install` ругается на `pnpm-workspace.yaml`, замените строку
> `esbuild: set this to true or false` на `esbuild: true`.

### Открыть порты в файрволе

Консоль сама подключается к ПК, поэтому входящие соединения из LAN должны быть разрешены:

- **TCP 3000** — веб‑интерфейс, манифесты и раздача PKG;
- **TCP, случайный высокий порт** — обратное подключение payload (порт выбирается ОС при каждом запуске).

Пример для `ufw` (разрешить всё из домашней подсети):

```bash
sudo ufw allow from 192.168.1.0/24
```

Для `firewalld`:

```bash
sudo firewall-cmd --permanent --zone=trusted --add-source=192.168.1.0/24
sudo firewall-cmd --reload
```

## Запуск

### Режим разработки

```bash
pnpm dev
```

Сервер слушает `0.0.0.0:3000` (см. `nuxt.config.ts`). Откройте `http://localhost:3000`.

### Продакшен‑сборка

```bash
pnpm build
HOST=0.0.0.0 PORT=3000 node .output/server/index.mjs
```

> Запускайте сервер **из корня проекта**: пути к payload (`public/` или `.output/public/`) и к папке данных `.data/` вычисляются от текущего каталога.

### Автозапуск через systemd (Linux)

`/etc/systemd/system/packageflow.service`:

```ini
[Unit]
Description=PackageFlow PS4 installer
After=network-online.target

[Service]
Type=simple
User=developer
WorkingDirectory=/home/developer/projects/web/playstation_installer
Environment=HOST=0.0.0.0
Environment=PORT=3000
ExecStart=/usr/bin/node .output/server/index.mjs
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now packageflow
```

## PackageFlowService и сопряжение с WEB

**PackageFlowService** — фоновый сервис для PS4, с которым работает WEB. Через него идут установка с подтверждением результата, раздел «На консоли», «О системе» и «Файлы». Сервис распространяется **готовым PKG** в разделе [Releases](https://github.com/demagoc3-cpu/playstation_installer/releases) этого репозитория; его исходный код не публикуется. Сервис слушает HTTP API на порту `12801` и принимает команды только от сопряжённого WEB.

### Установка сервиса на PS4

1. Скачайте `PackageFlowService.pkg` из [Releases](https://github.com/demagoc3-cpu/playstation_installer/releases).
2. Установите его на PS4 удобным способом — например, из библиотеки PackageFlow способом **PyLoader** (добавьте папку с PKG, выберите «PyLoader», нажмите «Установить»).
3. Запустите **PackageFlowService** на приставке (в меню PS4 он называется *PackegeFlowService*). На экране появятся адрес сервиса и **код сопряжения**.

Дальнейшие обновления сервиса ставятся прямо из веба — раздел **«О системе» → «Обновление PackageFlowService»**: проверка релиза на GitHub или выбор локального PKG, затем установка и перезапуск сервиса. Приставка скачивает обновление с вашего ПК по локальной сети.

### Сопряжение

Сопряжение выполняется **один раз для каждого IP приставки**:

1. Подключите PS4 в PackageFlow: нажмите на IP в правом верхнем углу, введите адрес консоли → **Подключить**.
2. В разделе **«Библиотека»** в блоке **«Способ установки»** выберите **PackageFlowService**. Если сопряжения ещё нет, появится поле **«Код с экрана запускателя PS4»**.
3. Запустите PackageFlowService на PS4 и введите показанный код вида `F7Y-YUH`. Дефис и заглавные буквы подставляются автоматически. **Код действует 5 минут**; если он истёк, откройте запускатель на PS4 ещё раз.
4. Нажмите **«Подключить»**. PackageFlow проверит сервис и сохранит подключение — статус станет «Сервис готов к установке игр, патчей и DLC».

После этого сервис используется автоматически во всех разделах: повторно вводить код после перезапуска PS4 или PackageFlow не нужно.

- **«Проверить сервис»** — проверить, отвечает ли сервис и действительно ли сопряжение.
- **«Повторить сопряжение»** — ввести новый код, например после переустановки сервиса или если приставка «забыла» подключение.
- **Сменился IP приставки** (например, роутер выдал другой адрес) — выполните сопряжение для нового адреса. Лучше закрепить за PS4 постоянный IP в настройках роутера.

**Как хранится подключение.** При сопряжении сервис выдаёт WEB ключ доступа. Ключ хранится только на сервере PackageFlow — в файле `.data/ps4-service-keys.json` с правами доступа только для владельца — и никогда не передаётся в браузер. Чтобы «забыть» приставку, удалите её запись из этого файла (или весь файл) при остановленном PackageFlow.

## Использование

### 1. Подготовить консоль

1. Запустите эксплойт и **GoldHEN** на PS4.
2. Для PackageFlowService — запустите сервис (при первом использовании выполните [сопряжение](#сопряжение)); для PyLoader — убедитесь, что загрузчик активен на порту `9090`.
3. Узнайте IP консоли: **Настройки → Сеть → Просмотреть состояние соединения**.

### 2. Подключить PS4

Нажмите на IP‑адрес в правом верхнем углу, введите IP консоли → **Подключить**. Индикатор станет зелёным. Адрес запоминается на сервере и восстанавливается при следующем открытии.

### 3. Добавить пакеты

- **«Выбрать папку»** — системный диалог выбора папки. Открывается на компьютере, где запущен сервер, и начинает с папки последнего сканирования.
- **«Указать путь»** (внизу страницы) — ввести путь вручную, например `D:\Games\PS4` или `/mnt/games/ps4`.

Сканер найдёт все `.pkg` / `.fpkg`, прочитает метаданные и обложки и сгруппирует пакеты по `CUSA`.

### 4. Установить

![Очередь установки: игра передаётся на PS4, патч и DLC ждут очереди](docs/screenshots/queue.png)

Выберите **способ установки** — PackageFlowService (по умолчанию) или PyLoader — и нажмите:

| Кнопка | Что делает |
|---|---|
| **Установить** (в строке пакета) | Отправляет один пакет |
| **Установить выбранное** | Все отмеченные галочками |
| **Все DLC** / **DLC** в ветке | Только DLC — всей библиотеки или одной игры |
| **Установить всё** | Всю библиотеку по порядку |
| **Отменить установку** | Останавливает очередь и текущую передачу |
| **Сбросить** | Возвращает пакет в «Готов к отправке», чтобы поставить его заново |

С PackageFlowService статус пакета доходит до подтверждённой установки. С PyLoader PackageFlow видит только передачу файла: «PS4 скачала пакет полностью», а итог установки показывается на экране приставки.

> Если после отмены загрузка осталась в «Уведомления → Загрузки» на PS4, удалите её там: BGFT не создаёт новое задание для игры, пока висит старое.

### 5. Управление библиотекой

- **Установлено** — отметить пакет как уже установленный.
- **×** — убрать пакет из списка (файл на диске не трогается).
- **Переиндекс.** — пересканировать ветку игры после замены или добавления файлов.
- **Удалить ветку** — убрать игру со всеми патчами и DLC из библиотеки.

### На консоли

Раздел показывает, что **фактически установлено** на PS4: игры с обложками, их патчи, бэкпорты и DLC с версиями и размерами.

- **Удалить** патч, DLC, все DLC или игру целиком — с подтверждением по `TITLE_ID`. Сохранения игр не удаляются. Ход удаления виден в окне задания, а после обрыва связи результат можно проверить повторно.
- **Запустить** / **Остановить** игру.
- **Переустановить** — из библиотеки PackageFlow: прежняя игра с патчами и DLC удаляется, затем ставится выбранный PKG.

### О системе

Прошивка, модель, GoldHEN, место на внутреннем и внешнем дисках, версия и время работы PackageFlowService. Данные обновляются, пока раздел открыт. Здесь же — **обновление и перезапуск сервиса**.

### Файлы

Проводник по каталогам PS4:

- **скачивание** файла на ПК (поддерживается докачка);
- **загрузка** файла в `/data` или на USB‑накопитель (`/mnt/usb0`–`/mnt/usb7`) с кнопкой **«Пауза»**: повторный выбор того же файла продолжит передачу с места остановки, даже после перезапуска сервиса.

Существующие файлы не перезаписываются, удаление и переименование не поддерживаются. Загрузка PKG в проводнике **не устанавливает** игру — для установки используйте «Библиотеку».

### Журнал

Лента событий сервера: подключение PS4, запросы манифестов и пакетов, обрывы передачи, итог по каждому пакету, автоустановка торрентов, ошибки qBittorrent и API. Предупреждения и ошибки подсвечиваются, их количество видно на пункте меню.

## Торрент-клиент (qBittorrent)

PackageFlow управляет qBittorrent через Web UI API. qBittorrent может работать на этом же ПК, на NAS, в Docker или на другом компьютере в локальной сети — укажите его адрес. Главное условие: скачанные файлы должны быть **доступны с компьютера, где запущен PackageFlow** (локальный диск, сетевая папка, подключённый диск).

### Установка qBittorrent

**Linux (с графическим интерфейсом):**

```bash
sudo apt install qbittorrent          # Debian / Ubuntu
sudo dnf install qbittorrent          # Fedora
sudo pacman -S qbittorrent            # Arch
```

**Linux (сервер без GUI) — `qbittorrent-nox`:**

```bash
sudo apt install qbittorrent-nox
qbittorrent-nox          # первый запуск: принять условия, в консоли будет логин и временный пароль
```

Автозапуск через systemd (Debian/Ubuntu‑пакет содержит шаблон сервиса):

```bash
sudo systemctl enable --now qbittorrent-nox@$USER
```

**Windows / macOS:** установщик с официального сайта — <https://www.qbittorrent.org/download>.

**Docker** (`linuxserver/qbittorrent`):

services:

1. В боковом меню откройте раздел **«Загрузки»** и нажмите **Настроить**.
2. Заполните:

   | Адрес qBittorrent Web UI | `http://127.0.0.1:8080` или `http://192.168.1.10:8080` | этот ПК или любой компьютер в сети |
   | Логин / Пароль | `admin` / ваш пароль | пустой пароль при повторном сохранении = оставить прежний |
   | Папка загрузок на этом ПК | `D:\Torrents\PS4`, `/home/user/Downloads/ps4`, `Z:\downloads` | отсюда PackageFlow берёт PKG |
   | Та же папка в qBittorrent | `/downloads` | только если qBittorrent на другом компьютере или в Docker |

>
> **Пример с NAS:** qBittorrent на NAS сохраняет в `/volume1/downloads`, а на Windows эта папка подключена как диск `Z:`. Укажите адрес `http://192.168.1.20:8080`, «Папка загрузок на этом ПК» — `Z:\`, «Та же папка в qBittorrent» — `/volume1/downloads`.

### qBittorrent на другом компьютере (NAS, сервер)

qBittorrent не обязан работать на том же ПК, что и PackageFlow. Важно понимать, **откуда PS4 берёт пакет**: приставка качает PKG не из qBittorrent, а **с сервера PackageFlow** по HTTP. qBittorrent через API сообщает только список задач и пути к файлам — само содержимое PackageFlow читает с диска. Поэтому папка загрузок qBittorrent должна быть **доступна с ПК, где запущен PackageFlow**, как сетевая папка (SMB / NFS).

```
┌──────── NAS / другой ПК ────────┐        ┌──────── ПК с PackageFlow ────────┐        ┌───── PS4 ─────┐
│                                 │        │                                  │        │               │
│  qBittorrent Web UI  :8080 ◄────┼─ API ──┤  1. статус торрентов, пути       │        │               │
│                                 │        │                                  │        │               │
│  /volume1/downloads/Игра/*.pkg ─┼─ SMB ─►│  2. Z:\Игра\*.pkg (сетевой диск) │        │               │
│                                 │        │  3. сканирование → библиотека    │        │               │
│                                 │        │  4. HTTP :3000  /api/packages/…  ├─ HTTP ►│  BGFT качает  │
│                                 │        │                                  │        │  и ставит PKG │
└─────────────────────────────────┘        └──────────────────────────────────┘        └───────────────┘
```

**Как это работает:**

1. qBittorrent на NAS докачивает торрент в свою папку, например `/volume1/downloads/Игра`.
2. PackageFlow получает от qBittorrent путь и **переводит его в путь на этом ПК**: `/volume1/downloads/Игра` → `Z:\Игра`. Для этого в настройках заполняется поле «Та же папка в qBittorrent».
3. PackageFlow сканирует найденные PKG и добавляет их в библиотеку (а при включённой «Автоустановке» — сразу ставит в очередь).
4. PS4 получает ссылку `http://<IP ПК>:3000/json/<id>.json` и скачивает пакет **с ПК**, который в это время на лету читает его с NAS. Ничего не копируется, место на диске ПК не расходуется.

**Настройка:**

1. Откройте папку загрузок NAS по сети (SMB-шара, например `\\NAS\downloads`).
2. Подключите её на ПК с PackageFlow:
   - **Windows:** «Этот компьютер» → «Подключить сетевой диск» → буква `Z:` → `\\NAS\downloads` → ✅ «Восстанавливать подключение при входе в систему».
   - **Linux:**
     ```bash
     sudo apt install cifs-utils
     sudo mkdir -p /mnt/nas-downloads
     sudo mount -t cifs //NAS/downloads /mnt/nas-downloads -o username=USER,uid=$(id -u),gid=$(id -g)
     ```
     Для автоподключения добавьте строку в `/etc/fstab`.
3. В PackageFlow → **«Загрузки»** → **«Настроить»**:

   | Поле | Значение |
   |---|---|
   | Адрес qBittorrent Web UI | `http://192.168.1.20:8080` (IP NAS) |
   | Логин / Пароль | учётные данные Web UI qBittorrent |
   | Папка загрузок на этом ПК | `Z:\` (Windows) или `/mnt/nas-downloads` (Linux) |
   | Та же папка в qBittorrent | `/volume1/downloads` — как её видит сам qBittorrent (в Docker — путь внутри контейнера, например `/downloads`) |

4. **Сохранить и проверить.** Новые торренты, добавленные из PackageFlow, qBittorrent будет сохранять в свою папку, а PackageFlow — находить их через сетевой диск.

**Что важно учитывать:**

- **ПК с PackageFlow должен быть включён** во время установки, а сетевой диск — подключён.
- **Данные проходят по сети дважды:** NAS → ПК → PS4. В проводной гигабитной сети это почти не заметно; если ПК подключён по Wi‑Fi, скорость установки может заметно снизиться.
- Если в журнале появляется `Загруженные файлы не найдены: …` — путь из qBittorrent не удалось сопоставить с диском на ПК: проверьте, что сетевой диск подключён и что «Та же папка в qBittorrent» указана точно так, как её показывает qBittorrent (путь сохранения в свойствах торрента).

> **Совет:** если на NAS или сервере с qBittorrent можно установить Node.js 20+, выгоднее запустить **PackageFlow прямо там** (`pnpm build && pnpm start`). Тогда PKG идут напрямую NAS → PS4 одним «прыжком», ПК не нужен, а веб‑интерфейс открывается с любого устройства по `http://<IP NAS>:3000`. Поле «Та же папка в qBittorrent» в этом случае оставьте пустым; папки добавляются через «Указать путь» (системного диалога выбора папки на сервере без рабочего стола нет).

### Скачивание и автоустановка

![Загрузки torrent: задачи qBittorrent с прогрессом, автоустановкой и выбором файлов внутри торрента](docs/screenshots/torrents.png)

1. Вставьте magnet‑ссылку (`magnet:?xt=urn:btih:…`) или HTTP(S)‑ссылку на `.torrent`.
2. При необходимости отметьте **«Установить после загрузки»**.
3. Нажмите **Скачать**.

Что происходит дальше:

- задача создаётся в qBittorrent с тегом `packageflow` (и `packageflow-auto-install`, если включена автоустановка);
- список задач на странице обновляется каждые 2 секунды;
- **Файлы** — выбрать, какие файлы торрента качать (например, только нужный патч);
- по завершении загрузки папка торрента сканируется, пакеты попадают в библиотеку;
- если включена автоустановка — **сервер сам** ставит пакеты в очередь установки (игра → патчи → DLC), даже когда страница PackageFlow закрыта. Если PS4 выключена или идёт другая установка, он дождётся.

Автоустановку можно включить/выключить у уже добавленной задачи галочкой **«Автоустановка»**.

Кнопка **×** удаляет задачу из qBittorrent, **не удаляя скачанные файлы**.

> PackageFlow показывает только задачи с тегом `packageflow`. Торренты, добавленные в qBittorrent вручную, в списке не появятся.

> Автоустановка торрентов всегда выполняется через PyLoader и запускается один раз на торрент. Чтобы повторить попытку, снимите и снова поставьте галочку «Автоустановка». Нужен сохранённый IP приставки — хотя бы раз нажмите «Подключить».

## Поиск через Torznab (Jackett / Prowlarr)

Раздел **«Поиск»** в боковом меню работает с любым Torznab‑совместимым API.

1. Установите [Jackett](https://github.com/Jackett/Jackett) или [Prowlarr](https://github.com/Prowlarr/Prowlarr) и добавьте в него трекеры, которыми вы имеете право пользоваться.
2. Скопируйте **Torznab URL** индексатора и **API‑ключ**:
   - Jackett: `http://127.0.0.1:9117/api/v2.0/indexers/<indexer>/results/torznab/`
   - Prowlarr: `http://127.0.0.1:9696/<id>/api`
3. В PackageFlow: **Источник** → название, URL, API‑ключ → **Сохранить**.
4. Введите запрос → **Найти** → **Скачать** у нужного результата (уйдёт в qBittorrent, с учётом галочки «Установить после загрузки»).

Показывается до 40 результатов с размером и количеством сидов.

## Решение проблем

| Симптом | Причина и решение |
|---|---|
| «PS4 не подключена» | Неверный IP, консоль в режиме покоя, GoldHEN не запущен. Для PyLoader проверьте `http://<PS4_IP>:9090/status` |
| «Сервис не отвечает на порту 12801» | PackageFlowService не запущен на PS4 или приставка ушла в режим покоя. Запустите сервис и нажмите «Проверить сервис» |
| `Введите код вида F7Y-YUH` / сопряжение не проходит | Код истёк (действует 5 минут) — откройте запускатель сервиса на PS4 снова и введите новый код |
| Раньше работало, теперь сервис не принимает команды | Сменился IP приставки или сервис переустановлен — нажмите «Повторить сопряжение» |
| `Payload не подключился к серверу за 12 секунд` (PyLoader) | Файрвол ПК блокирует входящие соединения от PS4, либо ПК и консоль в разных подсетях / VLAN |
| Задание отправлено, но PS4 не скачивает | Порт `3000` закрыт для локальной сети или сервер запущен на `127.0.0.1`. Разрешите порт в файрволе; запускайте с `HOST=0.0.0.0` |
| «Нельзя выполнить загрузку» на PS4 сразу после старта | В «Уведомления → Загрузки» висит старое задание для этой игры — удалите его и повторите |
| `CE-36441-8` / ошибка установки на PS4 | Патч не подходит к установленной версии игры, либо приставка онлайн и проверка сорвала установку. Удалите старую версию, поставьте игру, затем подходящий патч |
| Игра установилась, но требует новую прошивку | Нужен бэкпорт под вашу прошивку. **Не обновляйте прошивку** — это лишит вас GoldHEN |
| `Некорректный заголовок PKG` / пакет не появился | Файл повреждён, недокачан или не является PS4 PKG |
| «Выбрать папку» не работает | Linux: нет `zenity` / `kdialog` или сервер запущен без графической сессии. Диалог открывается на ПК с сервером. Используйте «Указать путь» |
| `qBittorrent: неверный логин или пароль` / временная блокировка | Проверьте данные Web UI; после нескольких неудачных попыток qBittorrent временно блокирует IP |
| `Загруженные файлы не найдены: …` | qBittorrent сохраняет файлы по пути, которого нет на этом ПК. Подключите папку загрузок как сетевой диск и заполните «Та же папка в qBittorrent» |
| Автоустановка торрента не началась | Посмотрите «Журнал»: сервер пишет, чего ждёт (PS4 недоступна, идёт другая очередь). Для повтора снимите и снова поставьте «Автоустановку» |

## Ограничения

- Поддерживается только **PS4** (`PS4GD`, `PS4GP`, `PS4AC` …). PS5 не поддерживается.
- Разделы «На консоли», «О системе» и «Файлы» работают только с запущенным и сопряжённым PackageFlowService.
- Одна активная очередь установки. Автоустановка торрентов всегда идёт через PyLoader.
- В «Файлах» нет перезаписи, удаления и переименования; запись разрешена только в `/data` и на USB.
- Раздел «Удалённый доступ» пока в разработке.
- У самого WEB нет входа по паролю: **не открывайте порт `3000` в интернет**, используйте PackageFlow только в доверенной локальной сети.
- Пароль qBittorrent и API‑ключ Torznab хранятся в `.data/` в открытом виде.
